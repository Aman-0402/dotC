Searching Algorithms

A Searching Algorithm is used to find the location of a particular element (called the key) in a collection of data.

If the element exists, the algorithm returns its position; otherwise, it reports that the element is not found.

Types of Searching Algorithms

The two most common searching algorithms are:

  1. Linear Search
  2. Binary Search
Searching Algorithm Array Requirement Time Complexity

1. Linear Search

Definition

Linear Search (Sequential Search) searches for an element by checking each element one by one from the beginning until the desired element is found or the array ends.

It is the simplest searching technique.

Working Principle

  1. Start from the first element.
  2. Compare it with the key.
  3. If equal, return the index.
  4. Otherwise, move to the next element.
  5. Repeat until the key is found or the array ends.

C Program

#include<stdio.h>

int main()
{
    int arr[]={10,20,30,40,50};
    int key=40;
    int found=0;

    for(int i=0;i<5;i++)
    {
        if(arr[i]==key)
        {
            printf("Element found at index %d",i);
            found=1;
            break;
        }
    }

    if(found==0)
        printf("Element not found");

    return 0;
}

Advantages

  • Very easy to implement.
  • Works on sorted and unsorted arrays.
  • No preprocessing required.
  • Suitable for small datasets.

Disadvantages

  • Slow for large datasets.
  • Checks every element sequentially.
  • Inefficient compared to Binary Search.

Applications

  • Small datasets.
  • Unsorted arrays.
  • Linked Lists.
  • Simple searching tasks.

2. Binary Search

Definition

Binary Search is a fast searching algorithm that repeatedly divides a sorted array into two halves until the required element is found.

Important: Binary Search works only on sorted arrays.

Working Principle

  1. Find the middle element.
  2. Compare it with the key.
  3. If equal, search ends.
  4. If key is smaller, search the left half.
  5. If key is larger, search the right half.
  6. Repeat until the element is found or the search interval becomes empty.

C Program

#include<stdio.h>

int main()
{
    int arr[]={10,20,30,40,50,60,70};

    int key=60;

    int low=0;

    int high=6;

    while(low<=high)
    {
        int mid=(low+high)/2;

        if(arr[mid]==key)
        {
            printf("Element found at index %d",mid);
            return 0;
        }

        else if(key<arr[mid])

            high=mid-1;

        else

            low=mid+1;
    }

    printf("Element not found");

    return 0;
}

When to Use Which?

Use Linear Search when:

  • Data is unsorted.
  • Dataset is small.
  • Simplicity is more important than speed.

Use Binary Search when:

  • Data is sorted.
  • Dataset is large.
  • High performance is required.

Summary

  • A Searching Algorithm finds the position of a target element in a collection.
  • Linear Search checks elements one by one and works with both sorted and unsorted arrays.
  • Binary Search repeatedly divides a sorted array into halves, making it much faster for large datasets.
  • Linear Search has:
    • Best Case: Ω(1)
    • Average Case: Θ(n)
    • Worst Case: O(n)
  • Binary Search has:
    • Best Case: Ω(1)
    • Average Case: Θ(log n)
    • Worst Case: O(log n)
  • Binary Search is significantly more efficient than Linear Search for large, sorted datasets.
