C Programming / Unit 2 / Scope

Scope

What is Scope?

Scope defines where a variable or function can be accessed in a program.

In simple words:

Scope tells us from which part of the program a variable or function is visible and can be used.

If a variable is outside its scope, it cannot be accessed.

Real-Life Analogy

Imagine a classroom.

  • A student's notebook can only be used by that student.
  • A classroom whiteboard can be seen by every student in the class.
  • The principal's notice board can be seen by the entire school.

Similarly in C:

  • Local Variable → Like a student's notebook (usable only inside one function/block).
  • Global Variable → Like the school's notice board (usable by all functions in the file).

Why is Scope Important?

Scope helps to:

  • Prevent name conflicts.
  • Improve program organization.
  • Protect variables from accidental modification.
  • Reduce memory misuse.
  • Improve readability and debugging.

Types of Scope in C

There are 4 main types of scope in C.

Scope
│
├── Local Scope
├── Global Scope (File Scope)
├── Block Scope
└── Function Scope

1. Local Scope

A variable declared inside a function is called a local variable.

It can be used only inside that function.

Example

#include <stdio.h>

int main()
{
    int age = 20;

    printf("%d", age);

    return 0;
}

Output

20

Memory

main()

┌──────────────────┐
│ age = 20         │
└──────────────────┘

Outside main(), age does not exist.

Wrong Example

#include <stdio.h>

void display()
{
    printf("%d", age);
}

int main()
{
    int age = 20;

    display();

    return 0;
}

Error

'age' undeclared

Reason:

age belongs only to main().

2. Global Scope (File Scope)

Variables declared outside all functions are called global variables.

They are accessible from any function in the same source file after their declaration.

Example

#include <stdio.h>

int age = 20;

void display()
{
    printf("%d\n", age);
}

int main()
{
    printf("%d\n", age);

    display();

    return 0;
}

Output

20
20

Memory

Global Memory

┌────────────────────┐
│ age = 20           │
└────────────────────┘

        │
        ├────────► main()
        │
        └────────► display()

3. Block Scope

Variables declared inside a pair of braces {} exist only inside that block.

Example

#include <stdio.h>

int main()
{
    if(1)
    {
        int x = 100;

        printf("%d\n", x);
    }

    return 0;
}

Output

100

Wrong Example

#include <stdio.h>

int main()
{
    if(1)
    {
        int x = 100;
    }

    printf("%d", x);

    return 0;
}

Error

'x' undeclared

Reason:

x exists only inside the if block.

Block Scope in Loops

Variables declared inside a loop also have block scope.

#include <stdio.h>

int main()
{
    for(int i = 1; i <= 3; i++)
    {
        printf("%d ", i);
    }

    return 0;
}

Output

1 2 3

After the loop ends, i is no longer accessible.

4. Function Scope

Function labels (used with goto) have function scope.

Example

#include <stdio.h>

int main()
{
    goto end;

    printf("Hello");

end:
    printf("Finished");

    return 0;
}

Output

Finished

The label end is accessible only within the same function.

Variable Visibility

Scope determines visibility.

Example

#include <stdio.h>

int x = 10;

void show()
{
    printf("%d\n", x);
}

int main()
{
    printf("%d\n", x);

    show();

    return 0;
}

Both functions can see x.

Local vs Global Scope

Local Scope Global Scope
Declared inside a functionDeclared outside all functions
Accessible only within that functionAccessible throughout the file
Temporary lifetime (during function execution)Exists for the entire program execution
Example: int age; inside main()Example: int age; outside all functions

Variable Shadowing

A local variable can have the same name as a global variable.

The local variable shadows (hides) the global variable within its scope.

Example

#include <stdio.h>

int number = 100;

int main()
{
    int number = 50;

    printf("%d", number);

    return 0;
}

Output

50

Memory

Global Variable

number = 100

↓

main()

number = 50

Inside main(), the local number is used.

Nested Block Scope

#include <stdio.h>

int main()
{
    int a = 10;

    {
        int b = 20;

        printf("%d %d\n", a, b);
    }

    printf("%d", a);

    return 0;
}

Output

10 20
10

Explanation:

  • a is visible in the inner block.
  • b is not visible outside the inner block.

Scope vs Lifetime

Many beginners confuse these two concepts.

Scope Lifetime
Where a variable can be accessedHow long the variable exists in memory
Compile-time conceptRuntime concept

Example

int main()
{
    int x = 10;

    return 0;
}
  • Scope: Only inside main()
  • Lifetime: From entering main() until it finishes execution.

Note: Lifetime will be discussed in more detail when studying Storage Classes.

Common Beginner Mistakes

1. Accessing Local Variables Outside Their Scope

Wrong

int main()
{
    int x = 10;
}

printf("%d", x);

Error:

'x' undeclared

2. Using Block Variables Outside the Block

Wrong

if(1)
{
    int marks = 90;
}

printf("%d", marks);

3. Confusing Global and Local Variables

int x = 100;

int main()
{
    int x = 50;

    printf("%d", x);
}

Output

50

The local variable hides the global one.

4. Declaring Variables in the Wrong Scope

Poor

int total;

int main()
{
}

If total is used only inside main(), it should be declared there instead of globally.

Interview Questions

1. What is scope in C?

Scope defines the region of a program where a variable or function can be accessed.

2. What is the difference between local and global scope?

  • Local scope: Accessible only within the function or block where declared.
  • Global scope: Accessible throughout the source file after its declaration.

3. What is block scope?

A variable declared inside {} is accessible only within that block.

4. What is variable shadowing?

Variable shadowing occurs when a local variable has the same name as a global variable, causing the local variable to hide the global one within its scope.

5. What is the difference between scope and lifetime?

  • Scope determines where a variable can be accessed.
  • Lifetime determines how long the variable exists in memory.

Summary

  • Scope defines where a variable or function can be accessed.
  • C provides four main scopes:
    • Local Scope
    • Global (File) Scope
    • Block Scope
    • Function Scope
  • Local variables are accessible only within their function or block.
  • Global variables are accessible throughout the source file after their declaration.
  • Variable shadowing occurs when a local variable hides a global variable with the same name.
  • Scope and lifetime are different concepts: scope is about visibility, while lifetime is about existence in memory.
