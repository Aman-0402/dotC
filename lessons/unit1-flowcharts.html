Flowcharts

A Flowchart is a graphical (diagrammatic) representation of an algorithm. Instead of writing steps in words, we use standard symbols connected by arrows to show the flow of a program.

It helps us understand the logic of a program visually.

What is a Flowchart?

Definition:

A Flowchart is a diagram that represents the sequence of steps in solving a problem using standard symbols connected by arrows.

A flowchart shows:

  • Where the program starts
  • What operations are performed
  • What decisions are made
  • Where the program ends

Why Use Flowcharts?

  • Easy to understand.
  • Helps in planning before coding.
  • Makes debugging easier.
  • Shows program logic visually.
  • Improves communication among programmers.

Common Flowchart Symbols

1. Terminator (Start / Stop)

Used to indicate the beginning and end of a program.

Shape: Oval

   _________
 /         \
|  START    |
 \_________/

OR

   _________
 /         \
|   STOP    |
 \_________/

2. Process

Used for calculations or assignments.

Shape: Rectangle

+----------------+
| SUM = A + B    |
+----------------+

Examples:

  • Area = L × W
  • Total = A + B
  • Count = Count + 1

3. Input / Output

Used for taking input or displaying output.

Shape: Parallelogram

  /--------------/
 / INPUT A      /
/--------------/

Examples:

  • Read Number
  • Print Result

4. Decision

Used for checking conditions.

Shape: Diamond

      /\
     /  \
    < A>B? >
     \  /
      \/

It has two possible paths:

  • Yes (True)
  • No (False)

Example:

Marks >= 40 ?

5. Flow Line

Shows the direction of execution.

↓
↑
→
←

6. Connector

Used to connect different parts of a flowchart.

Shape: Small Circle

 (A)

Useful when the flowchart becomes too large.

Summary of Symbols

Symbol Shape Purpose

Example 4: Pass or Fail

Condition

If Marks >= 40
Pass
Else
Fail

Flowchart

             (START)
                 │
                 ▼
        / Input Marks /
                 │
                 ▼
            ◇ Marks ≥ 40? ◇
             /           \
          Yes             No
           │               │
           ▼               ▼
    / Print PASS /   / Print FAIL /
           │               │
            \             /
             \           /
                 ▼
              (STOP)

Notice the Decision Symbol (Diamond) creates two different paths.

Rules for Drawing Flowcharts

  • Start with START and end with STOP.
  • Use arrows to show the direction of flow.
  • Flow should generally move from top to bottom.
  • Use standard symbols only.
  • Keep the flowchart simple and neat.
  • Every symbol should be connected properly.

Advantages of Flowcharts

  • Easy to understand.
  • Helps in finding logical errors.
  • Simplifies coding.
  • Useful for documentation.
  • Easy to modify.

Disadvantages of Flowcharts

  • Time-consuming for large programs.
  • Difficult to update if logic changes frequently.
  • Large programs produce complex flowcharts.

Key Points to Remember

  • A Flowchart is a graphical representation of an algorithm.
  • It uses standard symbols to represent different operations.
  • The Oval represents Start/Stop.
  • The Rectangle represents Processing.
  • The Parallelogram represents Input/Output.
  • The Diamond represents Decision Making.
  • Arrows show the flow of execution.
  • Flowcharts help programmers understand program logic before writing code.

Interview Questions

Q1. What is a flowchart?

Answer: A flowchart is a graphical representation of an algorithm using standard symbols connected by arrows.

Q2. Which symbol is used for decision making?

Answer: The Diamond symbol.

Q3. Which symbol is used for calculations?

Answer: The Rectangle (Process) symbol.

Q4. Why are flowcharts important?

Answer: They help visualize program logic, simplify debugging, and make coding easier.
