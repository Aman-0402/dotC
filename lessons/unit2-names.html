Names

What are Names in C?

A name is a human-readable label given to different program elements so that programmers can easily identify and use them.

In C, names are used for:

  • Variables
  • Functions
  • Arrays
  • Structures
  • Unions
  • Enums
  • Labels
  • Typedefs

A name is usually an identifier, but the term name is more general.

Definition

A name is a meaningful label given by the programmer to identify a program element.

Why Do We Need Names?

Imagine a program without names.

Instead of writing:

int studentMarks = 95;

Suppose you had to remember only memory addresses:

Memory Address: 0x7ffe5a20

That would be extremely difficult.

Names make programs:

  • Easy to read
  • Easy to write
  • Easy to debug
  • Easy to maintain

Examples of Names

int age = 20;
float salary = 50000.50;
char grade = 'A';

Names are:

  • age
  • salary
  • grade

Another example:

int add(int a, int b)
{
    return a + b;
}

Names are:

  • add
  • a
  • b

Rules for Naming

Since names are identifiers, they follow the same rules.

Rule 1

Must begin with

  • Letter
  • Underscore

Correct

student
_total

Wrong

2student

Rule 2

Digits are allowed after the first character.

Correct

student1
roll2026

Rule 3

Spaces are not allowed.

Wrong

student age

Correct

studentAge

Rule 4

Special symbols are not allowed except _.

Wrong

salary@

Correct

salary

Rule 5

Cannot use keywords.

Wrong

int if;

Correct

int marks;

Rule 6

Names are case-sensitive.

age
Age
AGE

These represent three different names.

Good Names vs Bad Names

Poor

int a;
int b;
int c;

What do these variables represent?

It is impossible to know without reading the entire program.

Better

int marks;
int age;
int salary;

Now the purpose is clear.

Best

int studentTotalMarks;

The name clearly indicates its purpose.

Naming Styles

1. camelCase (Most Common)

studentAge
totalMarks
employeeSalary

First word starts with a lowercase letter, and each following word starts with an uppercase letter.

2. snake_case

student_age
total_marks
employee_salary

Words are separated by underscores.

3. PascalCase

StudentAge
EmployeeSalary

Usually used for structure names or type names in many coding styles.

4. UPPER_CASE

Usually used for symbolic constants or macros.

#define MAX_SIZE 100

#define PI 3.14159

studentAge

Example 3

Clear and meaningful.

Example 4

int calculateArea(int length, int width)
{
    return length * width;

Meaningful names:

  • calculateArea
  • length

Bad Naming Example

#include <stdio.h>

int main()
{
    int a = 10;
    int b = 20;

    int c = a + b;

    printf("%d", c);

    return 0;
}

Works correctly, but the names do not explain their purpose.

Improved Version

#include <stdio.h>

int main()
{
    int firstNumber = 10;
    int secondNumber = 20;

    int sum = firstNumber + secondNumber;

    printf("%d", sum);

    return 0;
}

Now the code is much easier to understand.

Common Beginner Mistakes

1. Using meaningless names

Poor

int abc;

Better

int studentMarks;

2. Using keywords

Wrong

int while;

Correct

int total;

3. Using spaces

Wrong

int total marks;

Correct

int totalMarks;

4. Mixing naming styles

Avoid

studentAge
student_age
StudentAge

in the same project unless a coding standard requires it.

Instead, use one style consistently.

5. Using confusing abbreviations

Poor

int stdmrks;

Better

int studentMarks;

Best Practices

  • Use meaningful names.
  • Follow one naming convention throughout the project.
  • Avoid unnecessary abbreviations.
  • Keep names readable.
  • Use camelCase or snake_case consistently.
  • Use UPPER_CASE for macros and symbolic constants.
  • Use nouns for variables and verbs for functions.

Examples:

int studentCount;
float averageMarks;
char grade;

Function names:

calculateTotal();
printReport();
findMaximum();

Interview Questions

1. What is a name in C?

A name is a meaningful label given by the programmer to identify program elements such as variables, functions, arrays, and structures.

2. What is the difference between a name and an identifier?

  • Identifier is the technical term defined by the C language.
  • Name is a general term referring to what the programmer calls a program element.

In practice, most names in C are identifiers.

3. Why should names be meaningful?

Meaningful names improve readability, maintenance, debugging, and collaboration.

4. Which naming style is most commonly used for variables in C?

camelCase and snake_case are the most commonly used styles.

5. How should constants be named?

Constants defined using #define are commonly written in UPPER_CASE.

Example:

#define MAX_SIZE 100

Summary

  • A name is a meaningful label given to program elements.
  • All names in C follow the identifier naming rules.
  • Use descriptive and meaningful names to improve readability.
  • Follow a consistent naming convention such as camelCase or snake_case.
  • Use UPPER_CASE for macros and symbolic constants.
  • Good naming practices make programs easier to understand, debug, and maintain.
