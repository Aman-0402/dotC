File Utilities & Command Line Arguments

This topic covers some additional file handling functions used for line input/output, miscellaneous file operations, and passing arguments from the command line.

1. Line Input/Output

Line input/output functions read or write entire strings (lines) instead of single characters.

The two most commonly used functions are:

  • fgets()
  • fputs()

1.1 fgets()

Definition

The fgets() function reads an entire line (or a specified number of characters) from a file.

It stops reading when:

  • Newline (\n) is encountered
  • End of File (EOF) is reached
  • Maximum size is reached

Syntax

fgets(array, size, file_pointer);

Parameters

  • array → Character array to store data
  • size → Maximum characters to read
  • file_pointer → File to read from

Example

Suppose message.txt

Program

#include <stdio.h>

int main()
{
    FILE *fp;
    char str[100];

    fp = fopen("message.txt", "r");

    if(fp == NULL)
    {
        printf("File cannot be opened.");
        return 1;
    }

    fgets(str, sizeof(str), fp);

    printf("%s", str);

    fclose(fp);

    return 0;
}

1.2 fputs()

Definition

The fputs() function writes an entire string into a file.

Syntax

fputs(string, file_pointer);

Example

#include <stdio.h>

int main()
{
    FILE *fp;

    fp = fopen("message.txt", "w");

    fputs("Welcome to C Programming\n", fp);
    fputs("Learning File Handling", fp);

    fclose(fp);

    return 0;
}

2. Miscellaneous File Functions

Besides reading and writing, C provides several utility functions for file management.

2.1 feof()

Definition

Checks whether the End of File (EOF) has been reached.

Syntax

feof(file_pointer);

Example

#include <stdio.h>

int main()
{
    FILE *fp;
    char ch;

    fp = fopen("sample.txt","r");

    while(!feof(fp))
    {
        ch = fgetc(fp);

        if(!feof(fp))
            printf("%c", ch);
    }

    fclose(fp);

    return 0;
}

2.2 rewind()

Definition

Moves the file pointer back to the beginning of the file.

Syntax

rewind(file_pointer);

Example

FILE *fp;

fp = fopen("sample.txt","r");

/* Read data */

rewind(fp);

/* Read again from the beginning */

fclose(fp);

2.3 fflush()

Definition

The fflush() function clears the output buffer and forces buffered data to be written immediately.

Syntax

fflush(file_pointer);

Example

FILE *fp;

fp = fopen("sample.txt","w");

fprintf(fp,"Hello");

fflush(fp);

fclose(fp);

Note: Using fflush(stdin) is not standard C and should be avoided. It is supported only by some compilers.

2.4 ftell()

Definition

Returns the current position of the file pointer.

Syntax

long position;

position = ftell(file_pointer);

Example

#include <stdio.h>

int main()
{
    FILE *fp;

    fp = fopen("sample.txt","r");

    fgetc(fp);
    fgetc(fp);

    printf("%ld", ftell(fp));

    fclose(fp);

    return 0;
}

Output

2

The file pointer is currently at the third character (position 2).

2.5 fseek()

Definition

Moves the file pointer to a specified position.

Syntax

fseek(file_pointer, offset, origin);

Origin Values

Origin Meaning
SEEK_SETBeginning of file
SEEK_CURCurrent position
SEEK_ENDEnd of file

Example

FILE *fp;

fp = fopen("sample.txt","r");

fseek(fp, 5, SEEK_SET);

fclose(fp);

The file pointer moves to the 6th byte of the file.

2.6 rename()

Changes the file name.

rename("old.txt", "new.txt");

2.7 remove()

Deletes a file.

remove("old.txt");

3. Command Line Arguments

Definition

Command Line Arguments allow values to be passed to a program when it starts executing, instead of asking the user for input using scanf().

These arguments are supplied after the program name in the command prompt or terminal.

Why Use Command Line Arguments?

  • Automate program execution
  • Avoid repeated user input
  • Useful for utilities and scripts
  • Common in operating systems and Linux commands

Syntax

int main(int argc, char *argv[])
{
}

or

int main(int argc, char **argv)
{
}

Meaning of Parameters

Parameter Description
argcArgument Count
argvArgument Vector (array of strings)

Example

Suppose the program is executed as:

program.exe Aman 101 C

Then:

Index Value
argv[0]program.exe
argv[1]Aman
argv[2]101
argv[3]C
 
argc = 4

Program Example

#include <stdio.h>

int main(int argc, char *argv[])
{
    int i;

    for(i = 0; i < argc; i++)
    {
        printf("%s\n", argv[i]);
    }

    return 0;
}

Execution

program.exe Hello C Programming

Output

C
Programming

Example: Adding Two Numbers

#include <stdio.h>
#include <stdlib.h>

int main(int argc, char *argv[])
{
    int a, b;

    if(argc != 3)
    {
        printf("Usage: program number1 number2");
        return 1;
    }

    a = atoi(argv[1]);
    b = atoi(argv[2]);

    printf("Sum = %d", a + b);

    return 0;
}

Execution

program.exe 25 30

Output

Sum = 55

Here, atoi() converts the string arguments into integers.

Advantages of Command Line Arguments

  • Faster execution
  • No need for interactive input
  • Useful in automation
  • Easy to pass filenames and options
  • Widely used in system programming

Real-World Applications

  • File Copy Utilities
  • Backup Programs
  • Linux Commands (cp, mv, grep)
  • Compilers (gcc)
  • Database Tools
  • Antivirus Software
  • Compression Utilities
  • Batch Processing Programs

Key Takeaways

  • fgets() reads an entire line from a file, while fputs() writes an entire string to a file.
  • feof() checks whether the end of a file has been reached.
  • rewind() resets the file pointer to the beginning of the file.
  • ftell() returns the current position of the file pointer, and fseek() moves it to a desired location.
  • fflush() forces buffered output to be written to the file immediately.
  • rename() and remove() are used to rename and delete files.
  • Command Line Arguments (argc and argv) allow programs to receive input directly from the command line, making them ideal for automation and system utilities.
