Radix Sort

Radix Sort is a non-comparison-based sorting algorithm that sorts numbers digit by digit instead of comparing entire numbers.

It processes one digit at a time, starting from either:

  • Least Significant Digit (LSD) → Rightmost digit (Most commonly used)
  • Most Significant Digit (MSD) → Leftmost digit

In this chapter, we will study the LSD Radix Sort, which uses Counting Sort as a subroutine.

What is Radix Sort?

Unlike Bubble Sort or Quick Sort, Radix Sort does not compare numbers directly.

Instead, it:

  1. Sorts the numbers based on the units digit.
  2. Then sorts based on the tens digit.
  3. Then sorts based on the hundreds digit.
  4. Continues until the highest place value is processed.

Since Counting Sort is stable, the order established in earlier passes is preserved.

C Program

#include <stdio.h>

int getMax(int arr[], int n)
{
    int max = arr[0];

    for(int i = 1; i < n; i++)
        if(arr[i] > max)
            max = arr[i];

    return max;
}

void countingSort(int arr[], int n, int exp)
{
    int output[n];
    int count[10] = {0};

    for(int i = 0; i < n; i++)
        count[(arr[i] / exp) % 10]++;

    for(int i = 1; i < 10; i++)
        count[i] += count[i - 1];

    for(int i = n - 1; i >= 0; i--)
    {
        output[count[(arr[i] / exp) % 10] - 1] = arr[i];
        count[(arr[i] / exp) % 10]--;
    }

    for(int i = 0; i < n; i++)
        arr[i] = output[i];
}

void radixSort(int arr[], int n)
{
    int max = getMax(arr, n);

    for(int exp = 1; max / exp > 0; exp *= 10)
        countingSort(arr, n, exp);
}

int main()
{
    int arr[] = {170, 45, 75, 90, 802, 24, 2, 66};
    int n = sizeof(arr) / sizeof(arr[0]);

    radixSort(arr, n);

    printf("Sorted Array:\n");

    for(int i = 0; i < n; i++)
        printf("%d ", arr[i]);

    return 0;
}

Counting Sort

Each digit is sorted using Counting Sort, which must be stable to preserve the ordering established in previous passes.

Time Complexity

CaseComplexity
Best CaseO(d × (n + k))
Average CaseO(d × (n + k))
Worst CaseO(d × (n + k))

Where:

  • n = Number of elements
  • d = Number of digits in the largest number
  • k = Base (10 for decimal numbers)

For decimal integers, k = 10, so the complexity is often simplified to O(d × n).

Space Complexity

O(n + k)

Additional space is required for the output array and the count array.

Advantages

  • Faster than comparison-based sorting for suitable datasets.
  • Stable sorting algorithm.
  • Does not compare elements directly.
  • Efficient when the number of digits is small.

Disadvantages

  • Works mainly for integers (or fixed-length strings with suitable adaptations).
  • Requires extra memory.
  • Not suitable when numbers have a very large number of digits.
  • More complex to implement than simple sorting algorithms.

Applications

  • Sorting large collections of integers.
  • Postal code sorting.
  • Employee ID sorting.
  • Student roll number sorting.
  • Telephone number sorting.
  • Used in systems where keys have a fixed number of digits.

Key Points to Remember

  • Radix Sort is a non-comparison-based sorting algorithm.
  • It sorts numbers digit by digit.
  • LSD (Least Significant Digit) Radix Sort starts from the rightmost digit.
  • It uses Counting Sort as a stable subroutine.
  • Time Complexity: O(d × (n + k)).
  • Space Complexity: O(n + k).
  • Best suited for sorting large collections of integers with a limited number of digits.
