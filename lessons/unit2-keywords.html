Keywords

What are Keywords?

Keywords are reserved words in C that have predefined meanings. These words are part of the C language itself, so the compiler understands them and uses them for specific purposes.

Since keywords are reserved, they cannot be used as identifiers (such as variable names, function names, or array names).

Definition

A keyword is a reserved word in C with a predefined meaning that cannot be used as an identifier.

Why are Keywords Important?

Keywords tell the compiler what action to perform.

Examples:

  • int → Declares an integer variable.
  • if → Makes a decision.
  • for → Creates a loop.
  • return → Returns a value from a function.

Without keywords, the compiler would not understand the structure or logic of a C program.

Number of Keywords in C

The ANSI C (C89/C90) standard defines 32 keywords.

Modern C standards (such as C99, C11, C17, and C23) introduce additional keywords. However, for most academic syllabi and interviews, the original 32 ANSI C keywords are the primary focus.

Categories of Keywords

1. Data Type Keywords

Used to declare variables.

int age;
char grade;
float salary;
double pi;
void display();
Keyword Purpose
intInteger
charCharacter
floatDecimal number
doubleHigh-precision decimal
voidNo value or return type

2. Decision-Making Keywords

Used to make decisions.

if (marks >= 40)
{
    printf("Pass");
}
else
{
    printf("Fail");
}

Keywords used:

  • if
  • else

3. Loop Keywords

Used for repetition.

for Loop

for(int i = 1; i <= 5; i++)
{
    printf("%d ", i);
}

Output:

1 2 3 4 5

while Loop

int i = 1;

while(i <= 5)
{
    printf("%d ", i);
    i++;
}

Output:

1 2 3 4 5

do-while Loop

int i = 1;

do
{
    printf("%d ", i);
    i++;
} while(i <= 5);

Output:

1 2 3 4 5

4. Jump Keywords

break

Stops the loop immediately.

for(int i = 1; i <= 10; i++)
{
    if(i == 5)
        break;

    printf("%d ", i);
}

Output:

1 2 3 4

continue

Skips the current iteration.

for(int i = 1; i <= 5; i++)
{
    if(i == 3)
        continue;

    printf("%d ", i);
}

Output:

1 2 4 5

return

Ends a function and optionally returns a value.

int main()
{
    return 0;
}

goto

Transfers control to a labeled statement.

#include <stdio.h>

int main()
{
    goto end;

    printf("This will not execute.\n");

end:
    printf("Program Finished.");

    return 0;
}

Output:

Program Finished.

Note: goto is valid in C but is generally avoided because it can make programs harder to read and maintain.

5. Storage Class Keywords

These control the lifetime and visibility of variables.

Keyword Purpose
autoLocal variable (default)
registerSuggest storing variable in CPU register
staticPreserve value between function calls
externVariable defined in another file or scope

These will be covered in detail in the Storage Classes topic.

6. User-Defined Type Keywords

struct

Groups related variables.

struct Student
{
    int id;
    char grade;
};

union

Members share the same memory.

union Data
{
    int i;
    float f;
};

enum

Defines a set of named integer constants.

enum Day
{
    MON,
    TUE,
    WED
};

typedef

Creates an alias for an existing type.

typedef int Number;

Number age = 20;

Equivalent to:

int age = 20;

Example Program Using Keywords

#include <stdio.h>

int main()
{
    int age = 18;

    if(age >= 18)
    {
        printf("Eligible to Vote");
    }
    else
    {
        printf("Not Eligible");
    }

    return 0;
}

Keywords used:

  • #include (preprocessor directive, not a keyword)
  • int
  • if
  • else
  • return

Output:

Eligible to Vote

Rules About Keywords

Rule 1

Keywords cannot be used as variable names.

❌ Wrong

int if = 10;

✅ Correct

int number = 10;

Rule 2

Keywords are case-sensitive.

int age;

Correct.

Int age;

Wrong (Int is not a keyword).

Rule 3

The spelling of a keyword cannot be changed.

❌ Wrong

Float salary;

✅ Correct

float salary;

Common Beginner Mistakes

Mistake 1

Using keywords as identifiers.

int while;

Error: while is a keyword.

Mistake 2

Incorrect capitalization.

Int marks;

Should be:

int marks;

Mistake 3

Misspelling keywords.

retrun 0;

Correct:

return 0;

Interview Questions

1. What is a keyword in C?

A keyword is a reserved word with a predefined meaning that cannot be used as an identifier.

2. How many keywords are there in ANSI C?

There are 32 keywords in ANSI C.

3. Can keywords be used as variable names?

No. Keywords are reserved by the language and cannot be used as identifiers.

4. Is printf a keyword?

No. printf is a library function declared in <stdio.h>.

5. Is main a keyword?

No. main is a function name chosen by convention as the program's entry point; it is not a C keyword.

Key Takeaways

  • Keywords are reserved words with predefined meanings.
  • ANSI C contains 32 standard keywords.
  • Keywords cannot be used as identifiers.
  • They are case-sensitive.
  • Keywords define data types, loops, conditions, storage classes, and user-defined types.
