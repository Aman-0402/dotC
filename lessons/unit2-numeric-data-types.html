Numeric Data Types

Numeric Data Types are used to store numbers. They are among the most frequently used data types in C because most programs perform mathematical calculations.

What are Numeric Data Types?

A Numeric Data Type is a data type that stores numerical values.

These values may be:

  • Whole numbers (Integers)
  • Decimal numbers (Floating-point numbers)

Definition

Numeric data types are data types that store numbers and allow arithmetic operations such as addition, subtraction, multiplication, and division.

Why Do We Need Numeric Data Types?

Imagine a program for a school.

You need to store:

  • Student Age → 20
  • Marks → 95
  • Height → 172.5
  • Salary → 45000.75

All of these are numbers, but not all are the same kind of number.

That's why C provides different numeric data types.

float
double
long double

They differ mainly in:

  • Range

Choosing the Correct Numeric Type

Store Student Age

int age = 20;

Good choice because age is a whole number.

Store Salary

float salary = 25000.50;

Good because salary includes decimals.

Scientific Calculation

double pi = 3.141592653589793;

Better than float because it provides higher precision.

Large Population Count

long long population = 1450000000;

Suitable for very large integer values.

Common Beginner Mistakes

1. Using int for Decimal Numbers

Wrong

int price = 99.95;

Stored value

99

The fractional part is discarded.

Correct

float price = 99.95;

2. Using float for High Precision

Wrong

float pi = 3.141592653589793;

Much of the precision is lost.

Better

double pi = 3.141592653589793;

3. Using unsigned for Negative Values

Wrong

unsigned int temperature = -20;

This produces unexpected results because unsigned types cannot represent negative numbers.

4. Assuming Sizes Are Fixed

Avoid assuming:

int = 4 bytes
long = 8 bytes

These sizes depend on the platform. Use sizeof() when exact sizes matter.

Interview Questions

1. What are numeric data types?

Numeric data types store numerical values and support arithmetic operations.

2. What are the two main categories of numeric data types?

  • Integer data types
  • Floating-point data types

3. What is the difference between int and float?

int float
Stores whole numbersStores decimal numbers
No fractional partFractional part allowed
Exact integer representationLimited decimal precision

4. Why is double more accurate than float?

double uses more memory (typically 8 bytes), allowing it to store more significant digits.

5. What is the purpose of unsigned?

unsigned allows only non-negative values, increasing the maximum positive range for the same memory size.

Q3. Demonstrate precision.

#include <stdio.h>

int main()
{
    float f = 3.141592653589793f;
    double d = 3.141592653589793;

    printf("Float  : %.15f\n", f);
    printf("Double : %.15lf\n", d);

    return 0;
}

Sample Output

Float  : 3.141592741012573
Double : 3.141592653589793

Notice that double retains much more precision than float.

Exam Tips

  • ⭐ Numeric data types are divided into Integer and Floating-Point types.
  • ⭐ Use int for whole numbers and float/double for decimal numbers.
  • ⭐ double provides higher precision than float.
  • ⭐ unsigned types cannot represent negative values.
  • ⭐ Use sizeof() to check the actual size of a type on your system.

Summary

  • Numeric data types store numerical values used in calculations.
  • They are divided into Integer (short, int, long, long long) and Floating-Point (float, double, long double) types.
  • Choose the data type based on the kind of value, required range, and precision.
  • double is preferred over float when higher accuracy is required.
  • Always remember that the exact size of a numeric type is implementation-dependent.
