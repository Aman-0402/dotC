Structures & Unions

Structures and unions are user-defined data types in C that allow programmers to group multiple variables under a single name. They help organize related data and make programs more structured and easier to manage.

Although structures and unions appear similar, they differ in how memory is allocated and used.

1. User-defined Structure

Definition

A structure (struct) is a user-defined data type that groups variables of different data types into a single unit.

Instead of storing related information in separate variables, a structure stores them together.

Real-Life Example

Consider student information.

Instead of writing:

char name[30];
int roll;
float marks;
char grade;

We can combine them into one structure.

struct Student
{
    char name[30];
    int roll;
    float marks;
    char grade;
};

Now all student-related information belongs to one data type.

Why Use Structures?

  • Store related information together.
  • Makes code organized.
  • Easy to pass data to functions.
  • Represents real-world objects.
  • Used in databases, file handling, linked lists, trees, etc.

Syntax

struct StructureName
{
    data_type member1;
    data_type member2;
    data_type member3;
};

Example

struct Employee
{
    int id;
    char name[30];
    float salary;
};

Declaring Structure Variables

After defining the structure, create variables.

struct Employee emp1;

Multiple variables:

struct Employee emp1, emp2, emp3;

Initializing Structure

struct Employee emp1 =
{
    101,
    "Rahul",
    45000.50
};

Accessing Members

Use the dot (.) operator.

emp1.id
emp1.name
emp1.salary

Example

printf("%d", emp1.id);
printf("%s", emp1.name);
printf("%.2f", emp1.salary);

Taking Input

#include <stdio.h>

struct Student
{
    int roll;
    char name[30];
    float marks;
};

int main()
{
    struct Student s;

    printf("Enter Roll: ");
    scanf("%d", &s.roll);

    printf("Enter Name: ");
    scanf("%s", s.name);

    printf("Enter Marks: ");
    scanf("%f", &s.marks);

    printf("\nStudent Details\n");
    printf("Roll : %d\n", s.roll);
    printf("Name : %s\n", s.name);
    printf("Marks: %.2f\n", s.marks);

    return 0;
}

Output

Enter Roll: 101
Enter Name: Aman
Enter Marks: 92.5

Student Details
Roll : 101
Name : Aman
Marks: 92.50

Memory Allocation in Structure

Each member gets its own memory.

Example

struct Demo
{
    int a;
    float b;
    char c;
};

Approximate memory

a -> 4 Bytes

b -> 4 Bytes

c -> 1 Byte

Total ≈ 12 Bytes (including padding)

Each member exists independently.

Array of Structures

Useful for storing multiple records.

struct Student
{
    int roll;
    char name[30];
};

struct Student s[50];

Stores information of 50 students.

Nested Structure

A structure inside another structure.

struct Address
{
    char city[30];
    int pin;
};

struct Student
{
    char name[30];
    int roll;
    struct Address add;
};

Access members

student.add.city
student.add.pin

Structure Example

#include <stdio.h>

struct Book
{
    int id;
    char title[40];
    float price;
};

int main()
{
    struct Book b =
    {
        1,
        "C Programming",
        499.50
    };

    printf("Book ID : %d\n", b.id);
    printf("Title   : %s\n", b.title);
    printf("Price   : %.2f\n", b.price);

    return 0;
}

Advantages of Structures

  • Organizes related data.
  • Supports arrays of records.
  • Supports nested structures.
  • Easy to maintain.
  • Widely used in real-world software.

Limitations

  • Members occupy separate memory.
  • Arithmetic operations cannot be performed directly on structures.
  • Requires dot operator for member access.

2. Union

Definition

A union (union) is a user-defined data type similar to a structure, but all members share the same memory location.

Only one member can hold a meaningful value at a time because writing to one member overwrites the others.

Syntax

union UnionName
{
    data_type member1;
    data_type member2;
};

Example

union Data
{
    int i;
    float f;
    char str[20];
};

Declaring Union Variable

union Data d;

Accessing Members

Use the dot operator.

d.i
d.f
d.str

Example

#include <stdio.h>

union Data
{
    int i;
    float f;
};

int main()
{
    union Data d;

    d.i = 100;
    printf("Integer = %d\n", d.i);

    d.f = 5.5;
    printf("Float = %.2f\n", d.f);

    printf("Integer after storing float = %d\n", d.i);

    return 0;
}

Possible Output

Integer = 100
Float = 5.50
Integer after storing float = 1085276160

The integer value changes because both members share the same memory.

Memory Allocation in Union

union Demo
{
    int a;
    float b;
    char c;
};

Memory

int   -> 4 Bytes
float -> 4 Bytes
char  -> 1 Byte

Total Memory = 4 Bytes

The union size is determined by its largest member (plus any alignment requirements).

Structure vs Union

Feature Structure Union
Memory AllocationSeparate memory for each memberShared memory for all members
Total SizeSum of member sizes (plus padding)Size of the largest member
Simultaneous ValuesAll members can store values at the same timeOnly one member can store a meaningful value at a time
Memory EfficiencyLowerHigher
Data SafetyBetterLower, as members overwrite each other
Use CaseRecords (students, employees, books)Memory optimization, hardware interfaces, embedded systems

Dry Run (Union)

union Data
{
    int i;
    float f;
};

union Data d;

Step 1

d.i = 25;

Memory

+---------+
|   25    |
+---------+

Step 2

d.f = 6.75;

Memory

+---------+
| 6.75    |
+---------+

The previous integer value (25) is overwritten because both members occupy the same memory location.

Applications of Structures

  • Student Management System
  • Employee Database
  • Library Management
  • Banking Software
  • Inventory System
  • Hospital Management
  • Linked Lists
  • Trees
  • Graphs

Applications of Unions

  • Memory optimization
  • Embedded systems
  • Device drivers
  • Hardware register mapping
  • Communication protocols
  • Low-level system programming

Key Takeaways

  • Structure stores multiple related variables, with each member having its own memory.
  • Union stores different data types in the same memory location, saving memory.
  • Structures are ideal for managing records and real-world entities.
  • Unions are useful when memory efficiency is more important and only one member is needed at a time.
  • Both struct and union are user-defined data types and are widely used in C programming.
