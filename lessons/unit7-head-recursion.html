Head Recursion

What is Head Recursion?

Head Recursion is a type of recursion in which the recursive function call is the first operation performed.

After the recursive call returns, the function performs the remaining operations.

Definition: A recursive function is called Head Recursive if the recursive call occurs before any other processing.

General Structure

returnType function(parameters)
{
    if(base_condition)
        return;

    function(smaller_problem);

    // Work is done after recursion
}

The important rule is:

Recursive Call

↓

Return

↓

Remaining Work

Real-Life Analogy

Imagine climbing a ladder.

Ground

↓

Step 1

↓

Step 2

↓

Step 3

↓

Top

While climbing, you don't do any work.

Only after reaching the top do you start coming down and perform work on each step.

This is exactly how Head Recursion works.

Example 1: Print Numbers (1 to 5)

#include <stdio.h>

void print(int n)
{
    if(n == 0)
        return;

    print(n - 1);

    printf("%d ", n);
}

int main()
{
    print(5);

    return 0;
}

Output

1 2 3 4 5

Why is it Head Recursive?

Notice:

print(n - 1);

printf("%d ", n);

The recursive call happens first.

The printf() statement executes after the recursive call returns.

Therefore, this is Head Recursion.

Example 2: Print Characters

#include <stdio.h>

void display(char ch)
{
    if(ch > 'E')
        return;

    display(ch + 1);

    printf("%c ", ch);
}

{

    return 0;

Example 3: Sum of N Numbers (Head Recursive)

#include <stdio.h>

int sum(int n)
{
    if(n == 0)
        return 0;

    int s = sum(n - 1);

    return s + n;
}

int main()
{
    printf("%d", sum(5));

    return 0;
}

Output

15

The addition (s + n) is performed after the recursive call returns, making it head recursive.

Head Recursion vs Tail Recursion

Feature Head Recursion Tail Recursion
Recursive callFirst operationLast operation
Work after recursionYesNo
Output generatedWhile returningWhile calling
Tail Call OptimizationNot possiblePossible (compiler dependent)
Loop conversionDifficultEasier

Example Comparison

Head Recursion

void fun(int n)
{
    if(n == 0)
        return;

    fun(n - 1);

    printf("%d ", n);
}

Output:

1 2 3 4 5

Tail Recursion

void fun(int n)
{
    if(n == 0)
        return;

    printf("%d ", n);

    fun(n - 1);
}

Output:

5 4 3 2 1

Advantages

  • Simple way to process data after recursive calls complete.
  • Useful when results from smaller subproblems are needed before further computation.
  • Natural for algorithms that build results while returning from recursion.

Disadvantages

  • Cannot benefit from Tail Call Optimization.
  • Uses more stack memory for deep recursion.
  • Often slower than equivalent iterative solutions.

Applications

  • Tree traversals (Postorder Traversal).
  • Recursive mathematical computations.
  • Building results after recursive calls.
  • Expression evaluation.
  • Divide and Conquer algorithms.

Key Points to Remember

  • In Head Recursion, the recursive call happens before any processing.
  • The actual work is performed while the function returns.
  • Head recursion cannot be optimized using Tail Call Optimization.
  • The output often appears in the reverse order of the recursive calls.
  • It is useful when later computation depends on results from deeper recursive calls.
