Constants

What are Constants?

A constant is a fixed value that cannot be changed during program execution.

Unlike variables, whose values can change, constants always remain the same.

Definition

A constant is a fixed value that does not change during the execution of a program.

Variable vs Constant

Variable Constant
Value can change Value cannot change
Stored in memory Also stored in memory (if declared using const) or embedded directly in code (literals)
Example: age = 20; Example: 3.14, 'A', "Hello"

Example:

int age = 20;

age = 25;      // Allowed
const int age = 20;

age = 25;      // Error

Types of Constants in C

There are five major types of constants.

Constants
│
├── Integer Constants
├── Floating-Point Constants
├── Character Constants
├── String Constants (String Literals)
└── Enumeration Constants

We'll also cover Symbolic Constants (#define) and the const keyword, which are commonly used in real programs.

1. Integer Constants

Integer constants are whole numbers without a decimal point.

Examples:

10
250
-45
0
9999

Program:

#include <stdio.h>

int main()
{
    printf("%d", 100);

    return 0;
}

Output

100

Integer Constant Formats

Decimal (Base 10)

25
100
500

Octal (Base 8)

Starts with 0.

025
012

Example:

int x = 025;

025 (octal) equals 21 in decimal.

Hexadecimal (Base 16)

Starts with 0x or 0X.

0x1A
0XFF

Example:

int x = 0xA;

0xA equals 10 in decimal.

2. Floating-Point Constants

Floating-point constants contain decimal values.

Examples:

3.14
0.5
100.25
-45.67

Program

#include <stdio.h>

int main()
{
    float pi = 3.14;

    printf("%.2f", pi);

    return 0;
}

Output

3.14

Scientific Notation

Large or very small numbers can be written using exponential notation.

3.5e2

Means:

3.5 × 10² = 350

Another example

1.2e-3

Means

0.0012

3. Character Constants

A character constant contains exactly one character enclosed in single quotes.

Examples

'A'
'B'
'7'
'#'

Program

#include <stdio.h>

int main()
{
    char grade = 'A';

    printf("%c", grade);

    return 0;
}

Output

A

ASCII Representation

Every character has an ASCII value.

Example

'A'

ASCII value:

65

Program

#include <stdio.h>

int main()
{
    char ch = 'A';

    printf("%d", ch);

    return 0;
}

Output

65

Escape Character Constants

Escape sequences begin with a backslash (\).

Escape Sequence Meaning
\nNew line
\tHorizontal tab
\\Backslash
\"Double quote
\'Single quote
\rCarriage return
\bBackspace
\0Null character

Example

printf("Hello\nWorld");

Output

Hello
World

4. String Constants (String Literals)

A string is a sequence of characters enclosed in double quotes.

Examples

"Hello"
"India"
"C Programming"

Program

#include <stdio.h>

int main()
{
    printf("Welcome");

    return 0;
}

Output

Welcome

Character vs String

Character String
'A'"A"
Single quotesDouble quotes
One characterOne or more characters
Type: charStored as an array of char ending with '\0'

Example

char ch = 'A';
char name[] = "Aman";

5. Enumeration Constants

Enumeration constants are defined using enum.

Example

enum Day
{
    MON,
    TUE,
    WED
};

Here,

  • MON
  • TUE
  • WED

are enumeration constants.

By default:

MON = 0
TUE = 1
WED = 2

Symbolic Constants (#define)

A symbolic constant is created using the preprocessor directive #define.

Syntax

#define NAME value

Example

#define PI 3.14159

Program

#include <stdio.h>

#define PI 3.14159

int main()
{
    printf("%.5f", PI);

    return 0;
}

Output

3.14159

Note: #define performs text substitution before compilation.

Constants Using const

The const keyword creates a variable whose value cannot be modified after initialization.

Syntax

const data_type variable = value;

Example

const int MAX = 100;

Program

#include <stdio.h>

int main()
{
    const int MAX = 100;

    printf("%d", MAX);

    return 0;
}

Output

100

Attempting to modify it:

MAX = 200;

Results in a compilation error.

const vs #define

const #define
Creates a typed constantPerforms text substitution
Type checked by compilerNo type checking
Occupies memory (typically)Does not allocate memory for the macro itself
Can have an addressCannot have an address

Example

const float PI = 3.14;
#define PI 3.14

Real-World Example

#include <stdio.h>

#define PASS_MARKS 40

int main()
{
    int marks = 55;

    if(marks >= PASS_MARKS)
        printf("Pass");
    else
        printf("Fail");

    return 0;
}

Output

Pass

Using symbolic constants makes code easier to update. If the pass mark changes, you only need to modify one line.

Common Beginner Mistakes

1. Using Double Quotes for a Character

❌ Wrong

char grade = "A";

✅ Correct

char grade = 'A';

2. Using Single Quotes for a String

❌ Wrong

printf('Hello');

✅ Correct

printf("Hello");

3. Modifying a const Variable

❌ Wrong

const int MAX = 100;

MAX = 200;

Compilation error.

4. Forgetting the Value in #define

❌ Wrong

#define PI

✅ Correct

#define PI 3.14

5. Forgetting the Null Terminator Concept

A string in C is automatically terminated with '\0'.

char name[] = "Aman";

Memory:

+-----+-----+-----+-----+------+
| 'A' | 'm' | 'a' | 'n' | '\0' |
+-----+-----+-----+-----+------+

Interview Questions

1. What is a constant?

A constant is a fixed value that does not change during program execution.

2. What is the difference between a variable and a constant?

A variable can change its value, while a constant retains the same value throughout program execution.

3. What is the difference between 'A' and "A"?

'A' "A"
Character constantString literal
Single characterTwo characters in memory: 'A' and '\0'

4. What is the difference between const and #define?

  • const creates a typed constant checked by the compiler.
  • #define creates a macro using preprocessor text substitution.

5. What are escape sequences?

Escape sequences are special character combinations beginning with \ that represent non-printable or special characters such as newline (\n) and tab (\t).

Summary

  • A constant is a fixed value that cannot change during program execution.
  • The main types are integer, floating-point, character, string, and enumeration constants.
  • Character constants use single quotes (' ').
  • String literals use double quotes (" ").
  • Escape sequences represent special characters like \n and \t.
  • #define creates symbolic constants through preprocessor substitution.
  • const creates typed constants that the compiler protects from modification.
