Singly Linked List – Traversal

Once a linked list is created, the first operation we usually perform is Traversal.

Traversal means visiting each node of the linked list exactly once to perform some operation such as:

  • Displaying data
  • Counting nodes
  • Finding the sum
  • Searching for an element
  • Finding the maximum or minimum value

Traversal is one of the most fundamental operations because almost every other linked list operation relies on it.

What is Traversal?

Traversal is the process of moving from the first node (head) to the last node (NULL) by following the next pointers.

Suppose we have the following linked list:

Head
 ↓
10 → 20 → 30 → 40 → NULL

Traversal visits the nodes in this order:

10
 ↓
20
 ↓
30
 ↓
40
 ↓
NULL

How Traversal Works

Instead of moving the head pointer, we create a temporary pointer.

struct Node *temp;

Initialize it with the head node.

temp = head;

Now move until NULL.

temp
 ↓
10 → 20 → 30 → 40 → NULL

Move one step.

Head
 ↓
10 → 20 → 30 → 40 → NULL
      ↑
     temp

Again.

Head
 ↓
10 → 20 → 30 → 40 → NULL
           ↑
          temp

Continue until:

Head
 ↓
10 → 20 → 30 → 40 → NULL
                      ↑
                     temp

When temp == NULL, traversal stops.

C Program for Traversal

#include <stdio.h>
#include <stdlib.h>

struct Node
{
    int data;
    struct Node *next;
};

int main()
{
    struct Node *head, *second, *third;
    struct Node *temp;

    head = (struct Node *)malloc(sizeof(struct Node));
    second = (struct Node *)malloc(sizeof(struct Node));
    third = (struct Node *)malloc(sizeof(struct Node));

    head->data = 10;
    head->next = second;

    second->data = 20;
    second->next = third;

    third->data = 30;
    third->next = NULL;

    temp = head;

    while(temp != NULL)
    {
        printf("%d ", temp->data);
        temp = temp->next;
    }

    free(head);
    free(second);
    free(third);

    return 0;
}

Output

10 20 30

Using a Function

Traversal is usually implemented as a separate function.

void display(struct Node *head)
{
    struct Node *temp = head;

    while(temp != NULL)
    {
        printf("%d ", temp->data);
        temp = temp->next;
    }
}

Calling it:

display(head);

Traversal Using for Loop

for(struct Node *temp = head; temp != NULL; temp = temp->next)
{
    printf("%d ", temp->data);
}

This is shorter but performs the same traversal.

Recursive Traversal

A linked list can also be traversed recursively.

void display(struct Node *head)
{
    if(head == NULL)
        return;

    printf("%d ", head->data);

    display(head->next);
}

Applications of Traversal

Traversal is used to:

  • Display all nodes
  • Count total nodes
  • Find the sum of all elements
  • Find the maximum or minimum value
  • Search for a specific value
  • Copy a linked list
  • Reverse a linked list (as part of the algorithm)

Common Mistakes

1. Moving the head Pointer

❌ Wrong

while(head != NULL)
{
    printf("%d ", head->data);
    head = head->next;
}

After this loop, head becomes NULL, and the original starting address is lost.

✔ Correct

struct Node *temp = head;

Use a temporary pointer for traversal.

2. Forgetting to Move the Pointer

❌ Wrong

while(temp != NULL)
{
    printf("%d ", temp->data);
}

The pointer never advances, causing an infinite loop.

✔ Correct

temp = temp->next;

3. Incorrect Loop Condition

❌ Wrong

while(temp->next != NULL)

This skips the last node.

✔ Correct

while(temp != NULL)

Worst CaseO(n)

Space Complexity

Method Space
Iterative TraversalO(1)
Recursive TraversalO(n) (due to the call stack)

Key Takeaways

  • Traversal means visiting every node from head to NULL.
  • Always use a temporary pointer (temp) instead of modifying head.
  • Move to the next node using temp = temp->next.
  • Stop when temp == NULL.
  • Iterative traversal uses O(1) extra space, while recursive traversal uses O(n) call stack space.
  • Traversal is the basis for many linked list operations such as searching, counting, summing, and reversing.
