Identifiers

What are Identifiers?

An identifier is a name given by the programmer to program elements such as variables, functions, arrays, structures, unions, enums, labels, etc.

Identifiers make programs readable and help us refer to data or functions by meaningful names.

Definition

An identifier is a user-defined name used to identify variables, functions, arrays, structures, and other program elements in C.

Why Do We Need Identifiers?

Imagine writing a program without names.

Instead of writing:

int age = 20;

You would have to remember memory addresses, which is practically impossible.

Identifiers provide meaningful names like:

  • age
  • salary
  • totalMarks
  • calculateArea

making programs easier to understand and maintain.

Examples of Identifiers

int age;
float salary;
char grade;

Identifiers:

  • age
  • salary
  • grade

Another example:

int add(int a, int b)
{
    return a + b;
}

Identifiers are:

  • add
  • a
  • b

Rules for Naming Identifiers

There are 8 important rules.

Rule 1: Must Begin with a Letter or Underscore

✅ Correct

int age;
int _count;

❌ Wrong

int 2age;

Reason:

Identifiers cannot begin with a digit.

Rule 2: Digits Are Allowed After the First Character

✅ Correct

student1
roll2026
value100

Example

int marks2026;

Rule 3: No Spaces Allowed

❌ Wrong

student age

✅ Correct

studentAge

or

student_age

Rule 4: No Special Characters

Except _, special characters are not allowed.

❌ Wrong

salary@
marks#
student-name

✅ Correct

salary
student_name
marks1

Rule 5: Cannot Be a Keyword

❌ Wrong

int while;
int return;
int if;

✅ Correct

int number;

Rule 6: Case Sensitive

These are all different identifiers.

age
Age
AGE

Example

int age = 20;
int Age = 30;

printf("%d %d", age, Age);

Output

20 30

Rule 7: No Length Restriction (Practically)

Modern C compilers support long identifier names.

Example

int totalNumberOfStudentsInComputerScienceDepartment;

Although valid, extremely long names may reduce readability.

Rule 8: Should Be Meaningful

Bad

int x;

Better

int totalMarks;

Best

int totalStudentMarks;

Meaningful identifiers make code easier to read and maintain.

Identifier vs Keyword

User-definedReserved by C
Can be chosen by the programmerPredefined by the language
Used to name variables/functionsUsed to define language syntax
Example: marksExample: int

Example

int marks;
  • int → Keyword
  • marks → Identifier

Identifier vs Variable

Many beginners confuse these terms.

A variable is a storage location.

An identifier is the name of that storage location.

Example

int age = 20;
  • Variable → Stores the value 20
  • Identifier → age

Interview Questions

1. What is an identifier?

An identifier is a user-defined name used to identify variables, functions, arrays, structures, and other program elements in C.

2. Can an identifier start with a number?

No. It must start with a letter or an underscore (_).

3. Can an identifier contain spaces?

No. Spaces are not allowed.

4. Is _count a valid identifier?

Yes. Identifiers can begin with an underscore.

5. What is the difference between an identifier and a keyword?

  • An identifier is a user-defined name.
  • A keyword is a reserved word with a predefined meaning in C.

Coding Questions

Q1. Declare variables using valid identifiers.

#include <stdio.h>

int main()
{
    int studentAge = 20;
    float totalMarks = 87.5;
    char studentGrade = 'A';

    printf("Age: %d\n", studentAge);
    printf("Marks: %.1f\n", totalMarks);
    printf("Grade: %c\n", studentGrade);

    return 0;
}

Output

Age: 20
Marks: 87.5
Grade: A

Summary

  • An identifier is a user-defined name for program elements.
  • It must begin with a letter or an underscore (_).
  • It cannot start with a digit, contain spaces, or use special characters (except _).
  • Identifiers are case-sensitive.
  • Keywords cannot be used as identifiers.
  • Choosing meaningful and consistent names makes programs easier to read and maintain.
