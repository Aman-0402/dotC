Strings

What is a String?

A string is a sequence of characters stored in a character array and terminated by a special character called the null character ('\0').

Unlike some programming languages, C does not have a built-in string data type. Instead, strings are represented using arrays of type char.

Example:

H  e  l  l  o  \0

Memory Representation:

Index 0 1 2 3 4 5
Value H e l l o \0

Why Strings are Important?

Strings are used for storing:

  • Names
  • Addresses
  • Passwords
  • Sentences
  • File names
  • Email IDs
  • User input

Almost every real-world C program uses strings.

String Declaration

Syntax

char string_name[size];

Example

char name[20];

This creates a character array capable of storing 19 characters + 1 null character ('\0').

String Initialization

Method 3

Initialize Character by Character

char name[] = {'A','m','a','n','\0'};

Incorrect Initialization

Missing '\0'.

This is not considered a proper C string.

Basic String Operations

The most common operations performed on strings are:

  • Input
  • Output
  • Reading characters
  • Writing characters
  • Printing formatted strings

gets()

Used to read an entire line of text including spaces.

Syntax

gets(string);

Example

#include <stdio.h>

int main()
{
    char name[50];

    printf("Enter Name: ");
    gets(name);

    printf("%s", name);

    return 0;
}

Input

Aman Kumar

Output

Aman Kumar

Advantages

  • Reads spaces.
  • Reads complete line.

Disadvantages

  • Does not check array size.
  • Can cause buffer overflow.
  • Removed from the modern C standard.
  • Avoid using it in real applications.

puts()

Displays a string and automatically moves the cursor to the next line.

Syntax

puts(string);

Example

#include <stdio.h>

int main()
{
    char name[] = "Aman";

    puts(name);

    return 0;
}

Output

Aman

Equivalent to

printf("%s\n", name);

getchar()

Reads one character from the keyboard.

Syntax

char variable = getchar();

Example

#include <stdio.h>

int main()
{
    char ch;

    printf("Enter Character: ");
    ch = getchar();

    printf("%c", ch);

    return 0;
}

Input

A

Output

A

putchar()

Displays one character.

Syntax

putchar(character);

Example

#include <stdio.h>

int main()
{
    char ch = 'A';

    putchar(ch);

    return 0;
}

Output

A

printf()

Used to display formatted output.

Syntax

printf("format", variables);

Example

#include <stdio.h>

int main()
{
    char name[] = "Aman";

    printf("%s", name);

    return 0;
}

Output

Aman

Important Notes

  • A string is a character array ending with '\0'.
  • gets() reads a full line but is unsafe and should generally be avoided.
  • puts() prints a string and automatically adds a newline.
  • getchar() reads a single character.
  • putchar() prints a single character.
  • printf() is the most flexible output function because it supports formatted output.
