C Tokens

What are C Tokens?

A token is the smallest individual unit (or meaningful element) of a C program that the compiler recognizes.

Just as an English sentence is made up of words, a C program is made up of tokens.

For example:

int age = 20;

This single statement contains 5 tokens:

Token Type
int Keyword
age Identifier
= Operator
20 Constant
; Special Symbol

Definition

A token is the smallest meaningful unit in a C program that is recognized by the compiler.

Types of Tokens in C

There are 6 main types of tokens:

No. Token Type Example
1 Keywords int, if, return
2 Identifiers age, sum, marks
3 Constants 10, 3.14, 'A'
4 Strings "Hello"
5 Operators +, -, *, =
6 Special Symbols (Separators/Punctuators) ;, {}, (), ,, []

1. Keywords

Keywords are reserved words that have predefined meanings in C.

Example:

2. Identifiers

Identifiers are the names given by the programmer to variables, functions, arrays, etc.

Example:

int marks;

Here:

  • marks is an identifier.

More examples:

studentName
totalMarks
salary
calculateArea

Rules (briefly):

  • Can contain letters, digits, and _
  • Cannot start with a digit
  • Cannot be a keyword
  • Case-sensitive

3. Constants

Constants are fixed values that do not change during program execution.

Examples:

100
25.5
'A'

Program:

#include <stdio.h>

int main()
{
    printf("%d", 100);
    return 0;
}

Output:

100

4. String Literals

A string is a sequence of characters enclosed in double quotes.

Example:

"Hello"

Program:

#include <stdio.h>

int main()
{
    printf("Welcome");
    return 0;
}

Output:

Welcome

Why are Tokens Important?

The compiler first breaks your source code into tokens before checking for syntax errors and generating machine code.

Compilation flow:

Source Code
      │
      ▼
Tokenization (Lexical Analysis)
      │
      ▼
Syntax Checking
      │
      ▼
Compilation
      │
      ▼
Machine Code

If a token is invalid, compilation fails.

Example:

int 2age = 10;

Here, 2age is not a valid identifier, so the compiler reports an error.

Common Beginner Mistakes

1. Using a keyword as an identifier

❌ Wrong

int int = 5;

✅ Correct

int number = 5;

2. Missing semicolon

❌ Wrong

int age = 20

✅ Correct

int age = 20;

3. Forgetting double quotes for strings

❌ Wrong

printf(Hello);

✅ Correct

printf("Hello");

4. Starting an identifier with a digit

❌ Wrong

int 1value;

✅ Correct

int value1;

Interview Questions

1. What is a token in C?

A token is the smallest meaningful unit of a C program recognized by the compiler.

2. Name the different types of tokens.

  • Keywords
  • Identifiers
  • Constants
  • String Literals
  • Operators
  • Special Symbols (Punctuators)

3. Is printf a keyword?

No. printf is a library function name (identifier) declared in <stdio.h>.

4. Is "Hello" a token?

Yes. It is a string literal token.

5. Is ; a token?

Yes. It is a special symbol (punctuator) token.

Q2. Write a program using different types of tokens.

{
    int age = 21;
