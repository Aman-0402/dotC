Unconditional Statements

Unconditional statements are statements that change the normal flow of program execution immediately, without checking any condition at that moment.

Normally, a C program executes statements one after another.

Statement 1
    ↓
Statement 2
    ↓
Statement 3
    ↓
Statement 4

Unconditional statements can interrupt this flow.

For example:

  • Exit a loop immediately.
  • Skip the remaining part of the current loop iteration.
  • Jump directly to another part of the program.

Types of Unconditional Statements

There are three commonly used unconditional statements in C.

Statement Purpose
breakTerminates the nearest loop or switch
continueSkips the remaining statements of the current loop iteration
gotoJumps directly to a labeled statement

1. break Statement

The break statement immediately terminates the nearest loop (for, while, do-while) or a switch-case statement.

As soon as break is executed:

  • The loop ends immediately.
  • Control moves to the statement after the loop.

Syntax

break;

int main()

2. continue Statement

The continue statement skips the remaining statements of the current iteration of a loop.

Instead of ending the loop, it immediately starts the next iteration.

Syntax

continue;

Flow

      V

3. goto Statement

The goto statement transfers program control directly to another labeled statement within the same function.

Unlike loops or conditional statements, goto performs an unconditional jump.

Syntax

goto label;

/* statements */

label:
    statement;

Flow

Statement
    |
goto label
    |
Jump
    |
label:
Statements

Example 1

#include <stdio.h>

int main()
{
    printf("Welcome\n");

    goto end;

    printf("This line will never execute\n");

end:
    printf("Program Finished");

    return 0;
}

Output

Welcome
Program Finished

Example 2

#include <stdio.h>

int main()
{
    int num;

start:

    printf("Enter a positive number: ");
    scanf("%d",&num);

    if(num < 0)
    {
        printf("Invalid Input\n");
        goto start;
    }

    printf("Valid Number");

    return 0;
}

Sample Output

Enter a positive number: -5
Invalid Input

Enter a positive number: -10
Invalid Input

Enter a positive number: 20
Valid Number

Why is goto Discouraged?

Although goto works correctly, excessive use makes programs difficult to understand and maintain.

Problems include:

  • Creates confusing program flow.
  • Makes debugging difficult.
  • Reduces code readability.
  • Can lead to Spaghetti Code (code with many uncontrolled jumps).

Bad Example

goto A
goto B
goto C
goto D
goto A
goto C
goto B

This becomes very difficult to follow.

When is goto Acceptable?

Although generally avoided, goto is occasionally useful for:

  • Exiting multiple nested loops.
  • Error handling in low-level system programming.
  • Resource cleanup (closing files, freeing memory) before exiting a function.

Summary

  • break immediately exits the nearest loop or switch statement.
  • continue skips the rest of the current iteration and proceeds with the next iteration of the loop.
  • goto transfers control directly to a labeled statement in the same function.
  • Prefer break and continue for structured programming. Use goto only in rare, well-justified situations where it simplifies cleanup or error handling.
