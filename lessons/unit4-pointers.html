Pointers

What is a Pointer?

A pointer is a special variable that stores the memory address of another variable instead of storing the actual value.

Every variable stored in memory has:

  • A value
  • A memory address

A pointer stores this memory address.

Why Use Pointers?

Pointers are one of the most powerful features of C.

They are used for:

  • Dynamic Memory Allocation
  • Call by Reference
  • Arrays and Strings
  • Data Structures (Linked List, Stack, Queue, Tree, Graph)
  • File Handling
  • Efficient Memory Management

Memory Representation

Example

int a = 10;

Suppose the variable is stored in memory as:

Variable Value Address (Example)
a101000

A pointer stores the address 1000, not the value 10.

Pointer Declaration

Syntax

data_type *pointer_name;

Examples

int *ptr;
char *ch;
float *fptr;
double *dptr;

The * indicates that the variable is a pointer.

Pointer Initialization

A pointer should be initialized with the address of a variable.

Example

int a = 10;

int *ptr = &a;

Now,

  • a stores 10
  • ptr stores the address of a

Address Operator (&)

The address operator (&) returns the memory address of a variable.

Syntax

&variable

Example

#include <stdio.h>

int main()
{
    int a = 10;

    printf("%p", &a);

    return 0;
}

Output

0x7ffd8f52...

The actual address depends on the system and changes each time the program runs.

Indirection (Dereference) Operator (*)

The dereference operator (*) is used to access the value stored at the memory address held by a pointer.

Example

int a = 10;

int *ptr = &a;

printf("%d", *ptr);

Output

10

Example: Address and Value

#include <stdio.h>

int main()
{
    int a = 25;

    int *ptr = &a;

    printf("Value of a = %d\n", a);
    printf("Address of a = %p\n", &a);
    printf("Value stored in ptr = %p\n", ptr);
    printf("Value pointed by ptr = %d\n", *ptr);

    return 0;
}

Sample Output

Value of a = 25
Address of a = 0x7ffd8f52...
Value stored in ptr = 0x7ffd8f52...
Value pointed by ptr = 25

Relationship Between Variable and Pointer

        +-----------+
        |  a = 10   |
        +-----------+
Address -> 1000

        +-----------+
ptr --->|   1000    |
        +-----------+
  • a contains the value 10
  • ptr contains the address of a
  • *ptr gives the value stored at that address (10)

Pointer Arithmetic

Pointers can be incremented and decremented.

Example

int arr[] = {10,20,30};

int *ptr = arr;

ptr++;

Initially

ptr → arr[0]

After increment

ptr → arr[1]

Example

#include <stdio.h>

int main()
{
    int arr[] = {10,20,30};

    int *ptr = arr;

    printf("%d\n", *ptr);

    ptr++;

    printf("%d\n", *ptr);

    return 0;
}

Output

10
20

Rules of Pointer Arithmetic

Allowed:

  • Increment (++)
  • Decrement (--)
  • Addition with integer
  • Subtraction with integer
  • Difference between two pointers (pointing into the same array)

Not Allowed:

  • Addition of two pointers
  • Multiplication of pointers
  • Division of pointers

Pointer and Arrays

The name of an array acts as a pointer to its first element.

Example

int arr[5] = {10,20,30,40,50};

int *ptr = arr;

Equivalent to

int *ptr = &arr[0];

Accessing Array Using Pointer

#include <stdio.h>

int main()
{
    int arr[] = {10,20,30,40};

    int *ptr = arr;

    for(int i=0;i<4;i++)
    {
        printf("%d ", *(ptr+i));
    }

    return 0;
}

Output

10 20 30 40

Null Pointer

A Null Pointer points to nothing.

It is assigned using NULL.

Example

int *ptr = NULL;

Characteristics

  • Safe initialization
  • Indicates "no valid address"
  • Prevents accidental use of uninitialized pointers

Void Pointer

A Void Pointer is a generic pointer.

It can store the address of any data type.

Example

int a = 100;

void *ptr = &a;

To access the value, type casting is required.

printf("%d", *(int *)ptr);

Wild Pointer

A Wild Pointer is a pointer that has been declared but not initialized.

Example

int *ptr;

This pointer contains an unknown (garbage) address.

Using a wild pointer can lead to undefined behavior.

Correct approach

int *ptr = NULL;

Dangling Pointer

A Dangling Pointer points to a memory location that is no longer valid.

Example

int *ptr;

{
    int x = 50;
    ptr = &x;
}

After the block ends, x no longer exists, so ptr becomes a dangling pointer.

Another common case is after freeing dynamically allocated memory.

free(ptr);
ptr = NULL;

Setting the pointer to NULL after free() helps avoid accidental use.

Types of Pointers

Pointer Type Description
Normal PointerStores address of a variable
Null PointerPoints to nothing (NULL)
Void PointerCan point to any data type
Wild PointerDeclared but not initialized

Complete Example

#include <stdio.h>

int main()
{
    int num = 50;

    int *ptr = &num;

    printf("Value of num = %d\n", num);

    printf("Address of num = %p\n", &num);

    printf("Pointer Value = %p\n", ptr);

    printf("Dereferenced Value = %d\n", *ptr);

    return 0;
}

Sample Output

Value of num = 50
Address of num = 0x7ffd8f52...
Pointer Value = 0x7ffd8f52...
Dereferenced Value = 50

Important Notes

  • A pointer stores the memory address of another variable.
  • The address operator (&) returns the address of a variable.
  • The dereference operator (*) accesses the value stored at the address.
  • Pointer arithmetic moves between elements based on the size of the data type.
  • The array name points to the first element of the array.
  • Always initialize pointers before using them.
  • Use NULL to indicate that a pointer does not currently point to a valid object.
  • Avoid using wild and dangling pointers, as they can cause undefined behavior and program crashes.
