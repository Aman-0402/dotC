Operators in C

Operators are one of the most important topics in C. Almost every C program uses operators for calculations, comparisons, logical decisions, memory operations, and bit manipulation.

This topic covers:

  • Operators

  • Pre-Increment & Post-Increment Expressions
  • Assignment Operators
  • Bitwise Operators
  • Comma Operator
  • Arrow (->) Operator
  • sizeof Operator

What is an Operator?

An operator is a special symbol that performs an operation on one or more operands and produces a result.

Definition

An operator is a symbol that tells the compiler to perform a specific operation on one or more operands.

General Form

Operand   Operator   Operand

a + b

Where:

  • a, b → Operands
  • + → Operator

Result:

a + b = value

4. Conditional (Ternary) Operator

The ternary operator is a shorthand for if...else.

Syntax

condition ? expression1 : expression2;

Meaning

If condition is true
↓

expression1

Else

expression2

Example

#include <stdio.h>

int main()
{
    int a = 10, b = 20;

    int max = (a > b) ? a : b;

    printf("%d", max);

    return 0;
}

Output

20

5. Operator Precedence

6. Pre-Increment & Post-Increment

Increment increases a value by 1.

Pre-Increment (++x)

Increment happens before the value is used.

int x = 5;

printf("%d", ++x);

Output

6

Memory

x = 5

↓

Increment

↓

6

↓

Print 6

Post-Increment (x++)

Value is used first.

Then increment happens.

int x = 5;

printf("%d", x++);

Output

5

After printing

x = 6

Comparison

Expression Output Final x
++x66
x++56

9. Comma Operator

The comma operator evaluates multiple expressions from left to right and returns the value of the last expression.

Example

int x;

x = (2, 4, 6);

Result

x = 6

Example

int a = (10, 20, 30);

printf("%d", a);

Output

30

10. Arrow (->) Operator

The arrow operator is used to access structure members through a pointer to a structure.

It is equivalent to:

(*pointer).member

Example

struct Student
{
    int id;
};

struct Student s = {101};
struct Student *ptr = &s;

printf("%d", ptr->id);

Output

101

We will study structures and pointers in detail in later units.

11. sizeof Operator

sizeof returns the size of a data type or variable in bytes.

Syntax

sizeof(data_type)

or

sizeof(variable)

Example

#include <stdio.h>

int main()
{
    printf("%zu\n", sizeof(int));
    printf("%zu\n", sizeof(char));
    printf("%zu\n", sizeof(double));

    return 0;
}

Sample Output

4
1
8

Exam Tips

  • ⭐ Operators perform operations on operands.
  • ⭐ = assigns a value, while == compares values.
  • ⭐ ++x increments before use; x++ increments after use.
  • ⭐ % works only with integer operands.
  • ⭐ The ternary operator ?: is a compact form of if...else.
  • ⭐ Parentheses () have the highest precedence and make expressions easier to understand.
  • ⭐ sizeof returns the memory size of a data type or variable.
  • ⭐ -> is used to access structure members through a pointer.

Summary

  • C provides a rich set of operators for arithmetic, comparison, logical operations, assignments, bit manipulation, and memory-related tasks.
  • Understanding operator precedence helps predict how expressions are evaluated.
  • Pre-increment and post-increment differ in when the increment occurs.
  • Bitwise operators work on binary representations of integers.
  • sizeof is useful for writing portable programs.
  • Comma and Arrow operators are specialized operators that are important in advanced C programming.
