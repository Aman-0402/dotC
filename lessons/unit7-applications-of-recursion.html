Applications of Recursion

Recursion is one of the most powerful programming techniques. It is widely used to solve problems that can be broken into smaller subproblems of the same type.

Many important algorithms and data structures rely on recursion.

Why Use Recursion?

Recursion is useful when:

  • A problem can be divided into smaller versions of itself.
  • The solution naturally follows a hierarchical structure.
  • Divide and Conquer is an appropriate strategy.
  • Working with trees or graphs.

1. Factorial

Formula:

n! = n × (n − 1)!

0! = 1

Example:

5!

↓

5 × 4!

↓

5 × 4 × 3!

↓

5 × 4 × 3 × 2!

↓

5 × 4 × 3 × 2 × 1!

↓

120

C Program

int factorial(int n)
{
    if(n == 0)
        return 1;

    return n * factorial(n - 1);
}

2. Fibonacci Series

Formula:

F(n)

=

F(n-1) + F(n-2)

Base Cases:

F(0)=0

F(1)=1

Sequence:

0 1 1 2 3 5 8 13 21 ...

C Program

int fib(int n)
{
    if(n <= 1)
        return n;

    return fib(n-1) + fib(n-2);
}

3. Binary Search

Binary Search repeatedly divides a sorted array into two halves.

Example:

10 20 30 40 50 60 70

Search:

50

Steps:

Middle = 40

↓

50 > 40

↓

Search Right Half

↓

50 Found

Recursive Function:

int binarySearch(int arr[], int left, int right, int key)
{
    if(left > right)
        return -1;

    int mid = (left + right) / 2;

    if(arr[mid] == key)
        return mid;

    if(key < arr[mid])
        return binarySearch(arr, left, mid - 1, key);

    return binarySearch(arr, mid + 1, right, key);
}

Time Complexity

O(log n)

Example:

Advantages of Recursion

  • Simple and elegant code.
  • Natural for hierarchical structures.
  • Ideal for Divide and Conquer.
  • Easy implementation of tree and graph algorithms.
  • Reduces code complexity for many recursive problems.

Disadvantages

  • More memory due to the call stack.
  • Function call overhead.
  • Risk of stack overflow with deep recursion.
  • Some recursive algorithms perform repeated computations (e.g., naive Fibonacci).
