Heap Sort

Heap Sort is an efficient comparison-based sorting algorithm that uses a Binary Heap data structure. It works by first converting the array into a Max Heap, then repeatedly removing the largest element and placing it at the end of the array.

Heap Sort combines the efficiency of O(n log n) time complexity with O(1) extra space, making it a good choice when memory usage is important.

Prerequisite: What is a Heap?

A Heap is a special type of Complete Binary Tree.

A Complete Binary Tree is a binary tree where:

  • Every level is completely filled except possibly the last level.
  • The last level is filled from left to right.

There are two types of heaps:

1. Max Heap

Every parent node is greater than or equal to its children.

        90
      /    \
    70      60
   /  \    /  \
 40   30 20   10

The largest element is always at the root.

2. Min Heap

Every parent node is smaller than or equal to its children.

        10
      /    \
    20      30
   /  \    /  \
 40   50 60   70

The smallest element is always at the root.

Array Representation of a Heap

A heap is usually stored in an array.

Index : 0   1   2   3   4   5   6

Value : 90 70 60 40 30 20 10

Tree representation:

            90
         /      \
       70        60
      /  \      /  \
    40   30   20   10

Parent and Child Formula

If an element is at index i:

Node Formula
Left Child2 × i + 1
Right Child2 × i + 2
Parent(i - 1) / 2

Example:

Index : 0 1 2 3 4 5 6

Value :90 70 60 40 30 20 10

For index 1 (70)

  • Left Child = 3 → 40
  • Right Child = 4 → 30
  • Parent = 0 → 90

What is Heapify?

Heapify is the process of converting a subtree into a valid Max Heap.

Suppose we have:

        20
      /    \
    70      60

This is not a Max Heap because the parent (20) is smaller than its children.

After Heapify:

        70
      /    \
    20      60

Now the Max Heap property is satisfied.

How Heap Sort Works

Consider the array:

4 10 3 5 1

Step 1: Build Max Heap

Convert the array into a Max Heap.

        10
      /    \
     5      3
    / \
   4   1

Array representation:

10 5 3 4 1

Step 2: Swap Root with Last Element

Swap:

10 ↔ 1

Array:

1 5 3 4 10

Now 10 is in its correct sorted position.

Step 3: Heapify Remaining Heap

Heapify first four elements.

        5
      /   \
     4     3
    /
   1

Array:

5 4 3 1 10

Step 4: Repeat

Swap root with last unsorted element.

1 4 3 5 10

Heapify:

4 1 3 5 10

Repeat until only one element remains.

Final Sorted Array

1 3 4 5 10

Heap Sort Algorithm

Build Max Heap

Repeat until heap size becomes 1

    Swap root with last element

    Reduce heap size

    Heapify root

C Program

#include <stdio.h>

void swap(int *a, int *b)
{
    int temp = *a;
    *a = *b;
    *b = temp;
}

void heapify(int arr[], int n, int i)
{
    int largest = i;
    int left = 2 * i + 1;
    int right = 2 * i + 2;

    if (left < n && arr[left] > arr[largest])
        largest = left;

    if (right < n && arr[right] > arr[largest])
        largest = right;

    if (largest != i)
    {
        swap(&arr[i], &arr[largest]);
        heapify(arr, n, largest);
    }
}

void heapSort(int arr[], int n)
{
    // Build Max Heap
    for (int i = n / 2 - 1; i >= 0; i--)
        heapify(arr, n, i);

    // Extract elements one by one
    for (int i = n - 1; i > 0; i--)
    {
        swap(&arr[0], &arr[i]);
        heapify(arr, i, 0);
    }
}

int main()
{
    int arr[] = {4, 10, 3, 5, 1};
    int n = sizeof(arr) / sizeof(arr[0]);

    heapSort(arr, n);

    printf("Sorted Array:\n");

    for (int i = 0; i < n; i++)
        printf("%d ", arr[i]);

    return 0;
}

Output

Sorted Array:
1 3 4 5 10

Code Explanation

Build Max Heap

for (int i = n / 2 - 1; i >= 0; i--)
    heapify(arr, n, i);

Starts from the last non-leaf node and converts the array into a Max Heap.

Swap Root

swap(&arr[0], &arr[i]);

Moves the largest element (root) to its final position.

Heapify

heapify(arr, i, 0);

Restores the Max Heap property after removing the largest element.

Time Complexity

Case Complexity
Best CaseO(n log n)
Average CaseO(n log n)
Worst CaseO(n log n)

Heap Sort performs consistently well in all cases.

Space Complexity

O(1)

Heap Sort sorts the array in-place, requiring only constant extra memory.

Advantages

  • Guaranteed O(n log n) performance.
  • In-place sorting algorithm.
  • Does not require extra arrays.
  • Suitable for large datasets.
  • Predictable performance regardless of input order.

Disadvantages

  • Not a stable sorting algorithm.
  • Slightly slower than Quick Sort in practice due to more comparisons and heap maintenance.
  • More complex to implement than Bubble, Selection, or Insertion Sort.

Applications

  • Priority Queue implementation.
  • CPU Scheduling.
  • Graph algorithms (e.g., Dijkstra's and Prim's algorithms use heaps).
  • Embedded systems where memory is limited.
  • Systems requiring predictable worst-case performance.

Key Points to Remember

  • Heap Sort is based on the Max Heap data structure.
  • A Max Heap stores the largest element at the root.
  • Heapify maintains the heap property after each swap.
  • Heap Sort is in-place but not stable.
  • Time Complexity is O(n log n) in all cases.
  • Space Complexity is O(1).
