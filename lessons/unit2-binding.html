Binding

What is Binding?

Binding is the process of associating (linking) a name with an entity such as a variable, function, data type, or memory location.

In simple words:

Binding means connecting a name with what it represents.

For example:

int age = 20;

Here,

  • age → Name (Identifier)
  • int → Data Type
  • 20 → Value

The compiler binds:

  • The name age to its data type (int)
  • The name age to a memory location
  • The name age to its stored value

Real-Life Analogy

Imagine a classroom.

A teacher says:

"Aman, stand up."

The name Aman is bound to a specific student.

Similarly, in C,

int marks = 95;

The name marks is bound to:

  • Integer type
  • Memory address
  • Value 95

Why is Binding Important?

Binding allows the compiler to know:

  • Where data is stored
  • What type of data it is
  • Which function to execute
  • How much memory to allocate
  • Which operations are allowed

Without binding, the compiler would not know what each name refers to.

Binding Process in C

Consider the following code:

int age = 20;

The compiler performs these steps:

Identifier (age)
        │
        ▼
Data Type (int)
        │
        ▼
Memory Allocation (4 bytes on most systems)
        │
        ▼
Store Value (20)

So age becomes associated with:

  • Data type
  • Memory location
  • Stored value

Types of Binding

There are two major types of binding.

Binding
│
├── Static Binding (Early Binding)
└── Dynamic Binding (Late Binding)

1. Static Binding (Early Binding)

Static binding happens during compilation.

The compiler already knows:

  • Variable types
  • Function names
  • Memory requirements (for local/static variables)

C primarily uses static binding.

Example:

#include <stdio.h>

int main()
{
    int number = 10;

    printf("%d", number);

    return 0;
}

During compilation:

number
   │
   ▼
int
   │
   ▼
Memory Allocated

Everything is decided before execution.

Another Example

int sum(int a, int b)
{
    return a + b;
}

When the compiler sees:

sum(10, 20);

It already knows:

  • Function name
  • Return type
  • Parameters

This is static binding.

2. Dynamic Binding (Late Binding)

Dynamic binding occurs during program execution (runtime).

The decision about which function or object to use is made while the program is running.

Important Note

Traditional C does not support dynamic binding (runtime polymorphism) like C++ or Java.

Dynamic binding is mainly associated with object-oriented programming using features such as virtual functions.

In C, almost all binding is static.

Compile-Time Binding vs Run-Time Binding

Compile-Time Binding Run-Time Binding
Happens during compilationHappens during execution
FasterSlightly slower
Used by CUsed by languages like C++ (virtual functions) and Java
Also called Early BindingAlso called Late Binding

Name Binding

Name binding is the association between an identifier and its meaning.

Example:

int salary = 50000;

Binding:

salary
   │
   ▼
int
   │
   ▼
Memory Address
   │
   ▼
50000

Type Binding

A variable is bound to a data type.

Example:

char grade = 'A';

Binding:

grade
   │
   ▼
char

The compiler now knows:

  • It stores one character.
  • It should use %c with printf.
  • Operations are based on the char type.

Memory Binding

Each variable gets a memory location.

Example:

int marks = 90;

Memory:

Address      Variable      Value
--------------------------------
1000         marks          90

The compiler binds:

marks
   │
   ▼
Address 1000

Value Binding

The variable is associated with its current value.

Example:

int age = 20;

Initially:

age
 │
 ▼
20

Later:

age = 25;

Now:

age
 │
 ▼
25

The binding to the memory location stays the same, but the stored value changes.

Function Binding

Functions are also bound.

Example:

#include <stdio.h>

void greet()
{
    printf("Hello");
}

int main()
{
    greet();

    return 0;
}

Compiler Binding:

greet()

↓

Function Address

↓

Call Function

Binding During Compilation

Example:

int x = 10;

Compilation process:

Source Code
      │
      ▼
Lexical Analysis
      │
      ▼
Syntax Analysis
      │
      ▼
Semantic Analysis

Binding occurs during the compiler's semantic analysis phase.

Example Program

#include <stdio.h>

int main()
{
    int age = 21;
    float salary = 50000.50;
    char grade = 'A';

    printf("%d\n", age);
    printf("%.2f\n", salary);
    printf("%c\n", grade);

    return 0;
}

50000.50
A

Binding and Scope

Binding works together with scope.

Example:

#include <stdio.h>

int x = 100;

int main()
{
    int x = 50;

    printf("%d", x);

    return 0;
}

Output

50

Explanation:

  • Global x is bound globally.
  • Local x is bound inside main().
  • Inside main(), the local binding takes precedence (variable shadowing).

Common Beginner Mistakes

1. Thinking Binding Means Assignment

Wrong idea:

Binding = assigning a value

Correct:

Binding is the association between a name and an entity (type, memory, function, etc.). Assignment changes the value stored.

2. Confusing Binding with Scope

  • Binding → Associates a name with an entity.
  • Scope → Determines where that name can be accessed.

3. Assuming C Supports Dynamic Binding

C primarily uses static (early) binding.

Dynamic binding is a feature of object-oriented languages like C++ and Java.

4. Believing Memory Changes During Assignment

int age = 20;

age = 30;

The memory address usually remains the same; only the stored value changes.

Summary

  • Binding is the process of associating a name with a program entity such as a variable, function, data type, or memory location.
  • C primarily uses static (early) binding, where most decisions are made during compilation.
  • Dynamic (late) binding is generally not supported in traditional C.
  • Binding works together with scope and memory allocation to allow the compiler to correctly interpret program elements.
  • Understanding binding helps explain how variables, functions, and types are connected during compilation.
