Non-Numeric Data Types (Character & String)

In C, not all data is numerical. Many programs work with letters, words, names, passwords, addresses, messages, and symbols. These are stored using Non-Numeric Data Types.

This topic covers:

  • Non-Numeric Data Types
  • Character (char)
  • String

What are Non-Numeric Data Types?

Non-numeric data types are used to store data that is not primarily used for mathematical calculations.

Examples:

  • Student Name
  • Gender
  • Address
  • Email
  • Grade
  • Password
  • Country Name

Instead of numbers, they store:

  • Characters
  • Text
  • Symbols

Definition

Non-numeric data types are data types used to store characters, text, symbols, and other non-numerical information.

Classification

Non-Numeric Data Types
│
├── Character (char)
└── String

Why Do We Need Non-Numeric Data Types?

Imagine a student management system.

You need to store:

Name        : Aman
Gender      : M
City        : Ranchi
Grade       : A

Using only integers would not make sense.

Therefore C provides:

  • char
  • Strings

Part 1: Character (char)

What is Character Data Type?

A character stores exactly one character.

It can store:

  • Alphabets
  • Digits
  • Symbols
  • Special characters

Definition

The char data type stores a single character enclosed in single quotes (' ').

Syntax

char variableName;

Example

char grade = 'A';

Memory Size

Typically

1 Byte (8 bits)

Why Only One Byte?

One byte can represent 256 different values.

These values come from the ASCII character set.

ASCII (American Standard Code for Information Interchange)

Computers do not store characters directly.

Instead they store numbers.

Part 2: String

What is a String?

A string is a collection (sequence) of characters.

Example

Hello

Aman

Programming

Definition

A string is an array of characters terminated by a special null character (\0).

Why Doesn't C Have a Built-in String Type?

Unlike languages such as Java or Python, C does not have a built-in string data type.

Instead,

A string is stored as:

char name[];

String Syntax

char name[] = "Aman";

Memory Representation

char name[] = "Aman";

Memory

Index      Character

0             A
1             m
2             a
3             n
4            \0

The last character is automatically:

Null Character

\0

which marks the end of the string.

Why is \0 Important?

Without \0

the computer would not know where the string ends.

Example

#include <stdio.h>

int main()
{

Common Beginner Mistakes

1. Using Double Quotes for Character

Wrong

char ch = "A";

Correct

char ch = 'A';

2. Using Single Quotes for String

Wrong

char name[] = 'Aman';

Correct

char name[] = "Aman";

3. Forgetting the Null Character

Wrong

char word[3] = {'C','A','T'};

This is not a null-terminated string.

Correct

char word[] = "CAT";

or

char word[4] = {'C','A','T','\0'};

4. Using %d for Characters

Wrong

printf("%d", 'A');

This prints the ASCII value (65), not the character.

Correct

printf("%c", 'A');

5. Confusing Character and String

Wrong

char ch = 'AB';

A char can store only one character.

Correct

char ch = 'A';

Interview Questions

1. What is a non-numeric data type?

A non-numeric data type stores characters, text, or symbols instead of numerical values.

2. What is the size of char?

Typically 1 byte (8 bits).

3. What is ASCII?

ASCII is a standard character encoding where each character is represented by a numeric value.

4. What is a string in C?

A string is a sequence of characters terminated by the null character (\0).

5. Why does every string end with \0?

Because \0 tells C where the string ends.

Exam Tips

  • ⭐ char stores only one character.
  • ⭐ A character is written using single quotes ('A').
  • ⭐ A string is written using double quotes ("Aman").
  • ⭐ Every string automatically ends with \0 (null character).
  • ⭐ %c is used for characters, %s for strings.
  • ⭐ char is typically 1 byte and stores ASCII values internally.
  • ⭐ "A" is a string, while 'A' is a character.

Summary

  • Non-Numeric Data Types are used to store characters and text.
  • The char data type stores a single character and typically occupies 1 byte.
  • Characters are internally represented using ASCII values.
  • A string in C is a sequence of characters stored in a char array and terminated by the null character (\0).
  • Characters use single quotes, while strings use double quotes.
  • Understanding char and strings is essential because they are widely used in user input, text processing, and file handling.
