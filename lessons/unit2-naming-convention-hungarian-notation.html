Naming Convention & Hungarian Notation

Writing a program that works is important, but writing code that is easy to read, understand, and maintain is equally important.

This topic explains how programmers should name variables, functions, constants, files, and other identifiers using standard conventions.

This topic covers:

  • Naming Convention
  • Hungarian Notation

What is a Naming Convention?

A Naming Convention is a set of rules and best practices for giving meaningful names to variables, functions, constants, files, and other program elements.

Definition

A Naming Convention is a standard way of naming identifiers to make code readable, understandable, and maintainable.

Why are Naming Conventions Important?

Imagine reading this code:

int a;
int b;
int c;

c = a * b;

What do a, b, and c represent?

Nobody knows.

Now look at this:

int length;
int width;
int area;

area = length * width;

It is immediately clear what the program does.

Benefits of Naming Conventions

  • Improves readability
  • Makes debugging easier
  • Makes teamwork easier
  • Reduces mistakes
  • Makes code self-explanatory
  • Easier maintenance

Good vs Bad Naming

Bad

int x;

Better

int studentAge;

int totalMarks;

Best

int studentAge;

The name itself explains the purpose.

Rules for Naming Identifiers

A valid identifier in C must follow these rules.

Rule 1: Begin with a Letter or Underscore

Correct

age
_student
salary2025

Wrong

2age

Identifiers cannot start with a digit.

Rule 2: Digits are Allowed (Not at the Beginning)

Correct

student1
rollNumber2

Wrong

123name

Rule 3: No Spaces

Wrong

student name

Correct

studentName

or

student_name

Rule 4: No Special Characters

Wrong

price@
salary$

Correct

price

Rule 5: Keywords Cannot Be Used

Wrong

int int;

Wrong

float return;

Correct

int total;

int totalStudents;

Instead of

Common Naming Styles

There are several naming styles used in programming.

1. camelCase

First word starts with a lowercase letter.

Each new word starts with a capital letter.

Example

studentAge
totalMarks
employeeSalary

2. PascalCase

Every word starts with a capital letter.

Example

StudentAge

EmployeeSalary

CalculateArea

Used more commonly in languages like C#, Java, and C++ for class names.

3. snake_case

Words are separated by underscores.

Example

student_age

employee_salary

total_marks

Very common in C programming and many C libraries.

Comparison

Style Example
camelCasestudentAge
PascalCaseStudentAge
snake_casestudent_age

Which Style is Preferred in C?

Most C projects use:

  • snake_case for variables and functions
  • UPPER_CASE for macros and constants

Example

int student_age;

float total_marks;

#define MAX_SIZE 100

Some modern C projects also use camelCase, but consistency within a project is more important than the specific style.

Real-World Example

Professional Code

Easy to understand.

Hungarian Notation

Hungarian Notation is an old naming convention where the variable name begins with a prefix that indicates its data type or purpose.

It was popular in the 1980s and 1990s, especially in Microsoft software development.

Definition

Hungarian Notation is a naming convention where prefixes are added to variable names to indicate their type or usage.

Why Was It Introduced?

Before modern IDEs and advanced compilers, programmers could not easily determine the type of a variable.

Prefixes helped identify the data type quickly.

Example

Instead of

age

Programmers wrote

iAge

where

i

↓

Integer

Note: C itself does not have a built-in bool type before C99, but the b prefix is still commonly seen in Hungarian notation.

Without Hungarian

Advantages of Hungarian Notation

  • Easy to identify variable types
  • Useful in older development environments
  • Helpful in large legacy projects
  • Makes pointer variables easy to recognize

Disadvantages

Modern IDEs automatically display:

  • Data type
  • Documentation
  • Auto-completion
  • Error checking

Because of this,

Modern code usually prefers meaningful names over type prefixes.

Instead of

int iStudentAge;

many developers now prefer

int student_age;

or

int studentAge;

Modern Recommendation

Instead of focusing on the data type,

focus on the meaning.

Less Preferred

int iTotal;

Preferred

int total_students;

The name explains the purpose, while the compiler and IDE already know the type.

Complete Example

#include <stdio.h>

#define MAX_STUDENTS 100

int main()
{
    int student_age = 20;
    float average_marks = 88.5f;
    char grade = 'A';

    printf("Age            : %d\n", student_age);

    printf("Grade          : %c\n", grade);

}

Interview Questions

1. What is a naming convention?

A naming convention is a standard set of rules for naming variables, functions, constants, and other identifiers to improve readability and maintainability.

2. Why are naming conventions important?

They improve code readability, reduce errors, simplify debugging, and make teamwork easier.

3. What is Hungarian Notation?

It is a naming convention that uses prefixes to indicate the data type or purpose of a variable.

4. Is Hungarian Notation still widely used?

It is mainly found in legacy codebases. Modern C projects usually prefer meaningful names with consistent naming styles such as snake_case.

5. Which naming style is commonly used in C?

  • snake_case for variables and functions
  • UPPER_CASE for macros and constants

Exam Tips

  • ⭐ Always use meaningful and descriptive names.
  • ⭐ Follow one naming style consistently throughout the project.
  • ⭐ Use snake_case for variables and functions in C.
  • ⭐ Use UPPER_CASE for macros and constants.
  • ⭐ Avoid single-letter variable names except for simple loop counters like i and j.
  • ⭐ Hungarian Notation is useful for understanding older codebases but is less common in modern C development.

Summary

  • Naming conventions improve the readability, maintainability, and quality of code.
  • Use descriptive names that clearly indicate the purpose of variables and functions.
  • Common naming styles include camelCase, PascalCase, and snake_case, with snake_case being the most common in C.
  • Hungarian Notation uses prefixes such as i, f, c, and p to indicate data types or usage.
  • While Hungarian Notation is still found in legacy systems, modern C programming emphasizes meaningful names and consistent style over type prefixes.
