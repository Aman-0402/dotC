Data Types

Data Types are one of the fundamental building blocks of C programming. Every variable, constant, function, and expression is associated with a data type.

What is a Data Type?

A data type tells the compiler:

  • What kind of data will be stored.
  • How much memory should be allocated.
  • What operations can be performed on the data.
  • How the data should be interpreted.

Definition

A data type is a specification that tells the compiler what type of value a variable can store, how much memory it requires, and what operations are valid on it.

Real-Life Analogy

Imagine you have different containers:

🪣 Bucket       → Water
📦 Box          → Books
🧴 Bottle       → Oil
💰 Wallet       → Money

Each container is designed for a specific type of item.

Similarly in C:

int age;
float salary;
char grade;
  • age stores integers
  • salary stores decimal numbers
  • grade stores characters

Why Do We Need Data Types?

Suppose C had no data types.

20
'A'
3.14
"Hello"

The compiler would not know:

  • Is 20 a number or a character?
  • Is 3.14 an integer?
  • How much memory should be allocated?
  • Which format specifier should be used?

Data types solve these problems.

Example

#include <stdio.h>

int main()
{
    int age = 20;
    float percentage = 92.5;
    char grade = 'A';

    printf("%d\n", age);
    printf("%.1f\n", percentage);
    printf("%c\n", grade);

    return 0;
}

Output

20
92.5
A

How Does the Compiler Use Data Types?

Consider:

int number = 10;

The compiler performs these steps:

number
   │
   ▼
Data Type = int
   │
   ▼
Allocate Memory (typically 4 bytes)
   │
   ▼
Store Value = 10

Without the data type, the compiler would not know how to store or interpret 10.

Classification of Data Types

C data types can be divided into four major categories.

Data Types
│
├── Primary (Basic / Primitive)
├── Derived
├── User-Defined
└── Void

Let's understand each one.

1. Primary (Basic / Primitive) Data Types

These are the built-in data types provided by the C language.

Primary Data Types
│
├── int
├── char
├── float
└── double

Examples

int age = 20;
char grade = 'A';
float price = 99.99;
double pi = 3.1415926535;

These are the most commonly used data types in C.

2. Derived Data Types

Derived data types are created using the basic data types.

Examples:

Arrays
Pointers
Functions

Array

int marks[5];

Pointer

int *ptr;

Function

int add(int a, int b);

These will be covered in later units.

3. User-Defined Data Types

These are created by the programmer.

Examples:

struct
union
enum
typedef

Structure

struct Student
{
    int id;
    char name[30];
};

Enumeration

enum Day
{
    MON,
    TUE,
    WED
};

typedef

typedef unsigned int uint;

4. Void Data Type

void means no value or no data type.

It is commonly used in functions.

Example:

void display()
{
    printf("Hello");
}

Here the function returns nothing.

Another example:

void *ptr;

A void pointer can point to any data type.

Memory Allocation

Different data types require different amounts of memory.

Typical sizes on modern systems:

Data Type Typical Size
char1 byte
int4 bytes
float4 bytes
double8 bytes

Note: These sizes are implementation-dependent. They may vary across compilers and hardware architectures.

Why Different Sizes?

Suppose:

char grade = 'A';

Only one character needs to be stored.

So 1 byte is usually enough.

Now:

double pi = 3.141592653589793;

A much larger and more precise value needs more memory, so double typically uses 8 bytes.

Using sizeof

C provides the sizeof operator to determine the size of a data type or variable.

Example:

#include <stdio.h>

int main()
{
    printf("int = %zu bytes\n", sizeof(int));
    printf("char = %zu bytes\n", sizeof(char));
    printf("float = %zu bytes\n", sizeof(float));
    printf("double = %zu bytes\n", sizeof(double));

    return 0;
}

Sample Output

int = 4 bytes
char = 1 byte
float = 4 bytes
double = 8 bytes

Memory Representation

int age = 20;
char grade = 'A';
float marks = 95.5;

Memory

Address      Variable      Type      Value
----------------------------------------------
1000         age           int        20
1004         grade         char       A
1005         marks         float      95.5

The addresses shown are illustrative, not actual memory addresses.

Choosing the Correct Data Type

Wrong

int pi = 3.14;

Stored value:

3

The decimal part is lost.

Correct

float pi = 3.14;

Stored value:

3.14

Another example:

Wrong

char age = 25;

Although it may compile, char is intended for character data and has a limited range. Using it for age is poor design.

Better

int age = 25;

Common Beginner Mistakes

1. Storing Decimal Numbers in int

int salary = 25000.75;

Stored value:

25000

The fractional part is discarded.

2. Using char for Strings

Wrong

char name = "Aman";

Correct

char name[] = "Aman";

3. Confusing Characters and Integers

Wrong

char grade = 65;

While this stores the ASCII value for 'A', it is less readable.

Better

char grade = 'A';

4. Assuming Fixed Sizes Everywhere

Do not assume:

int = 4 bytes

on every platform. Always use sizeof() if the exact size matters.

Interview Questions

1. What is a data type?

A data type specifies the kind of data a variable can store, the memory required, and the operations that can be performed on it.

2. Why are data types needed?

They help the compiler allocate memory, interpret data correctly, and perform valid operations.

3. What are the categories of data types in C?

  • Primary (Basic)
  • Derived
  • User-Defined
  • Void

4. What is the purpose of void?

void represents the absence of a value or type. It is commonly used for functions that return nothing and for generic pointers (void *).

5. How can you determine the size of a data type?

By using the sizeof operator.

Example:

sizeof(int)

Summary

  • A data type tells the compiler what kind of data is stored, how much memory is needed, and which operations are valid.
  • C classifies data types into Primary, Derived, User-Defined, and Void.
  • The four primary data types are int, char, float, and double.
  • Different data types generally require different amounts of memory.
  • Use the sizeof operator to determine the size of a data type or variable.
  • Choosing the correct data type helps avoid memory waste and data loss.
