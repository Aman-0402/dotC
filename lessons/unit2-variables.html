C Programming / Unit 2 / Variables

Variables

What is a Variable?

A variable is a named memory location used to store data. The value stored in a variable can change during program execution, which is why it is called a variable.

Definition

A variable is a named memory location that stores a value, and its value can be changed during program execution.

Why Do We Need Variables?

Suppose you want to store a student's age.

Without a variable:

printf("%d", 20);

If the age changes to 21, you must modify the code.

With a variable:

int age = 20;

age = 21;

Now only the value changes, not the program structure.

Memory Representation

When a variable is created, the operating system allocates memory for it.

Variable Name        Memory Address        Stored Value
------------------------------------------------------
age                  1000                  20
marks                1004                  85
salary               1008                  45000.50

Note: The addresses above are examples. Actual memory addresses vary each time the program runs.

Syntax of Variable Declaration

data_type variable_name;

Example:

int age;

Here:

  • int → Data type
  • age → Variable name

Variable Initialization

Assigning a value to a variable when it is declared is called initialization.

int age = 20;

Here,

  • Declaration → int age
  • Initialization → = 20

Variable Assignment

You can also assign a value after declaration.

int age;

age = 20;

Complete Example

#include <stdio.h>

int main()
{
    int age;

    age = 20;

    printf("%d", age);

    return 0;
}

Output

20

Declaring Multiple Variables

int a, b, c;

or

int a = 10, b = 20, c = 30;

Example

#include <stdio.h>

int main()
{
    int x = 5, y = 10;

    printf("%d %d", x, y);

    return 0;
}

Output

5 10

Types of Variables

1. Local Variable

Declared inside a function or block.

#include <stdio.h>

int main()
{
    int x = 10;

    printf("%d", x);

    return 0;
}

Here, x is a local variable.

It exists only inside main().

2. Global Variable

Declared outside all functions.

#include <stdio.h>

int x = 100;

int main()
{
    printf("%d", x);

    return 0;
}

Output

100

Global variables can be accessed by all functions in the same file (unless restricted).

Variable Naming Rules

A variable name:

Rule 1

Must start with

  • Letter
  • Underscore (_)

Correct

int age;
int _count;

Wrong

int 2age;

Rule 2

Cannot contain spaces.

Wrong

int student age;

Correct

int studentAge;

Rule 3

Cannot use special symbols except _.

Wrong

int salary$;

Correct

int salary;

Rule 4

Cannot use keywords.

Wrong

int if;

Correct

int marks;

Rule 5

Variable names are case-sensitive.

int age = 20;
int Age = 30;

These are two different variables.

Variable Declaration vs Initialization

Declaration

int age;

Only memory is reserved.

Initialization

int age = 20;

Memory is reserved and a value is assigned.

Assignment

age = 30;

Changes the existing value.

Changing Variable Values

#include <stdio.h>

int main()
{
    int age = 20;

    printf("%d\n", age);

    age = 25;

    printf("%d", age);

    return 0;
}

Output

20
25

Memory Visualization

Program

int marks = 80;

Memory

Address        Variable        Value
------------------------------------
1000           marks            80

After

marks = 95;

Memory

Address        Variable        Value
------------------------------------
1000           marks            95

The address remains the same, but the stored value changes.

Common Beginner Mistakes

1. Using an undeclared variable

Wrong

age = 20;

Correct

int age;

age = 20;

2. Using reserved keywords

Wrong

int return;

Correct

int result;

3. Forgetting initialization (when a value is expected)

int age;

printf("%d", age);

The variable contains an indeterminate (garbage) value because it has not been initialized.

Better

int age = 0;

4. Duplicate declaration

Wrong

int age;

int age;

Correct

int age;

5. Confusing assignment with comparison

Wrong

int age = 20;

age == 30;

This compares values but does not change age.

Correct

age = 30;

Real-World Example

Suppose we want to store employee information.

#include <stdio.h>

int main()
{
    int employeeID = 101;
    float salary = 50000.50;
    char grade = 'A';

    printf("Employee ID : %d\n", employeeID);
    printf("Salary      : %.2f\n", salary);
    printf("Grade       : %c\n", grade);

    return 0;
}

Output

Employee ID : 101
Salary      : 50000.50
Grade       : A

Interview Questions

1. What is a variable?

A variable is a named memory location used to store data whose value can change during program execution.

2. What is the difference between declaration and initialization?

Declaration Initialization
Creates the variable Assigns its first value
int age; int age = 20;

3. Can a variable name start with a digit?

No. A variable name must start with a letter or an underscore (_).

4. Are variable names case-sensitive?

Yes.

age
Age
AGE

These are three different identifiers.

5. What happens if you use an uninitialized local variable?

It contains an indeterminate value (often referred to as a garbage value), and using it can lead to unpredictable results.

Q1. Declare and print a variable.

Age = 21

Q2. Store and print three variables.

#include <stdio.h>

int main()
{
    int rollNo = 15;
    float percentage = 88.75;
    char grade = 'A';

    printf("Roll No    : %d\n", rollNo);
    printf("Percentage : %.2f\n", percentage);
    printf("Grade      : %c\n", grade);

    return 0;
}

Output

Roll No    : 15
Percentage : 88.75
Grade      : A

Q3. Swap two variable values (using a third variable).

#include <stdio.h>

int main()
{
    int a = 10, b = 20, temp;

    temp = a;
    a = b;
    b = temp;

    printf("a = %d\n", a);
    printf("b = %d\n", b);

    return 0;
}

Output

a = 20
b = 10

Summary

  • A variable is a named memory location used to store data.
  • Variables must be declared before use.
  • Initialization assigns the first value; assignment updates it later.
  • Variable names must follow C naming rules.
  • Variables can be local or global.
  • Local variables should always be initialized before they are used.
