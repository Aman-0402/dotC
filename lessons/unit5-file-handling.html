File Handling

Programs normally store data in RAM (memory) while they are running. Once the program ends, all the data is lost. To store data permanently, C provides File Handling.

File handling allows a program to create, read, write, update, and delete files stored on secondary storage devices such as hard disks or SSDs.

What is a File?

A file is a collection of related data stored permanently on a storage device.

Examples:

  • Student Records
  • Employee Details
  • Banking Transactions
  • Text Documents
  • Images
  • Videos
  • Log Files

Unlike variables, data stored in a file remains available even after the program terminates.

File Basics

File Pointer

In C, every file is accessed using a file pointer.

A file pointer is a pointer of type FILE.

Syntax

FILE *fp;
  • FILE is a predefined structure available in <stdio.h>.
  • fp stores the address of the opened file.

Opening a File

The fopen() function opens a file.

Syntax

FILE *fp;

fp = fopen("filename", "mode");

Example

FILE *fp;

fp = fopen("student.txt", "r");

If the file opens successfully,

fp → File Address

If opening fails,

fp = NULL

Always check before using the file.

Example

if(fp == NULL)
{
    printf("File cannot be opened.");
}

Closing a File

Always close a file after use.

Syntax

fclose(fp);

Example

fclose(fp);

Closing a file:

  • Saves data properly
  • Frees memory
  • Prevents corruption

Text Files

Definition

A text file stores data in human-readable characters.

Examples

Hello World

100

Aman

95.5

Common extensions

.txt
.csv
.log

Characteristics of Text Files

  • Human-readable
  • Can be opened in Notepad or any text editor
  • Easy to edit manually
  • Slightly larger in size
  • Slower than binary files for large data

Writing to a Text File

Example

#include <stdio.h>

int main()
{
    FILE *fp;

    fp = fopen("student.txt", "w");

    if(fp == NULL)
    {
        printf("Cannot open file");
        return 1;
    }

    fprintf(fp, "Roll: %d\n", 101);
    fprintf(fp, "Name: Aman\n");
    fprintf(fp, "Marks: %.2f\n", 92.5);

    fclose(fp);

    printf("Data Written Successfully");

    return 0;
}

Output

Data Written Successfully

Contents of student.txt

Roll: 101
Name: Aman
Marks: 92.50

Reading from a Text File

Example

#include <stdio.h>

int main()
{
    FILE *fp;
    char ch;

    fp = fopen("student.txt", "r");

    if(fp == NULL)
    {
        printf("Cannot open file");
        return 1;
    }

    while((ch = fgetc(fp)) != EOF)
    {
        printf("%c", ch);
    }

    fclose(fp);

    return 0;
}

Output

Roll: 101
Name: Aman
Marks: 92.50

Appending Data

Append means adding data without deleting existing contents.

FILE *fp;

fp = fopen("student.txt", "a");

fprintf(fp, "\nCity: Ranchi");

fclose(fp);

Result

Roll: 101
Name: Aman
Marks: 92.50
City: Ranchi

Binary Files

Definition

A binary file stores data in binary format (0s and 1s) instead of readable text.

Example

student.dat
employee.bin
record.dat

The contents cannot be read directly using a text editor.

Characteristics of Binary Files

  • Not human-readable
  • Faster than text files
  • Smaller file size
  • Better for storing structures and large data
  • More secure against manual modification

Writing to a Binary File

Example

#include <stdio.h>

struct Student
{
    int roll;
    char name[20];
    float marks;
};

int main()
{
    struct Student s = {101, "Aman", 92.5};

    FILE *fp;

    fp = fopen("student.dat", "wb");

    if(fp == NULL)
    {
        printf("Cannot open file");
        return 1;
    }

    fwrite(&s, sizeof(s), 1, fp);

    fclose(fp);

    printf("Record Saved");

    return 0;
}

Reading from a Binary File

#include <stdio.h>

struct Student
{
    int roll;
    char name[20];
    float marks;
};

int main()
{
    struct Student s;

    FILE *fp;

    fp = fopen("student.dat", "rb");

    if(fp == NULL)
    {
        printf("Cannot open file");
        return 1;
    }

    fread(&s, sizeof(s), 1, fp);

    fclose(fp);

    printf("Roll : %d\n", s.roll);
    printf("Name : %s\n", s.name);
    printf("Marks: %.2f\n", s.marks);

    return 0;
}

Name : Aman
Marks: 92.50

Key Takeaways

  • A file stores data permanently on secondary storage.
  • Every file is accessed through a FILE * pointer.
  • fopen() opens a file, and fclose() closes it.
  • Text files store readable characters and are suitable for reports, logs, and documents.
  • Binary files store raw binary data, offering faster performance and compact storage, making them ideal for structures and large datasets.
  • Always check if fopen() returns NULL before performing file operations.
  • Closing a file with fclose() ensures data is saved correctly and resources are released.
