Dynamic Memory Allocation (DMA)

Definition

Dynamic Memory Allocation (DMA) is the process of allocating and releasing memory during program execution (runtime) instead of at compile time.

Unlike static memory allocation, the amount of memory required does not need to be known in advance. The programmer can request memory from the operating system whenever needed and release it after use.

Dynamic memory allocation functions are declared in the <stdlib.h> header file.

Why Dynamic Memory Allocation?

Suppose a program stores marks of students.

Static Allocation

int marks[100];

Problems:

  • Memory for 100 integers is reserved even if only 10 students exist.
  • If more than 100 students are required, the program fails.

Dynamic Allocation

Program Starts
      │
      ▼
Request Memory
      │
      ▼
Use Memory
      │
      ▼
Release Memory

Memory is allocated only when required, making programs more efficient.

Advantages of Dynamic Memory Allocation

  • Efficient memory utilization
  • Memory allocated at runtime
  • Can resize memory when required
  • Reduces memory wastage
  • Useful for dynamic data structures like linked lists, stacks, queues, and trees

1. malloc()

Definition

The malloc() (Memory Allocation) function allocates a specified number of bytes of memory.

The allocated memory contains garbage values (uninitialized data).

Syntax

pointer = (data_type *) malloc(size_in_bytes);

Parameters

  • size_in_bytes → Amount of memory required.

Return Value

  • Returns pointer to allocated memory.
  • Returns NULL if allocation fails.

Example

#include <stdio.h>
#include <stdlib.h>

int main()
{
    int *ptr;

    ptr = (int *)malloc(sizeof(int));

    if(ptr == NULL)
    {
        printf("Memory Allocation Failed");
        return 1;
    }

    *ptr = 100;

    printf("%d", *ptr);

    free(ptr);

    return 0;
}

Output

100

Allocating an Integer Array

arr = (int *)malloc(5 * sizeof(int));

2. calloc()

Definition

The calloc() (Contiguous Allocation) function allocates memory for multiple elements and initializes all bytes to zero.

Syntax

pointer = (data_type *)calloc(number_of_elements,
                              size_of_each_element);

Return Value

  • Pointer to allocated memory.
  • NULL if allocation fails.

Example

#include <stdio.h>
#include <stdlib.h>

int main()
{
    int *ptr;

    ptr = (int *)calloc(5, sizeof(int));

    if(ptr == NULL)
    {
        printf("Memory Allocation Failed");
        return 1;
    }

    for(int i = 0; i < 5; i++)
        printf("%d ", ptr[i]);

    free(ptr);

    return 0;
}

Output

0 0 0 0 0

Memory after calloc()

+----+----+----+----+----+
| 0  | 0  | 0  | 0  | 0  |
+----+----+----+----+----+

3. realloc()

Definition

The realloc() (Reallocation) function changes the size of previously allocated memory.

It can:

  • Increase memory
  • Decrease memory
  • Preserve existing data (when possible)

Syntax

pointer = realloc(pointer, new_size);

Example

#include <stdio.h>
#include <stdlib.h>

int main()
{
    int *ptr;

    ptr = (int *)malloc(3 * sizeof(int));

    ptr = (int *)realloc(ptr, 6 * sizeof(int));

    free(ptr);

    return 0;
}

After realloc()

Memory size has increased.

Example with Values

#include <stdio.h>
#include <stdlib.h>

int main()
{
    int *arr;

    arr = (int *)malloc(3 * sizeof(int));

    arr[0] = 10;
    arr[1] = 20;
    arr[2] = 30;

    arr = (int *)realloc(arr, 5 * sizeof(int));

    arr[3] = 40;
    arr[4] = 50;

    for(int i = 0; i < 5; i++)
        printf("%d ", arr[i]);

    free(arr);

    return 0;
}

Output

10 20 30 40 50

4. free()

Definition

The free() function releases memory that was previously allocated using malloc(), calloc(), or realloc().

If memory is not released, it results in a memory leak.

Syntax

free(pointer);

Example

#include <stdlib.h>

int *ptr;

ptr = (int *)malloc(sizeof(int));

free(ptr);

Good Practice

After freeing memory:

free(ptr);

ptr = NULL;

This prevents accidental access to freed memory (dangling pointer).

Memory Leak

A memory leak occurs when allocated memory is never released.

Example

int *ptr;

ptr = (int *)malloc(100 * sizeof(int));

/* free(ptr); Missing */

The allocated memory remains occupied until the program ends.

Dangling Pointer

int *ptr;

ptr = (int *)malloc(sizeof(int));

free(ptr);

Now:

ptr

↓

Invalid Memory

Correct way

free(ptr);

ptr = NULL;

Complete Example

#include <stdio.h>
#include <stdlib.h>

int main()
{
    int n;

    printf("Enter Number of Elements: ");
    scanf("%d", &n);

    int *arr = (int *)malloc(n * sizeof(int));

    if(arr == NULL)
    {
        printf("Memory Allocation Failed");
        return 1;
    }

    for(int i = 0; i < n; i++)
    {
        scanf("%d", &arr[i]);
    }

    printf("Elements:\n");

    for(int i = 0; i < n; i++)
    {
        printf("%d ", arr[i]);
    }

    free(arr);

    arr = NULL;

    return 0;
}

Common Mistakes

❌ Not checking if malloc() or calloc() returns NULL.

❌ Forgetting to call free(), causing memory leaks.

❌ Accessing memory after it has been freed (dangling pointer).

❌ Calling free() twice on the same pointer (double free).

❌ Losing the original pointer returned by malloc() before freeing it.

Key Takeaways

  • Dynamic Memory Allocation (DMA) allocates memory at runtime from the heap.
  • malloc() allocates a single block of memory and leaves it uninitialized.
  • calloc() allocates memory for multiple elements and initializes all bytes to zero.
  • realloc() changes the size of previously allocated memory while preserving existing data whenever possible.
  • free() releases dynamically allocated memory and should always be called when the memory is no longer needed.
  • Setting a pointer to NULL after free() is a good programming practice to avoid dangling pointers.
  • Dynamic memory allocation is essential for building flexible and efficient applications that work with data whose size is not known in advance.
