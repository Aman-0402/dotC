String Handling Functions

String handling functions are predefined library functions used to perform operations on strings such as finding length, copying, concatenating, comparing, and changing case.

These functions are declared in the header file:

#include <string.h>

Why Use String Functions?

Without string functions, many operations require loops.

For example:

  • Finding string length
  • Copying one string to another
  • Joining two strings
  • Comparing two strings

The string library makes these tasks simple and efficient.

Common String Functions

Function Purpose
strlen()Find length of string
strcpy()Copy one string to another
strcat()Concatenate (join) strings
strcmp()Compare two strings
strrev()*Reverse string (Non-standard)
strupr()*Convert to uppercase (Non-standard)

Note: strrev(), strupr(), and strlwr() are not part of the ISO C standard. They are available only in some compilers (such as older Turbo C or certain Windows compilers). For portable C programs, use loops or functions from <ctype.h> instead.

1. strlen()

Returns the number of characters in a string.

The null character ('\0') is not counted.

Syntax

strlen(string);

Example

#include <stdio.h>
#include <string.h>

int main()
{
    char name[] = "Programming";

    printf("Length = %lu", strlen(name));

    return 0;
}

Output

Length = 11

2. strcpy()

Copies one string into another.

Syntax

strcpy(destination, source);

Example

#include <stdio.h>
#include <string.h>

int main()
{
    char source[] = "Programming";
    char destination[30];

    strcpy(destination, source);

    printf("%s", destination);

    return 0;
}

Output

Programming

3. strcat()

Joins two strings.

The second string is added to the end of the first string.

Syntax

strcat(firstString, secondString);

Example

#include <stdio.h>
#include <string.h>

int main()
{
    char first[30] = "Hello ";
    char second[] = "World";

    strcat(first, second);

    printf("%s", first);

    return 0;
}

Output

Hello World

4. strcmp()

Compares two strings alphabetically.

Syntax

strcmp(string1, string2);

Return Values

Return Value Meaning
0Strings are equal
Negative ValueFirst string is smaller
Positive ValueFirst string is greater

Example 1

#include <stdio.h>
#include <string.h>

int main()
{
    char a[] = "Apple";
    char b[] = "Apple";

    if(strcmp(a,b)==0)
        printf("Equal");

    return 0;
}

Output

Equal

Example 2

#include <stdio.h>
#include <string.h>

int main()
{
    char a[] = "Cat";
    char b[] = "Dog";

    printf("%d", strcmp(a,b));

    return 0;
}

Output

Negative Value

(The exact negative number depends on the compiler.)

5. strrev() (Non-standard)

Reverses a string.

Syntax

strrev(string);

Example

#include <stdio.h>
#include <string.h>

int main()
{
    char name[] = "Programming";

    strrev(name);

    printf("%s", name);

    return 0;
}

Output

gnimmargorP

Note: strrev() is not available in standard C. It may not work on GCC, Clang, or other modern compilers.

Complete Example

#include <stdio.h>
#include <string.h>

int main()
{
    char s1[50] = "Hello";
    char s2[50] = " World";
    char copy[50];

    printf("Length of s1 = %lu\n", strlen(s1));

    strcpy(copy, s1);
    printf("Copied String = %s\n", copy);

    strcat(s1, s2);
    printf("Concatenated String = %s\n", s1);

    printf("Comparison Result = %d\n", strcmp("ABC","ABC"));

    return 0;
}

Output

Length of s1 = 5
Copied String = Hello
Concatenated String = Hello World
Comparison Result = 0

Important Notes

  • Include #include <string.h> to use standard string functions.
  • strlen() counts characters excluding the null character ('\0').
  • strcpy() overwrites the destination string, so ensure the destination array is large enough.
  • strcat() appends one string to another; the destination array must have sufficient space.
  • strcmp() compares strings based on their ASCII values and is case-sensitive.
  • strrev(), strupr(), and strlwr() are non-standard and should be avoided in portable C programs.
