C Programming / Unit 2 / Values

Values

What is a Value?

A value is the actual data stored in memory or used in an expression during program execution.

Everything a program processes is ultimately a value.

For example:

int age = 20;
  • age → Variable
  • 20 → Value

Here, the variable age stores the value 20.

Definition

A value is the actual piece of data stored in a variable, constant, or produced by an expression.

Why are Values Important?

Programs work by:

  • Taking input values
  • Processing those values
  • Producing output values

Example:

int a = 10;
int b = 20;

int sum = a + b;

Values involved:

10
20
30

Types of Values in C

There are several kinds of values.

Values
│
├── Integer Values
├── Floating-Point Values
├── Character Values
├── String Values
├── Boolean-like Values
└── Expression Values

1. Integer Values

Whole numbers.

Examples

10
25
-100
0
500

Program

#include <stdio.h>

int main()
{
    int marks = 95;

    printf("%d", marks);

    return 0;
}

Output

95

2. Floating-Point Values

Decimal numbers.

Examples

3.14
99.99
0.5
-25.6

Program

#include <stdio.h>

int main()
{
    float pi = 3.14;

    printf("%.2f", pi);

    return 0;
}

Output

3.14

3. Character Values

Single characters enclosed in single quotes.

Examples

'A'
'Z'
'7'
'#'

Program

#include <stdio.h>

int main()
{
    char grade = 'A';

    printf("%c", grade);

    return 0;
}

Output

A

4. String Values

Sequence of characters enclosed in double quotes.

Examples

"Hello"
"India"
"C Programming"

Program

#include <stdio.h>

int main()
{
    char name[] = "Aman";

    printf("%s", name);

    return 0;
}

Output

Aman

5. Boolean-like Values

C (before C99) does not have a built-in Boolean type. Instead:

0      → False
Non-zero → True

Example

#include <stdio.h>

int main()
{
    printf("%d\n", 5 > 3);

    printf("%d", 5 < 3);

    return 0;
}

Output

1
0

6. Expression Values

Expressions produce values.

Example

10 + 20

Result:

30

Program

#include <stdio.h>

int main()
{
    int result = 10 + 20;

    printf("%d", result);

    return 0;
}

Output

30

Literal Values

A literal is a value written directly in the source code.

Examples

100
3.14
'A'
"Hello"

Program

int age = 20;

Here,

20

is a literal value.

Variable Value

Variables store values.

int age = 20;

Memory

Variable      Value
-------------------
age             20

Later

age = 25;

Memory

Variable      Value
-------------------
age             25

The variable remains the same, but its value changes.

Constant Value

Constants never change.

const int MAX = 100;

Value

100

remains fixed.

Input Values

Users can provide values during execution.

Example

#include <stdio.h>

int main()
{
    int age;

    scanf("%d", &age);

    printf("%d", age);

    return 0;
}

Input

25

Output

25

Output Values

Programs produce values using printf().

printf("%d", 50);

Output

50

Temporary Values

Some values exist only while evaluating an expression.

Example

int result = (10 + 20) * 5;

Calculation:

10 + 20 = 30

30 × 5 = 150

Here,

30

is a temporary intermediate value.

Memory Representation

Program

int marks = 90;

Memory

Address        Variable        Value
------------------------------------
1000            marks            90

After

marks = 95;

Memory

Address        Variable        Value
------------------------------------
1000            marks            95

Only the value changes.

Common Beginner Mistakes

1. Confusing Variable and Value

Wrong understanding:

age is the value.

Correct:

age → Variable

20 → Value

2. Using the Wrong Data Type

int pi = 3.14;

Stored value:

3

The decimal part is lost because int stores only whole numbers.

Correct

float pi = 3.14;

3. Using Double Quotes for Characters

Wrong

char ch = "A";

Correct

char ch = 'A';

4. Forgetting Initialization

int age;

printf("%d", age);

The printed value is indeterminate (garbage) because age was never initialized.

5. Assigning Text to an Integer

Wrong

int age = "Twenty";

Correct

int age = 20;

Interview Questions

1. What is a value in C?

A value is the actual data stored in a variable, constant, or produced by an expression.

2. What is the difference between a variable and a value?

  • A variable is a named memory location.
  • A value is the data stored in that memory location.

3. What is a literal value?

A literal is a value written directly in the program, such as 100, 3.14, 'A', or "Hello".

4. Can a variable's value change?

Yes. The value of a variable can change during program execution unless the variable is declared with const.

5. What values represent true and false in C?

  • 0 → False
  • Any non-zero value → True

Q1. Store and print different types of values.

#include <stdio.h>

int main()
{
    int age = 20;
    float height = 5.9;
    char grade = 'A';
    char name[] = "Aman";

Output

Height: 5.9
Grade: A
Name: Aman

Summary

  • A value is the actual data stored in memory or produced by an expression.
  • Values can be integer, floating-point, character, string, Boolean-like, or expression results.
  • Literals are values written directly in the source code.
  • Variables hold values, and those values can change during execution.
  • Choosing the correct data type is essential to preserve the intended value.
