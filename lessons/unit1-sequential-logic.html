Problem Solving with Sequential Logic Structure

Before writing a program, we first think about how to solve the problem. This is called Problem Solving.

Programming is not just writing code — it's about finding the correct solution first.

What is Problem Solving?

Problem solving is the process of understanding a problem, planning the solution, and then converting that solution into a program.

Steps of Problem Solving

Problem
   ↓
Understand the Problem
   ↓
Plan the Solution
   ↓
Write Algorithm
   ↓
Draw Flowchart (Optional)
   ↓
Write Program
   ↓
Test & Debug

What is Logic?

Logic is the sequence of steps used to solve a problem.

Example

Problem: Calculate the area of a rectangle.

Logic:

  1. Read length.
  2. Read width.
  3. Multiply length × width.
  4. Display area.

What is Sequential Logic?

Sequential Logic means executing statements one after another in the exact order they are written.

There is:

  • No decision (if)
  • No repetition (for, while)
  • Every step runs once from top to bottom.

It is the simplest program structure.

Sequential Structure

Start
  ↓
Step 1
  ↓
Step 2
  ↓
Step 3
  ↓
End

Every instruction executes exactly once.

Example 1: Add Two Numbers

Problem: Find the sum of two numbers.

Sequential Steps

Start
Input A
Input B
Sum = A + B
Display Sum
Stop

C Program

#include <stdio.h>

int main()
{
    int a, b, sum;

    printf("Enter two numbers: ");
    scanf("%d %d", &a, &b);

    sum = a + b;

    printf("Sum = %d", sum);

    return 0;
}

Dry Run

Suppose

a = 10
b = 20

Execution:

Step 1 → Read 10
Step 2 → Read 20
Step 3 → sum = 10 + 20 = 30
Step 4 → Print 30

Output

Sum = 30

Example 2: Calculate Simple Interest

Formula

SI = (P × R × T) / 100

Sequential Steps

Read Principal
Read Rate
Read Time
Calculate SI
Display SI

Again, every statement executes only once.

Characteristics of Sequential Logic

  • Instructions execute from top to bottom.
  • No conditions are checked.
  • No loops are used.
  • Easy to understand.
  • Best for simple calculations.

Types of Program Control Structures

There are three basic control structures in programming.

1. Sequential Structure

Statements execute one after another.

Example:

Read Number
Square = Number × Number
Print Square

2. Selection Structure

Used when a decision is required.

Example:

If marks >= 40
    Pass
Else
    Fail

Uses:

  • if
  • if-else
  • switch

3. Iteration (Looping) Structure

Used to repeat a set of statements.

Example:

Print Hello 5 times

Uses:

  • for
  • while
  • do-while

Real-Life Example of Sequential Logic

Making Tea:

Boil water
↓
Add tea leaves
↓
Add sugar
↓

↓

↓

Every step happens in order without any decision or repetition.

Why is Sequential Logic Important?

  • It is the foundation of programming.
  • Every program starts with sequential execution.
  • Even programs with if or loops still execute sequentially until they reach those statements.
  • Understanding sequential logic makes learning conditions and loops much easier.

Key Points to Remember

  • Problem solving means finding the correct solution before coding.
  • Logic is the sequence of steps used to solve a problem.
  • Sequential Logic executes statements one after another in order.
  • It does not use decisions (if) or loops (for, while).
  • The three control structures in programming are:
    1. Sequential
    2. Selection
    3. Iteration
