Bubble Sort

Bubble Sort is the simplest sorting algorithm. It repeatedly compares two adjacent elements and swaps them if they are in the wrong order. This process continues until the entire array is sorted.

The largest element "bubbles up" to its correct position at the end of the array after each pass, which is why it is called Bubble Sort.

Real-Life Analogy

Imagine bubbles rising in a glass of water.

  • Small bubbles stay near the bottom.
  • Bigger bubbles rise to the top.

Similarly, in Bubble Sort, the largest element moves toward the end of the array after every pass.

How Bubble Sort Works

Suppose we have the following array:

5 3 8 4 2

We compare adjacent elements one by one.

Pass 1

Compare 5 and 3

5 3 8 4 2

Since 5 > 3, swap them.

3 5 8 4 2

Compare 5 and 8

3 5 8 4 2

Correct order, so no swap.

Compare 8 and 4

3 5 8 4 2

Swap.

3 5 4 8 2

Compare 8 and 2

Swap.

3 5 4 2 8

After Pass 1, the largest element (8) has reached its correct position.

Pass 2

Start from the beginning again.

3 5 4 2 8

Compare 3 and 5

No swap.

Compare 5 and 4

Swap.

3 4 5 2 8

Compare 5 and 2

Swap.

3 4 2 5 8

After Pass 2, 5 reaches its correct position.

Pass 3

3 4 2 5 8

Compare 3 and 4

No swap.

Compare 4 and 2

Swap.

3 2 4 5 8

Pass 4

3 2 4 5 8

Compare 3 and 2

Swap.

2 3 4 5 8

Array is now sorted.

Notice that after each pass, one largest unsorted element reaches its final position.

Bubble Sort Algorithm

Start

Repeat (n - 1) times

    Compare adjacent elements

    If left element > right element

        Swap them

Stop

Bubble Sort Flow

Start
   │
Compare Adjacent Elements
   │
Swap if Left > Right
   │
Move to Next Pair
   │
End of Pass?
   │
No ───────────────► Continue
   │
Yes
   │
Repeat Next Pass
   │
Sorted

C Program

#include <stdio.h>

int main()
{
    int arr[] = {5, 3, 8, 4, 2};
    int n = 5;

    for (int i = 0; i < n - 1; i++)
    {
        for (int j = 0; j < n - i - 1; j++)
        {
            if (arr[j] > arr[j + 1])
            {
                int temp = arr[j];
                arr[j] = arr[j + 1];
                arr[j + 1] = temp;
            }
        }
    }

    printf("Sorted Array:\n");

    for (int i = 0; i < n; i++)
        printf("%d ", arr[i]);

    return 0;
}

Output

Sorted Array:
2 3 4 5 8

Explanation of the Code

Outer Loop

for(int i = 0; i < n - 1; i++)
  • Controls the number of passes.
  • Total passes = n − 1.

Inner Loop

for(int j = 0; j < n - i - 1; j++)
  • Compares adjacent elements.
  • The -i avoids comparing elements that are already in their correct positions at the end of the array.

Swap Condition

if(arr[j] > arr[j + 1])

If the left element is greater than the right element, they are exchanged.

Optimized Bubble Sort

If no swaps occur during a pass, the array is already sorted, so we can stop early.

#include <stdio.h>

int main()
{
    int arr[] = {5, 3, 8, 4, 2};
    int n = 5;

    for (int i = 0; i < n - 1; i++)
    {
        int swapped = 0;

        for (int j = 0; j < n - i - 1; j++)
        {
            if (arr[j] > arr[j + 1])
            {
                int temp = arr[j];
                arr[j] = arr[j + 1];
                arr[j + 1] = temp;
                swapped = 1;
            }
        }

        if (!swapped)
            break;
    }

    for (int i = 0; i < n; i++)
        printf("%d ", arr[i]);

    return 0;
}

Time Complexity

Case Complexity
Best Case (already sorted, optimized)O(n)
Average CaseO(n²)
Worst Case (reverse order)O(n²)

Space Complexity

O(1)

Bubble Sort uses only one temporary variable for swapping, so it requires constant extra memory.

Advantages

  • Easy to understand and implement.
  • In-place sorting (no extra array needed).
  • Stable sorting algorithm (equal elements keep their original order).
  • Efficient for very small datasets.
  • Optimized version performs well on nearly sorted arrays.

Disadvantages

  • Very slow for large datasets.
  • Requires many comparisons and swaps.
  • Not suitable for performance-critical applications.

Applications

  • Educational purposes to learn sorting concepts.
  • Sorting very small datasets.
  • Detecting whether a list is already sorted (using the optimized version).
  • Embedded systems with tiny data sizes.

Key Points to Remember

  • Bubble Sort compares adjacent elements.
  • The largest unsorted element moves to the end after each pass.
  • Number of passes = n − 1.
  • It is stable and in-place.
  • Best Case: O(n) (optimized version).
  • Average/Worst Case: O(n²).
