Storage Classes

Storage classes are one of the most important topics in C and are frequently asked in interviews, university exams, and competitive programming.

What is a Storage Class?

A storage class defines the properties of a variable or function, such as:

  • Where it is stored in memory
  • Its scope (visibility)
  • Its lifetime (how long it exists)
  • Its linkage (whether it can be accessed from other files)

Definition

A storage class specifies the scope, lifetime, memory location, and linkage of variables and functions in C.

Why Do We Need Storage Classes?

Suppose you have two variables:

int a = 10;
static int b = 20;

Although both store integers, they behave differently.

Questions like these are answered by storage classes:

  • Where are they stored?
  • Who can access them?
  • How long do they exist?
  • Can another file use them?

1. auto Storage Class

auto is the default storage class for local variables.

You normally don't write it because the compiler assumes it automatically.

Syntax

auto int age;

Equivalent to:

int age;

Example

#include <stdio.h>

int main()
{
    auto int x = 10;

    printf("%d", x);

    return 0;
}

Output

10

Memory

main()

Stack Memory

+-----------+
| x = 10    |
+-----------+

When main() finishes:

Stack Cleared

x destroyed

Characteristics of auto

  • Default for local variables
  • Stored in Stack Memory
  • Exists only while the function executes
  • Not accessible outside the function

2. register Storage Class

The register keyword requests the compiler to store a variable in a CPU register instead of RAM for faster access.

Important: It is only a request. The compiler may ignore it if there are not enough CPU registers or if optimization decides otherwise.

Syntax

register int count;

Example

#include <stdio.h>

int main()
{
    register int i;

    for(i = 1; i <= 5; i++)
    {
        printf("%d ", i);
    }

    return 0;
}

Output

1 2 3 4 5

Characteristics of register

  • Local scope
  • Function lifetime
  • Faster access (if stored in a CPU register)
  • Default value is indeterminate (garbage)
  • Address cannot normally be taken using &

Wrong Example

register int x = 10;

printf("%p", &x);

This is not allowed because a register variable may not have a memory address that can be accessed.

3. static Storage Class

static is one of the most important storage classes.

A static variable:

  • Is initialized only once.
  • Retains its value between function calls.
  • Exists throughout the program execution.

Static Local Variable

Example

#include <stdio.h>

void counter()
{
    static int count = 0;

    count++;

    printf("%d\n", count);
}

int main()
{
    counter();
    counter();
    counter();

    return 0;
}

Output

1
2
3

Memory

First call

count = 0

↓

count++

↓

1

Second call

count already exists

↓

2

Third call

count

↓

3

The variable is not recreated every time.

Compare with auto

#include <stdio.h>

void counter()
{
    int count = 0;

    count++;

    printf("%d\n", count);
}

int main()
{
    counter();
    counter();
    counter();

    return 0;
}

Output

1
1
1

Each function call creates a new local variable.

Static Global Variable

static int total = 100;

This variable:

  • Exists throughout the program.
  • Is accessible only within the current source file (internal linkage).

Characteristics of static

  • Lifetime: Entire program
  • Default value: 0
  • Stored in Data Segment
  • Retains value between function calls
  • Can restrict visibility of global variables/functions to the current file

4. extern Storage Class

extern is used to declare a variable that is defined elsewhere.

It tells the compiler:

"The actual variable exists in another place."

Example (Single File)

#include <stdio.h>

int number = 100;

int main()
{
    extern int number;

    printf("%d", number);

    return 0;
}

Output

100

Multi-File Example

file1.c

int marks = 95;

file2.c

#include <stdio.h>

extern int marks;

int main()
{
    printf("%d", marks);

    return 0;
}

Here:

  • marks is defined in file1.c
  • extern allows file2.c to use it

Characteristics of extern

  • Refers to an existing global variable
  • Does not create new storage
  • Lifetime: Entire program
  • Default value: 0 (for the actual global variable if not explicitly initialized)
  • Stored in Data Segment

Common Beginner Mistakes

1. Expecting auto Variables to Remember Values

void test()
{
    int x = 0;
    x++;
}

x becomes 1 every time the function is called because it is recreated on each call.

2. Using & with register

register int x;

printf("%p", &x);

Not allowed.

3. Forgetting static Preserves Values

static int count;

The value is not reset every time the function is called.

4. Confusing extern with Variable Definition

extern int x;

This declares x; it does not create storage.

Exam Tips

  • ⭐ auto → Default local variable → Stack
  • ⭐ register → Fast access → CPU Register (if possible)
  • ⭐ static → Retains value → Entire Program
  • ⭐ extern → Uses a global variable defined elsewhere
  • ⭐ Scope ≠ Lifetime ≠ Linkage
  • ⭐ static is one of the most frequently asked interview topics.

Summary

  • Storage classes define scope, lifetime, memory location, and linkage.
  • C has four storage classes: auto, register, static, and extern.
  • auto and register are local and exist only during function execution.
  • static variables retain their values throughout the program and can have internal linkage.
  • extern is used to access global variables defined elsewhere without allocating new storage.
  • Understanding storage classes is essential for writing efficient and maintainable C programs.
