Conditional Statements

Introduction

Until now, every C program you've written has executed line by line from top to bottom.

But in real-life applications, programs need to make decisions.

Examples:

  • Should the student pass or fail?
  • Is the password correct?
  • Can a user log in?
  • Is a number even or odd?
  • Should the ATM allow withdrawal?

Decision-making is done using Conditional Statements.

What is a Conditional Statement?

A Conditional Statement allows a program to execute different blocks of code depending on whether a condition is true or false.

Think of it like real life.

If it is raining
    Take an umbrella
Else
    Wear sunglasses

The computer works exactly the same way.

Condition → True → Execute one block

Condition → False → Execute another block

Types of Conditional Statements in C

There are five major decision-making statements.

Statement Purpose
ifExecutes code only if condition is true
if...elseChooses between two blocks
else if LadderChecks multiple conditions
Nested ifif inside another if
switch-caseSelects one option among many

1. if Statement

The if statement is the simplest conditional statement.

It executes code only when the condition is true.

If the condition is false, nothing happens.

Syntax

if (condition)
{
    // statements
}

Flow

Condition

   |
   |
True? -------- No
 |
Yes
 |
Execute Block
 |
Next Statement

Example 1

#include <stdio.h>

int main()
{
    int age = 20;

    if(age >= 18)
    {
        printf("Eligible to vote");
    }

    return 0;
}

Output

Eligible to vote

Example 2

#include <stdio.h>

int main()
{
    int marks = 80;

    {
        printf("Pass");
    }

    printf("\nProgram End");

    return 0;
}

Output

Pass
Program End

{
    int marks = 30;

Output

The if block is skipped because the condition is false.

2. if...else Statement

Sometimes we want one action when the condition is true and another when it is false.

For this, we use if...else.

Syntax

if(condition)
{
    // True block
}
else
{
    // False block
}

Flow

          Condition
             |
      ----------------
      |              |
    True          False
      |              |
 True Block     False Block
      |
 Next Statement

Example 1

#include <stdio.h>

int main()
{
    int age = 16;

    if(age >=18)
    {
        printf("Eligible to vote");
    }
    else
    {
        printf("Not eligible");
    }

    return 0;
}

Output

Not eligible

Example 2

Even or Odd

#include <stdio.h>

int main()
{
    int num = 15;

    if(num % 2 == 0)
    {
        printf("Even");
    }
    else
    {
        printf("Odd");
    }

    return 0;
}

Output

Odd

3. else if Ladder

When there are more than two choices, we use else if.

The program checks conditions from top to bottom.

The first true condition is executed.

The remaining conditions are skipped.

Syntax

if(condition1)
{

}
else if(condition2)
{

}
else if(condition3)
{

}
else
{

}

Flow

     |

 |
No
 |
Condition 2
 |

 |
No
 |
Condition 3
 |
True? ----Yes--> Block 3
 |
No
 |
Else Block

Example

Student Grade

{
    int marks = 76;

    if(marks >=90)
    {
        printf("Grade A");

        printf("Grade C");

        printf("Grade D");

    {
        printf("Fail");

4. Nested if

A Nested if means placing one if statement inside another if statement.

It is useful when a second condition should only be checked if the first one is true.

Syntax

if(condition1)
{
    if(condition2)
    {

    }
}

Flow

Condition 1
     |
True?
 |
Yes
 |
Condition 2
 |
True?
 |
Execute Block

Example

#include <stdio.h>

int main()
{
    int age = 22;
    int citizen = 1;

    if(age >=18)
    {
        if(citizen == 1)
        {
            printf("Eligible to vote");
        }
    }

    return 0;
}

Output

Eligible to vote

Example

#include <stdio.h>

int main()
{
    int username = 1;
    int password = 1;

    if(username == 1)
    {
        if(password == 1)
        {
            printf("Login Successful");
        }
        else
        {
            printf("Wrong Password");
        }
    }
    else
    {
        printf("Invalid Username");
    }

    return 0;
}

Output

Login Successful

5. switch-case Statement

The switch statement is used when one variable needs to be compared with multiple constant values.

It is a cleaner alternative to writing many else if statements.

Syntax

switch(expression)
{
    case value1:
        statements;
        break;

    case value2:
        statements;
        break;

    default:
        statements;
}

How switch Works

  1. The expression is evaluated once.
  2. Its value is compared with each case.
  3. If a match is found, that case executes.
  4. break exits the switch.
  5. If no case matches, the default block executes.

Example

#include <stdio.h>

int main()
{
    int day = 3;

    switch(day)
    {
        case 1:
            printf("Monday");
            break;

        case 2:
            printf("Tuesday");
            break;

        case 3:
            printf("Wednesday");
            break;

        case 4:
            printf("Thursday");
            break;

        default:
            printf("Invalid Day");
    }

    return 0;
}

Output

Wednesday

Example

Calculator

#include <stdio.h>

int main()
{
    int a = 20, b = 10;
    char op = '+';

    switch(op)
    {
        case '+':
            printf("%d", a + b);
            break;

        case '-':
            printf("%d", a - b);
            break;

        case '*':
            printf("%d", a * b);
            break;

        case '/':
            printf("%d", a / b);
            break;

        default:
            printf("Invalid Operator");
    }

    return 0;
}

Output

30

Importance of break

Without break, execution continues into the next case. This behavior is called fall-through.

Example:

#include <stdio.h>

int main()
{
    int num = 2;

    switch(num)
    {
        case 1:
            printf("One\n");

        case 2:
            printf("Two\n");

        case 3:
            printf("Three\n");

        default:
            printf("End\n");
    }

    return 0;
}

Output

Two
Three
End

Because there is no break, execution continues through all following cases.

Rules of switch-case

  • The expression must evaluate to an integer, character, or enumeration type.
  • Each case value must be unique.
  • case values must be constant expressions.
  • default is optional but recommended.
  • break is optional, but omitting it causes fall-through.

Comparison of Conditional Statements

Statement Used For Number of Conditions
ifExecute code only when a condition is true1
if...elseChoose between two alternatives2
else if LadderCheck multiple conditions in orderMultiple
Nested ifVerify a secondary condition after a primary oneMultiple (hierarchical)
switch-caseCompare one expression against several constant valuesMultiple constant values

Summary

  • Conditional statements enable programs to make decisions.
  • if executes code only when a condition is true.
  • if...else selects between two possible actions.
  • else if ladders are ideal for handling multiple conditions.
  • Nested if statements allow decision-making within another decision.
  • switch-case provides a clean way to choose among multiple constant options and commonly uses break to prevent fall-through.
