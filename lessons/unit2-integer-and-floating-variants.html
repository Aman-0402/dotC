Integer Variants and Floating-Point Variants

These topics explain the different numeric data type variants available in C. Variants allow you to choose the appropriate type based on memory usage, value range, and precision.

Note: The exact sizes and ranges shown below are common on modern systems but are implementation-dependent. Always use sizeof() to verify on your platform.

Part 1: Integer Variants

What are Integer Variants?

Integer variants are different forms of integer data types that differ in:

  • Memory size
  • Range of values
  • Whether they can store negative numbers

Integer Family

Integer Variants
│
├── short

1. short (short int)

Used when storing small whole numbers.

Syntax

short int marks = 100;

or

short marks = 100;

Example

#include <stdio.h>

int main()
{
    short age = 25;

    printf("%hd", age);

    return 0;
}

Output

25

Typical Size

2 bytes

Typical Range

-32,768 to 32,767

2. int

The default integer type in C.

Syntax

int number = 100;

Example

#include <stdio.h>

int main()
{
    int salary = 50000;

    printf("%d", salary);

    return 0;
}

Output

50000

Typical Size

4 bytes

Typical Range

-2,147,483,648 to 2,147,483,647

3. long (long int)

Used for storing larger integer values.

Syntax

long population = 1500000000;

Example

#include <stdio.h>

int main()
{
    long population = 1500000000L;

    printf("%ld", population);

    return 0;
}

Output

1500000000

Typical Size

4 or 8 bytes

4. long long (long long int)

Stores very large integers.

Syntax

long long distance = 1234567890123LL;

Example

#include <stdio.h>

int main()
{
    long long stars = 9876543210123LL;

    printf("%lld", stars);

    return 0;
}

Output

9876543210123

Typical Size

8 bytes

Typical Range

-9,223,372,036,854,775,808
to
9,223,372,036,854,775,807

A signed integer stores:

  • Negative numbers
  • Positive numbers

An unsigned integer stores:

  • Zero

Practical Example

#include <stdio.h>

int main()
{
    short a = 100;
    int b = 50000;

Common Integer Mistakes

Wrong

short value = 50000;

50000 exceeds the range of a typical short, causing overflow or implementation-defined behavior.

Wrong

unsigned int x = -10;

Unsigned types cannot represent negative values, leading to unexpected results.

Part 2: Floating-Point Variants

What are Floating-Point Variants?

Floating-point variants are used to store decimal numbers with different levels of precision and range.

Floating-Point Family

Floating Variants
│
├── float
├── double
└── long double

1. float

Stores decimal values with single precision.

Syntax

float pi = 3.14f;

Example

#include <stdio.h>

int main()
{
    float price = 99.95f;

    printf("%.2f", price);

    return 0;
}

Output

99.95

Typical Size

4 bytes

Approximate Precision

6–7 decimal digits

2. double

Stores decimal values with double precision.

Example

#include <stdio.h>

int main()
{
    double pi = 3.141592653589793;

    printf("%.15lf", pi);

    return 0;
}

Output

3.141592653589793

Typical Size

8 bytes

Approximate Precision

15–16 decimal digits

3. long double

Stores decimal values with extended precision.

Example

#include <stdio.h>

int main()
{
    long double value = 12345.678901234567L;

    printf("%.18Lf", value);

    return 0;
}

Typical Size

16 bytes (commonly, but implementation-dependent)

Approximate Precision

18+ decimal digits

Floating-Point Comparison

Type Typical Size Approximate Precision
float4 bytes6–7 digits
double8 bytes15–16 digits
long double16 bytes18+ digits

Memory Illustration

float price = 99.95f;
Memory

+-------------+
|   99.95     |
+-------------+

Floating-Point Format Specifiers

Type Format Specifier
float%f
double%lf (commonly used with scanf; printf also uses %f)
long double%Lf

Important: In printf, both float and double are printed using %f because float arguments are automatically promoted to double. In scanf, use %f for float and %lf for double.

Precision Demonstration

#include <stdio.h>

int main()
{
    float f = 3.141592653589793f;
    double d = 3.141592653589793;

    printf("Float  : %.15f\n", f);
    printf("Double : %.15f\n", d);

    return 0;
}

Sample Output

Float  : 3.141592741012573
Double : 3.141592653589793

Notice that double preserves more precision.

Choosing the Right Floating Type

Situation Recommended Type
Simple decimal valuesfloat
Financial calculationsdouble
Scientific calculationsdouble or long double
High-precision mathematicslong double

Common Floating-Point Mistakes

1. Using float for High Precision

float pi = 3.141592653589793;

Much of the precision is lost.

Better

double pi = 3.141592653589793;

2. Comparing Floating-Point Values Directly

Wrong

if (0.1 + 0.2 == 0.3)
{
    printf("Equal");
}

Due to floating-point representation, direct equality comparisons can fail. A better approach is to compare the difference against a small tolerance.

Exam Tips

  • ⭐ int is the default integer type.
  • ⭐ long long is used for very large integer values.
  • ⭐ unsigned cannot store negative numbers.
  • ⭐ double provides much higher precision than float.
  • ⭐ long double offers the highest precision among the standard floating-point types.
  • ⭐ Use the correct format specifier (%hd, %d, %ld, %lld, %f, %Lf) to avoid incorrect output.

Summary

Integer Variants

  • short → Small integers
  • int → General-purpose integers
  • long → Larger integer range
  • long long → Very large integers
  • signed → Positive and negative values
  • unsigned → Non-negative values only

Floating-Point Variants

  • float → Single precision
  • double → Double precision
  • long double → Extended precision

Choosing the correct variant improves memory efficiency, performance, and accuracy, making your C programs more reliable and efficient.
