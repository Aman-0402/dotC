Input & Output (Input Functions & Output Functions)

Input and Output (I/O) are fundamental operations in every C program. A program becomes interactive when it can accept data from the user (Input) and display results (Output).

This topic covers:

  • Input & Output (I/O)
  • Input Functions
  • Output Functions

What is Input?

Input is the process of providing data to a program.

The data may come from:

  • Keyboard
  • Mouse
  • Scanner
  • File
  • Network

In this topic, we will focus on keyboard input.

Definition

Input is the process of entering data into a program for processing.

Real-Life Example

Enter Your Name
↓

Aman

Here,

Aman

is the input.

What is Output?

Output is the information displayed by the program after processing the input.

Definition

Output is the information produced by a program and displayed to the user or another device.

Example

Input

Number = 5

Processing

Square = 5 × 5

Output

25

Input → Process → Output (IPO Model)

          │
          ▼
+----------------+
|   Processing   |
+----------------+
          │
          ▼
        OUTPUT

Input and Output in C

C provides library functions for performing Input and Output.

These functions are available through

#include <stdio.h>

Without including this header file, functions like printf() and scanf() cannot be used.

Part 1: Output Functions

Output functions display information on the screen.

1. printf()

The most commonly used output function.

Definition

printf() prints formatted output to the screen.

Syntax

printf("message");

Example

#include <stdio.h>

int main()
{
    printf("Hello World");

    return 0;
}

Output

Hello World

Printing Variables

#include <stdio.h>

int main()
{
    int age = 20;

    printf("%d", age);

    return 0;
}

Output

20

Multiple Values

#include <stdio.h>

int main()
{
    int age = 20;
    float marks = 95.5;
    char grade = 'A';

    printf("Age = %d\n", age);
    printf("Marks = %.1f\n", marks);
    printf("Grade = %c\n", grade);

    return 0;
}

Output

Age = 20
Marks = 95.5
Grade = A

Part 2: Input Functions

Input functions read data from the keyboard.

1. scanf()

The most commonly used input function.

Definition

scanf() reads formatted input from the keyboard.

Syntax

scanf("format", &variable);

Notice the & operator before variables like int, float, and char. It passes the memory address of the variable so scanf() can store the input there.

Integer Input

#include <stdio.h>

int main()
{
    int age;

    printf("Enter Age: ");
    scanf("%d", &age);

    printf("Age = %d", age);

    return 0;
}

Sample Output

Enter Age: 20
Age = 20

Float Input

#include <stdio.h>

int main()
{
    float salary;

    printf("Enter Salary: ");
    scanf("%f", &salary);

    printf("%.2f", salary);

    return 0;
}

Character Input

#include <stdio.h>

int main()
{
    char grade;

    printf("Enter Grade: ");
    scanf(" %c", &grade);

    printf("%c", grade);

    return 0;
}

Notice the space before %c. It tells scanf() to skip any leftover whitespace (such as a newline from previous input).

String Input

#include <stdio.h>

int main()
{
    char name[30];

    printf("Enter Name: ");
    scanf("%29s", name);

    printf("%s", name);

    return 0;
}

Sample Input

Aman

Output

Aman

scanf("%s", ...) stops reading when it encounters whitespace.

Multiple Inputs

#include <stdio.h>

int main()
{
    int age;
    float marks;

    printf("Enter Age and Marks: ");

    scanf("%d %f", &age, &marks);

    printf("%d %.2f", age, marks);

    return 0;
}

Input

20 95.5

Output

20 95.50

2. getchar()

Reads a single character.

Syntax

char ch = getchar();

Example

#include <stdio.h>

int main()
{
    char ch;

    printf("Enter Character: ");

    ch = getchar();

    printf("%c", ch);

    return 0;
}

3. fgets()

Reads an entire line of text, including spaces (up to a specified limit).

Syntax

fgets(array, size, stdin);

Example

#include <stdio.h>

int main()
{
    char name[50];

    printf("Enter Full Name: ");

    fgets(name, sizeof(name), stdin);

    printf("%s", name);

    return 0;
}

Input

Aman Kumar

Output

Aman Kumar

scanf() vs fgets()

scanf("%s") fgets()
Stops at first spaceReads spaces too
Good for one wordGood for full sentences
Can overflow if width is omittedSafer because maximum size is specified

Common Beginner Mistakes

1. Forgetting & in scanf()

Wrong

scanf("%d", age);

Correct

scanf("%d", &age);

2. Using & with a Character Array

Wrong

scanf("%s", &name);

Correct

scanf("%29s", name);

Array names already represent their starting address.

3. Mixing scanf() and getchar()

scanf("%d", &age);
ch = getchar();

The getchar() may read the leftover newline ('\n') instead of waiting for new input.

4. Using %d for Float

Wrong

scanf("%d", &marks);

Correct

scanf("%f", &marks);

5. Ignoring Buffer Limits

Wrong

scanf("%s", name);

Safer

scanf("%29s", name);

This limits input to avoid overflowing a 30-character array.

Interview Questions

1. What is Input?

The process of entering data into a program.

2. What is Output?

The information displayed after processing data.

3. What is the difference between printf() and scanf()?

printf() scanf()
Displays outputReads input
Output functionInput function

4. Why is & used in scanf()?

It passes the memory address where the input should be stored. Character arrays used as strings are an exception because the array name already acts as an address.

5. Why is fgets() preferred over scanf("%s") for strings?

Because it can read spaces and helps prevent buffer overflow by limiting the number of characters read.

Exam Tips

  • ⭐ Include #include <stdio.h> when using standard input/output functions.
  • ⭐ printf() is used for formatted output.
  • ⭐ scanf() is used for formatted input.
  • ⭐ Use & with variables in scanf(), except for character arrays used as strings.
  • ⭐ puts() automatically prints a newline.
  • ⭐ putchar() and getchar() work with a single character.
  • ⭐ Use fgets() instead of scanf("%s") when reading text containing spaces.
  • ⭐ Use width specifiers like %29s with scanf() to reduce the risk of buffer overflow.

Summary

  • Input is the process of receiving data from the user, while Output is the process of displaying processed information.
  • The Standard I/O library (stdio.h) provides functions for reading and writing data.
  • Common Output Functions are printf(), puts(), and putchar().
  • Common Input Functions are scanf(), getchar(), and fgets().
  • Choosing the correct function depends on the type of data and whether spaces or formatting need to be handled.
  • Safe input practices, such as using field widths with scanf() and preferring fgets() for full lines, help write more reliable C programs.
