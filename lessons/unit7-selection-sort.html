Selection Sort

Selection Sort is a simple comparison-based sorting algorithm. Instead of repeatedly swapping adjacent elements like Bubble Sort, it finds the smallest element from the unsorted part of the array and places it at its correct position.

Real-Life Analogy

Imagine arranging playing cards in ascending order.

You:

  1. Look through all the cards.
  2. Find the smallest card.
  3. Place it at the beginning.
  4. Repeat the process for the remaining cards.

This is exactly how Selection Sort works.

How Selection Sort Works

Given the array:

64 25 12 22 11

Initially:

64 25 12 22 11
 ^

The arrow (^) indicates the current position where the smallest element should be placed.

Pass 1

Find the smallest element in:

64 25 12 22 11

Smallest = 11

Swap 64 and 11

11 25 12 22 64

Now, 11 is in its correct position.

Pass 2

Search the remaining unsorted part:

11 25 12 22 64
   ^

Smallest = 12

Swap 25 and 12

11 12 25 22 64

Pass 3

Search:

11 12 25 22 64
      ^

Smallest = 22

Swap 25 and 22

11 12 22 25 64

Pass 4

Remaining elements:

11 12 22 25 64
         ^

Smallest = 25

Already in the correct position, so no swap is needed.

Final array:

11 12 22 25 64

Pass Summary

Pass Array
Initial64 25 12 22 11
Pass 111 25 12 22 64
Pass 211 12 25 22 64
Pass 311 12 22 25 64
Pass 411 12 22 25 64

Notice that after each pass, the smallest unsorted element is placed in its correct position.

Selection Sort Algorithm

Start

For each position i

    Assume current element is the smallest

    Search remaining array

    If a smaller element is found

        Update minimum index

    Swap minimum element with current element

Stop

Flow of Selection Sort

Start
   │
Assume Current Element is Minimum
   │
Compare with Remaining Elements
   │
Found Smaller?
   │
Yes → Update Minimum
   │
No
   │
End of Search
   │
Swap Current and Minimum
   │
Next Position
   │
Sorted

C Program

#include <stdio.h>

int main()
{
    int arr[] = {64, 25, 12, 22, 11};
    int n = 5;

    for (int i = 0; i < n - 1; i++)
    {
        int minIndex = i;

        for (int j = i + 1; j < n; j++)
        {
            if (arr[j] < arr[minIndex])
            {
                minIndex = j;
            }
        }

        int temp = arr[i];
        arr[i] = arr[minIndex];
        arr[minIndex] = temp;
    }

    printf("Sorted Array:\n");

    for (int i = 0; i < n; i++)
        printf("%d ", arr[i]);

    return 0;
}

Output

Sorted Array:
11 12 22 25 64

Code Explanation

Outer Loop

for(int i = 0; i < n - 1; i++)
  • Runs n − 1 passes.
  • Each pass places one element in its correct position.

Minimum Index

int minIndex = i;

Initially, assume the current element is the smallest.

Inner Loop

for(int j = i + 1; j < n; j++)

Search the remaining unsorted elements for a smaller value.

Update Minimum

if(arr[j] < arr[minIndex])

If a smaller element is found, update minIndex.

Swap

int temp = arr[i];
arr[i] = arr[minIndex];
arr[minIndex] = temp;

Place the smallest element at the current position.

Time Complexity

Case Complexity
Best CaseO(n²)
Average CaseO(n²)
Worst CaseO(n²)

Unlike Bubble Sort, Selection Sort always scans the remaining array to find the minimum, even if the array is already sorted.

Space Complexity

O(1)

Only one temporary variable is used for swapping, so the extra memory required is constant.

Advantages

  • Easy to understand and implement.
  • Performs fewer swaps than Bubble Sort.
  • In-place sorting algorithm.
  • Suitable for small datasets.
  • Useful when swapping elements is expensive.

Disadvantages

  • Time complexity is always O(n²).
  • Not efficient for large datasets.
  • Not a stable sorting algorithm in its basic form.

Bubble Sort vs Selection Sort

MethodSwap adjacent elementsSelect minimum element

Applications

  • Sorting small datasets.
  • Situations where minimizing the number of swaps is important.
  • Educational purposes to understand sorting fundamentals.

Key Points to Remember

  • Finds the smallest element in the unsorted portion.
  • Places it at the beginning of the unsorted portion after each pass.
  • Performs one swap per pass.
  • Not stable in its basic implementation.
  • Time Complexity: O(n²) in all cases.
  • Space Complexity: O(1).
