Random Access Files

Normally, files are read sequentially, meaning data is processed from the beginning to the end. However, in many applications, we need to directly access a specific location in a file without reading all previous data.

This is called Random Access File Handling.

Random access is mainly achieved using the following functions:

  • fseek()
  • ftell()
  • rewind()

These functions are declared in the <stdio.h> header file.

What is Random Access?

Random Access is the ability to move the file pointer directly to any location in a file for reading or writing.

Instead of reading every record one by one, the program can jump directly to the required position.

File Pointer

Every opened file has a file pointer.

Initially, it points to the first byte of the file.

File Pointer

The pointer moves automatically while reading or writing.

Why Random Access?

  • Update a specific record
  • Search records quickly
  • Skip unnecessary data

1. fseek()

Definition

The fseek() function moves the file pointer to a specified position in a file.

Syntax

fseek(file_pointer, offset, origin);

Parameters

Parameter Description
file_pointerPointer to the opened file
offsetNumber of bytes to move
originStarting point for movement

Origin Constants

Constant Meaning
SEEK_SETBeginning of the file
SEEK_CURCurrent file pointer position
SEEK_ENDEnd of the file

Example 1

Move to the 10th byte.

FILE *fp;

fp = fopen("data.txt", "r");

fseek(fp, 10, SEEK_SET);

fclose(fp);

Example 2

Move forward from the current position.

fseek(fp, 5, SEEK_CUR);

Moves 5 bytes ahead.

Example 3

Move backward from the end.

fseek(fp, -20, SEEK_END);

Moves 20 bytes before the end of the file.

Reading a Specific Record

#include <stdio.h>

struct Student
{
    int roll;
    char name[20];
    float marks;
};

int main()
{
    FILE *fp;
    struct Student s;

    fp = fopen("student.dat", "rb");

    fseek(fp, 2 * sizeof(struct Student), SEEK_SET);

    fread(&s, sizeof(s), 1, fp);

    printf("%d %s %.2f",
           s.roll,
           s.name,
           s.marks);

    fclose(fp);

    return 0;
}

2. ftell()

Definition

The ftell() function returns the current position of the file pointer.

The returned value represents the number of bytes from the beginning of the file.

Syntax

long position;

position = ftell(file_pointer);

Example

#include <stdio.h>

int main()
{
    FILE *fp;

    fp = fopen("sample.txt", "r");

    fgetc(fp);
    fgetc(fp);
    fgetc(fp);

    printf("%ld", ftell(fp));

    fclose(fp);

    return 0;
}

Output

3

The file pointer has moved 3 bytes from the beginning.

Example with fseek()

FILE *fp;

fp = fopen("sample.txt", "r");

fseek(fp, 20, SEEK_SET);

printf("%ld", ftell(fp));

fclose(fp);

Output

20

Applications of ftell()

  • Determine current file location
  • Calculate file size
  • Track reading progress

Finding File Size

#include <stdio.h>

int main()
{
    FILE *fp;

    fp = fopen("sample.txt", "r");

    fseek(fp, 0, SEEK_END);

    printf("Size = %ld Bytes",
            ftell(fp));

    fclose(fp);

    return 0;
}

Example Output

Size = 245 Bytes

3. rewind()

Definition

The rewind() function moves the file pointer back to the beginning of the file.

Syntax

rewind(file_pointer);

Example

#include <stdio.h>

int main()
{
    FILE *fp;

    char ch;

    fp = fopen("sample.txt", "r");

    while((ch = fgetc(fp)) != EOF)
    {
        putchar(ch);
    }

    rewind(fp);

    printf("\n\nReading Again\n\n");

    while((ch = fgetc(fp)) != EOF)
    {
        putchar(ch);
    }

    fclose(fp);

    return 0;
}

The file is read twice because rewind() resets the pointer to the beginning.

Common Mistakes

❌ Using fseek() on a NULL file pointer.

❌ Forgetting to open the file before using random access functions.

❌ Using the wrong origin (SEEK_SET, SEEK_CUR, SEEK_END).

❌ Ignoring the return value of fseek() (it returns 0 on success and a non-zero value on failure).

❌ Assuming ftell() always returns the file size; it only returns the current file pointer position.

Key Takeaways

  • Random access allows direct movement to any location in a file without reading all previous data.
  • fseek() moves the file pointer to a specified byte position relative to the beginning, current position, or end of the file.
  • ftell() returns the current position of the file pointer in bytes from the beginning of the file.
  • rewind() resets the file pointer to the beginning of the file.
  • Random access is especially useful with binary files, where records have a fixed size and can be accessed efficiently.
  • These functions are widely used in database systems, record management, and large file processing applications.
