Structure of a C Program

Every C program follows a basic structure. Whether the program is small or large, it is generally organized in the same way.

Understanding this structure helps you read and write C programs correctly.

Basic Structure of a C Program

A C program generally consists of the following sections:

Documentation Section
        ↓
Link Section
        ↓
Definition Section (Optional)
        ↓
Global Declaration Section (Optional)
        ↓
main() Function
        ↓
User-Defined Functions (Optional)

Note: Only the Link Section and main() function are mandatory for most beginner C programs.

First C Program

#include <stdio.h>

int main()
{
    printf("Hello, World!");

    return 0;
}

Output

Hello, World!

Now let's understand every line.

1. Documentation Section

This section contains comments.

Example:

// My First C Program

or

/*
   My First C Program
   Written by Aman
*/

Purpose

  • Explains the program.
  • Makes code easier to understand.
  • Ignored by the compiler.

2. Link Section

#include <stdio.h>

This is called a Preprocessor Directive.

Meaning

  • #include tells the compiler to include a header file.
  • stdio.h stands for Standard Input Output Header File.

It provides functions like:

printf()
scanf()

Without including stdio.h, functions like printf() and scanf() may not work correctly.

Common Header Files

Header File Purpose
stdio.h Input and Output
math.h Mathematical functions
string.h String functions
stdlib.h Memory allocation, conversion, utilities
ctype.h Character handling

3. Definition Section (Optional)

Used to define constants.

Example:

#define PI 3.14159

Now instead of writing:

3.14159

we can write:

PI

4. Global Declaration Section (Optional)

Variables and function declarations that can be accessed throughout the program.

Example:

int count = 0;

We'll learn global variables in later units.

5. main() Function (Most Important)

Every C program starts execution from the main() function.

int main()
{
}

Why is main() important?

  • It is the entry point of every C program.
  • The operating system starts executing the program from here.

Without main(), the program cannot run.

Understanding int main()

int main()

int

Means the function returns an integer value.

Usually:

return 0;

returns the value 0 to the operating system, indicating successful execution.

Curly Braces { }

Everything inside these braces belongs to the main() function.

int main()
{
    // Program statements
}

6. Executable Statements

These are the instructions executed by the computer.

Example:

printf("Hello World");

or

a = b + c;

Understanding printf()

printf("Hello World");

Purpose

Displays output on the screen.

Output

Hello World

printf means Print Formatted.

Understanding return 0;

return 0;

It tells the operating system:

"The program finished successfully."

Although some modern compilers allow omitting it in main(), it is good practice to include it.

Why is Semicolon (;) Used?

Every statement in C ends with a semicolon.

Example:

printf("Hello");
return 0;

The semicolon tells the compiler that the statement has ended.

Incorrect

printf("Hello")

This results in a compilation error.

Overall Structure of a C Program

// Documentation Section

#include <stdio.h>     // Link Section

#define PI 3.14        // Definition Section

int count;             // Global Declaration

int main()             // Main Function
{
    printf("Hello");

    return 0;
}

// User Defined Functions

Important Rules

  • Every C program should have a main() function.
  • Statements end with a semicolon (;).
  • C is case-sensitive.
    • main ✅
    • Main ❌
    • MAIN ❌
  • Braces {} define blocks of code.
  • printf() is used to display output.
  • return 0; indicates successful program execution.

Common Beginner Mistakes

❌ Missing semicolon

printf("Hello")

✅ Correct

printf("Hello");

❌ Wrong case

Printf("Hello");

✅ Correct

printf("Hello");

❌ Missing braces

int main()
printf("Hello");

✅ Correct

int main()
{
    printf("Hello");
}

❌ Missing #include

int main()
{
    printf("Hello");
}

While some compilers may still compile this with warnings, always include the appropriate header (stdio.h) when using printf().

Key Points to Remember

  • Every C program starts execution from the main() function.
  • #include <stdio.h> includes the Standard Input/Output library.
  • printf() displays output on the screen.
  • Every statement ends with a semicolon (;).
  • Curly braces {} define the body of a function.
  • return 0; indicates successful execution.
  • C is case-sensitive.

Interview Questions

Q1. Which function is the starting point of every C program?

Answer: main().

Q2. What is the purpose of #include <stdio.h>?

Answer: It includes the Standard Input/Output header file, which provides functions like printf() and scanf().

Q3. Why do we use return 0;?

Answer: It returns 0 to the operating system, indicating that the program executed successfully.

Q4. What happens if you forget a semicolon?

Answer: The compiler generates a syntax (compilation) error.

Q5. Is C case-sensitive?

Answer: Yes. For example, printf() is correct, while Printf() is incorrect.
