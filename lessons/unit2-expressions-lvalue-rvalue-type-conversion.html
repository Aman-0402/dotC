Expressions, L-value & R-value, Type Conversion

Expressions are one of the most important concepts in C programming. Almost every statement in C contains an expression. Understanding expressions, L-values/R-values, and type conversion is essential for writing correct and efficient programs.

This topic covers:

  • Expressions
  • L-value and R-value
  • Type Conversion

Part 1: Expressions

What is an Expression?

An expression is a combination of:

  • Constants
  • Variables
  • Operators
  • Function calls

that produces a single value.

Definition

An expression is a valid combination of operands and operators that evaluates to a single value.

Part 2: L-value and R-value

This is a favorite interview topic.

What is an L-value?

The L stands for Left.

An L-value refers to a memory location.

It has:

  • Name
  • Address
  • Storage

Definition

An L-value is an expression that refers to an identifiable memory location.

Example

int age = 20;

Here

age

is an L-value.

Because:

  • It has memory.
  • It has an address.
  • Its value can be changed.

Memory Representation

int age = 20;
Address      Variable      Value

1000         age           20

Examples of L-values

x
marks
studentAge
array[0]

All have memory locations.

What is an R-value?

The R stands for Right.

An R-value is simply a value or temporary result.

It usually does not have a writable memory location.

Definition

An R-value is a value that can be assigned to an L-value but cannot itself be assigned a new value.

Example

int age = 20;

Here

20

is an R-value.

Another Example

age + 5

Suppose

age = 20

Result

The value

25

is an R-value.

It is temporary.

Part 3: Type Conversion

Different data types often work together in the same expression.

Example

int a = 10;

float b = 2.5;

a + b

The compiler converts one type to another before performing the operation.

This is called Type Conversion.

Definition

Type conversion is the process of converting one data type into another.

Types of Type Conversion

Type Conversion
│
├── Implicit Conversion
└── Explicit Conversion (Type Casting)

1. Implicit Conversion

Also called:

Automatic Type Conversion

The compiler performs it automatically.

Example

float b = 2.5;

float c = a + b;

Process

10

↓

10.0

↓

10.0 + 2.5

↓

12.5

12.5

Another Example

Stored

Implicit Conversion Rule

Generally, smaller types are promoted to larger compatible types.

Example

char

↓

↓

This helps preserve information whenever possible.

2. Explicit Conversion (Type Casting)

Here the programmer forces the conversion.

Syntax

(type) expression

Example

float price = 99.99;

int amount = (int)price;

Result

99

The decimal part is removed.

Another Example

#include <stdio.h>

int main()
{
    float marks = 95.75;

    printf("%d", (int)marks);

    return 0;
}

Output

95

Integer Division

Very important.

because both operands are integers.

Exam Tips

  • ⭐ An expression always evaluates to a single value.
  • ⭐ L-value → Has a memory location and can generally appear on the left side of =.
  • ⭐ R-value → A value or temporary result used on the right side of =.
  • ⭐ Implicit conversion is automatic.
  • ⭐ Explicit conversion uses type casting.
  • ⭐ Integer division (5 / 2) gives 2, not 2.5.
  • ⭐ Use (float) or another appropriate cast when you need floating-point results.

Summary

  • An expression combines operands and operators to produce a value.
  • Expressions can be arithmetic, relational, logical, assignment, increment/decrement, conditional, or bitwise.
  • L-values represent identifiable memory locations, while R-values represent values or temporary results.
  • Type conversion changes one data type into another and can be implicit (automatic) or explicit (using a cast).
  • Understanding these concepts is essential because they form the basis for operators, decision making, loops, functions, and many advanced C programming topics.
