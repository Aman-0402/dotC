Merge Sort

Merge Sort is an efficient, stable, comparison-based sorting algorithm based on the Divide and Conquer technique.

Unlike Bubble Sort, Selection Sort, and Insertion Sort, Merge Sort divides the array into smaller parts, sorts them recursively, and then merges them back into a sorted array.

What is Divide and Conquer?

Divide and Conquer is an algorithm design technique that solves a problem in three steps:

  1. Divide → Split the problem into smaller subproblems.
  2. Conquer → Solve each subproblem recursively.
  3. Combine → Merge the solutions into the final answer.

Merge Sort is one of the best examples of this technique.

Real-Life Analogy

Imagine you have a stack of exam papers.

Instead of sorting all 100 papers together:

  • Divide them into two piles of 50.
  • Divide each pile into 25.
  • Continue dividing until each pile has only one paper.
  • Now merge the smaller sorted piles into larger sorted piles.
  • Finally, all papers become sorted.

This is exactly how Merge Sort works.

C Program

#include <stdio.h>

void merge(int arr[], int left, int mid, int right)
{
    int i, j, k;

    int n1 = mid - left + 1;
    int n2 = right - mid;

    int L[n1], R[n2];

    for(i = 0; i < n1; i++)
        L[i] = arr[left + i];

    for(j = 0; j < n2; j++)
        R[j] = arr[mid + 1 + j];

    i = 0;
    j = 0;
    k = left;

    while(i < n1 && j < n2)
    {
        if(L[i] <= R[j])
            arr[k++] = L[i++];
        else
            arr[k++] = R[j++];
    }

    while(i < n1)
        arr[k++] = L[i++];

    while(j < n2)
        arr[k++] = R[j++];
}

void mergeSort(int arr[], int left, int right)
{
    if(left < right)
    {
        int mid = left + (right - left) / 2;

        mergeSort(arr, left, mid);

        mergeSort(arr, mid + 1, right);

        merge(arr, left, mid, right);
    }
}

int main()
{
    int arr[] = {38, 27, 43, 3, 9, 82, 10};

    int n = sizeof(arr) / sizeof(arr[0]);

    mergeSort(arr, 0, n - 1);

    printf("Sorted Array:\n");

    for(int i = 0; i < n; i++)
        printf("%d ", arr[i]);

    return 0;
}

Code Explanation

Recursive Function

mergeSort(arr, left, right);

Divides the array until only one element remains.

Middle Index

int mid = left + (right - left)/2;

Finds the middle safely without integer overflow.

Recursive Calls

mergeSort(left);
mergeSort(right);

Sort both halves independently.

Merge Function

merge(left,right);

Combines the two sorted halves into one sorted array.

Time Complexity

Case Complexity
Best CaseO(n log n)

Worst CaseO(n log n)

Unlike Bubble or Selection Sort, Merge Sort performs consistently well in every case.

Space Complexity

O(n)

Merge Sort requires an additional temporary array while merging.

Advantages

  • Fast for large datasets.
  • Stable sorting algorithm.
  • Predictable performance (O(n log n)).
  • Works well with linked lists.
  • Ideal for external sorting (large files stored on disk).

Disadvantages

  • Requires extra memory (O(n)).
  • Recursive implementation increases function call overhead.
  • Slower than Quick Sort for many in-memory datasets due to additional memory operations.

Applications

  • Large database sorting.
  • External sorting (files too large for RAM).
  • Linked list sorting.
  • Parallel processing.
  • Used in many standard library implementations.

Key Points to Remember

  • Uses the Divide and Conquer technique.
  • Recursively divides the array into halves.
  • Merges sorted halves into a fully sorted array.
  • Stable sorting algorithm.
  • Time Complexity is O(n log n) in all cases.
  • Space Complexity is O(n) because of temporary arrays.
  • Preferred for large datasets where stable sorting is required.
