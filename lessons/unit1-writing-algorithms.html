Writing Algorithms

Before writing a program, programmers first write an Algorithm.

An algorithm is a step-by-step procedure to solve a problem.

Think of it like a recipe. Before cooking, you follow a sequence of steps. Similarly, before coding, you define the steps needed to solve the problem.

What is an Algorithm?

Definition:

An Algorithm is a finite sequence of well-defined steps used to solve a problem or perform a task.

It focuses on what to do, not how to write it in a programming language.

Characteristics of a Good Algorithm

A good algorithm should have the following properties:

1. Input

It should accept zero or more inputs.

Example:

Enter two numbers

2. Output

It should produce at least one output.

Example:

Display the sum

3. Definiteness

Each step should be clear and unambiguous.

❌ Wrong

Do some calculation

✅ Correct

Sum = A + B

4. Finiteness

The algorithm must end after a finite number of steps.

❌ Wrong

Repeat forever

✅ Correct

Repeat 5 times
Stop

5. Effectiveness

Each step should be simple and executable.

Example:

Multiply two numbers

is effective because it is a basic operation.

General Structure of an Algorithm

Start
Step 1
Step 2
Step 3
...
Stop

Example 1: Add Two Numbers

Problem

Find the sum of two numbers.

Algorithm

Algorithm: Add Two Numbers

Step 1: Start
Step 2: Read A
Step 3: Read B
Step 4: Sum = A + B
Step 5: Display Sum
Step 6: Stop

Dry Run

Input:

A = 10
B = 20

Execution:

Sum = 10 + 20
Sum = 30

Output:

30

Example 2: Area of a Rectangle

Formula

Area = Length × Width

Algorithm

Algorithm: Area of Rectangle

Step 1: Start
Step 2: Read Length
Step 3: Read Width
Step 4: Area = Length × Width
Step 5: Display Area
Step 6: Stop

Example

Length = 8
Width = 5
Area = 40

Example 3: Swap Two Numbers (Using Third Variable)

Before

A = 10
B = 20

Algorithm

Step 1: Start
Step 2: Read A and B
Step 3: Temp = A
Step 4: A = B
Step 5: B = Temp
Step 6: Display A and B
Step 7: Stop

After swapping

A = 20
B = 10

Example 4: Find Simple Interest

Formula

SI = (P × R × T) / 100

Algorithm

Step 1: Start
Step 2: Read P, R and T
Step 3: SI = (P × R × T) / 100
Step 4: Display SI
Step 5: Stop

Example 5: Find Average of Three Numbers

Formula

Average = (A + B + C) / 3

Algorithm

Step 1: Start
Step 2: Read A, B and C
Step 3: Average = (A + B + C) / 3
Step 4: Display Average
Step 5: Stop

Advantages of Algorithms

  • Easy to understand.
  • Helps in planning before coding.
  • Independent of any programming language.
  • Makes debugging easier.
  • Can be converted into a flowchart or program.

Limitations of Algorithms

  • Writing algorithms for very large problems can be time-consuming.
  • There is no universal standard format.
  • Complex algorithms may become lengthy.

Algorithm vs Program

Algorithm Program
Step-by-step solution Actual implementation in a programming language
Written in simple English Written using language syntax (e.g., C, Java, Python)
Language-independent Language-dependent
Easier to understand Requires programming knowledge

Real-Life Example

Problem: Withdraw Money from an ATM

Step 1: Start
Step 2: Insert ATM Card
Step 3: Enter PIN
Step 4: Select Withdraw
Step 5: Enter Amount
Step 6: Collect Cash
Step 7: Take Receipt
Step 8: Remove Card
Step 9: Stop

Notice that these are simply ordered steps, just like an algorithm for a computer program.

Tips for Writing Good Algorithms

  • Start with Start and end with Stop.
  • Write one clear action per step.
  • Keep steps in the correct order.
  • Use meaningful variable names like sum, area, average.
  • Avoid unnecessary or vague instructions.

Key Points to Remember

  • An algorithm is a step-by-step procedure to solve a problem.
  • It is language-independent.
  • Every algorithm should have:
    • Input
    • Output
    • Definiteness
    • Finiteness
    • Effectiveness
  • Algorithms are written before writing the actual program.
  • A well-written algorithm makes coding easier and reduces errors.
