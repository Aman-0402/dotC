Arrays (Advanced)

Arrays are one of the most important data structures because they store multiple elements of the same data type in contiguous memory locations. Many algorithms such as searching, sorting, and dynamic programming are built using arrays.

1. Review of Arrays

Definition

An Array is a collection of elements of the same data type stored in contiguous memory locations.

Each element is identified using an index.

Declaration

int arr[5];

This creates an integer array of size 5.

Initialization

int arr[5]={10,20,30,40,50};

Accessing Elements

printf("%d",arr[2]);

Output

30

Indexing

Array indexing starts from 0.

Index : 0   1   2   3   4

Value :10  20  30  40  50

Advantages

  • Fast access using index
  • Easy to traverse
  • Memory efficient
  • Suitable for searching and sorting

Disadvantages

  • Fixed size
  • Same data type only
  • Insertion and deletion are costly

2. Memory Representation

Arrays store elements in contiguous (continuous) memory locations.

Suppose

int arr[5]={10,20,30,40,50};

Assume first element starts at address 1000.

Address

1000 → 10

1004 → 20

1008 → 30

1012 → 40

1016 → 50

Each integer occupies 4 bytes.

Address Formula

For one-dimensional arrays

Address(arr[i])

= Base Address + (Index × Size of Data Type)

Example

Base Address =1000

Index =3

Size =4 bytes

Address

=1000+(3×4)

=1012

3. Traversing an Array

Traversing means visiting every element exactly once.

Algorithm

Start

Repeat from i=0 to n−1

Print arr[i]

Stop

Program

#include<stdio.h>

int main()
{
    int arr[]={10,20,30,40,50};

    for(int i=0;i<5;i++)
    {
        printf("%d ",arr[i]);
    }

    return 0;
}

Output

10 20 30 40 50

Complexity

Time : O(n)

Space : O(1)

4. Insertion

Insertion means adding a new element at a desired position.

Example

Original Array

10 20 40 50

Insert 30 at Position 2

Result

10 20 30 40 50

Algorithm

Start

Read Position and Element

Move all elements one position right

Insert new element

Increase size

Stop

Program

#include<stdio.h>

int main()
{
    int arr[10]={10,20,40,50};
    int n=4;
    int pos=2;
    int item=30;

    for(int i=n;i>pos;i--)
        arr[i]=arr[i-1];

    arr[pos]=item;
    n++;

    for(int i=0;i<n;i++)
        printf("%d ",arr[i]);

    return 0;
}

Output

10 20 30 40 50

Complexity

Time : O(n)

Space : O(1)

5. Deletion

Deletion removes an element from an array.

Example

Original

10 20 30 40 50

Delete Position 2

Result

10 20 40 50

Algorithm

Start

Read Position

Shift all elements left

Decrease size

Stop

Program

#include<stdio.h>

int main()
{
    int arr[]={10,20,30,40,50};
    int n=5;
    int pos=2;

    for(int i=pos;i<n-1;i++)
        arr[i]=arr[i+1];

    n--;

    for(int i=0;i<n;i++)
        printf("%d ",arr[i]);

    return 0;
}

Output

10 20 40 50

Complexity

Time : O(n)

Space : O(1)

6. Searching

Searching means finding whether an element exists in an array.

There are two common searching techniques:

  • Linear Search
  • Binary Search (covered later)

Example

Array

10 20 30 40 50

Search 40

Found at index 3

Linear Search Program

#include<stdio.h>

int main()
{
    int arr[]={10,20,30,40,50};
    int key=40;

    for(int i=0;i<5;i++)
    {
        if(arr[i]==key)
        {
            printf("Found at index %d",i);
            return 0;
        }
    }

    printf("Not Found");

    return 0;
}

Complexity

Time : O(n)

Space : O(1)

7. Updating

Updating means changing an existing element.

Example

Original

10 20 30 40

Update index 2

99

Result

10 20 99 40

Program

#include<stdio.h>

int main()
{
    int arr[]={10,20,30,40};

Space : O(1)

8. Merging Arrays

Merging combines two arrays into one.

Example

Array A

10 20 30

Array B

40 50

Merged Array

10 20 30 40 50

Program

#include<stdio.h>

int main()
{
    int a[]={10,20,30};
    int b[]={40,50};
    int c[5];

    int i;

    for(i=0;i<3;i++)
        c[i]=a[i];

    for(int j=0;j<2;j++)
        c[i++]=b[j];

    for(i=0;i<5;i++)
        printf("%d ",c[i]);

    return 0;
}

Output

10 20 30 40 50

Complexity

Time : O(n+m)

Space : O(n+m)

9. Rotation

Rotation shifts array elements either left or right.

Left Rotation

Original

10 20 30 40 50

After Left Rotation

20 30 40 50 10

Program

#include<stdio.h>

int main()
{
    int arr[]={10,20,30,40,50};
    int temp=arr[0];

    for(int i=0;i<4;i++)
        arr[i]=arr[i+1];

    arr[4]=temp;

    for(int i=0;i<5;i++)
        printf("%d ",arr[i]);

    return 0;
}

Output

20 30 40 50 10

Right Rotation

Original

10 20 30 40 50

Result

50 10 20 30 40

Complexity

Time : O(n)

Space : O(1)

10. Reversal

Reverse changes the order of elements.

Example

Original

10 20 30 40 50

Reversed

50 40 30 20 10

Program

#include<stdio.h>

int main()
{
    int arr[]={10,20,30,40,50};
    int start=0,end=4,temp;

    while(start<end)
    {
        temp=arr[start];
        arr[start]=arr[end];
        arr[end]=temp;

        start++;
        end--;
    }

    for(int i=0;i<5;i++)
        printf("%d ",arr[i]);

    return 0;
}

Output

50 40 30 20 10

Complexity

Time : O(n)

Space : O(1)

11. Frequency Count

Frequency count determines how many times each element appears.

Example

Array

1 2 2 3 1 2

Frequency

1 → 2

2 → 3

3 → 1

Program

#include<stdio.h>

int main()
{
    int arr[]={1,2,2,3,1,2};
    int n=6;

    for(int i=0;i<n;i++)
    {
        int count=1;

        if(arr[i]==-1)
            continue;

        for(int j=i+1;j<n;j++)
        {
            if(arr[i]==arr[j])
            {
                count++;
                arr[j]=-1;
            }
        }

        printf("%d occurs %d times\n",arr[i],count);
    }

    return 0;
}

Output

1 occurs 2 times

2 occurs 3 times

3 occurs 1 time

Complexity

Time : O(n²)

Space : O(1)

12. Duplicate Detection

Duplicate detection identifies repeated elements in an array.

Example

Array

10 20 30 20 40 10

Duplicates

10

20

Program

#include<stdio.h>

int main()
{
    int arr[]={10,20,30,20,40,10};
    int n=6;

    for(int i=0;i<n;i++)
    {
        for(int j=i+1;j<n;j++)
        {
            if(arr[i]==arr[j])
            {
                printf("%d ",arr[i]);
                break;
            }
        }
    }

    return 0;
}

Output

10 20

Complexity

Time : O(n²)

Space : O(1)

Key Points to Remember

  • Arrays store homogeneous data in contiguous memory locations.
  • Array indexing starts from 0.
  • Address calculation formula: 
    Address = Base Address + (Index × Size of Data Type)
  • Traversing visits each element once.
  • Insertion and Deletion require shifting elements, making them O(n) operations.
  • Updating an element by index is O(1).
  • Merging combines two arrays into a larger array.
  • Rotation shifts elements left or right.
  • Reversal swaps elements from both ends toward the center.
  • Frequency Count counts occurrences of each element.
  • Duplicate Detection identifies repeated values in an array.
