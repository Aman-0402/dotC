Singly Linked List – Creation

Now that we know what a linked list is and why it is useful, let's learn how to create a Singly Linked List in C.

A singly linked list consists of nodes where each node stores:

  • Data
  • Address of the next node

The last node always points to NULL.

Structure of a Node

Every node is represented using a structure.

struct Node
{
    int data;
    struct Node *next;
};

Explanation

int data;

Stores the actual value.

struct Node *next;

Stores the address of the next node.

Visual Representation of One Node

+-----------+

Example

Every linked list begins with a Head Pointer.

struct Node *head;

Creating the First Node

Allocate memory dynamically.

head = (struct Node *)malloc(sizeof(struct Node));

Assign values.

head->data = 10;
head->next = NULL;

Step-by-Step Creation Process

Step 1

Create the structure.

struct Node
{
    int data;
    struct Node *next;
};

Step 2

Create the head pointer.

struct Node *head = NULL;

Step 3

Allocate memory.

head = (struct Node *)malloc(sizeof(struct Node));

Step 4

Store the data.

head->data = 10;

Step 5

Initialize the next pointer.

head->next = NULL;

The first node is ready.

Complete Program (Creating Three Nodes)

#include <stdio.h>
#include <stdlib.h>

struct Node
{
    int data;
    struct Node *next;
};

int main()
{
    struct Node *head, *second, *third;

    head = (struct Node *)malloc(sizeof(struct Node));
    second = (struct Node *)malloc(sizeof(struct Node));
    third = (struct Node *)malloc(sizeof(struct Node));

    head->data = 10;
    head->next = second;

    second->data = 20;
    second->next = third;

    third->data = 30;
    third->next = NULL;

    printf("Linked List Created Successfully\n");

    free(head);
    free(second);
    free(third);

    return 0;
}

Output

Linked List Created Successfully

Creating Nodes Using a Function

Instead of writing malloc() repeatedly, we can create a function.

struct Node* createNode(int value)
{
    struct Node *newNode;

    newNode = (struct Node *)malloc(sizeof(struct Node));

    newNode->data = value;
    newNode->next = NULL;

    return newNode;
}

Usage

struct Node *head;

head = createNode(10);

This makes the code cleaner and reusable.

Creating a List Dynamically

head = createNode(10);

head->next = createNode(20);

head->next->next = createNode(30);

Memory

head
 ↓
10 → 20 → 30 → NULL

Common Mistakes

1. Forgetting malloc()

❌ Wrong

struct Node *head;

head->data = 10;

head points to an unknown location, leading to undefined behavior.

✔ Correct

head = (struct Node *)malloc(sizeof(struct Node));
head->data = 10;

2. Forgetting to Set next

❌ Wrong

head->data = 10;

The next pointer contains a garbage address.

✔ Correct

head->next = NULL;

3. Memory Leak

❌ Wrong

malloc(sizeof(struct Node));

without

free(node);

Allocated memory is never released.

4. Using a Node After free()

❌ Wrong

free(head);

printf("%d", head->data);

This accesses freed memory.

✔ Better

free(head);
head = NULL;

Time Complexity

Operation Complexity
Create One NodeO(1)
Create n NodesO(n)

Key Points to Remember

  • Every node is created dynamically using malloc().
  • Each node contains data and a next pointer.
  • The head pointer stores the address of the first node.
  • The last node always points to NULL.
  • Always release allocated memory with free() to avoid memory leaks.
  • Creating helper functions like createNode() improves code readability and reusability.
