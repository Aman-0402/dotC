Insertion Sort

Insertion Sort is a simple and efficient comparison-based sorting algorithm. It works by taking one element at a time and inserting it into its correct position within the already sorted part of the array.

Unlike Bubble Sort and Selection Sort, Insertion Sort builds the sorted array gradually.

Real-Life Analogy

Imagine sorting a hand of playing cards.

When you pick up a new card:

  1. Compare it with the cards already in your hand.
  2. Shift larger cards to the right.
  3. Insert the new card into its correct position.

This is exactly how Insertion Sort works.

How Insertion Sort Works

Given the array:

12 11 13 5 6

Initially, the first element is considered sorted.

12 | 11 13 5 6
  • Left side = Sorted
  • Right side = Unsorted

Pass 1

Take 11 as the key.

12 | 11 13 5 6

Compare 11 with 12.

Since 11 < 12, shift 12 to the right.

12 12 13 5 6

Insert 11.

11 12 | 13 5 6

Pass 2

Take 13.

11 12 | 13 5 6

Compare with 12.

13 is larger, so no shifting.

11 12 13 | 5 6

Pass 3

Take 5.

11 12 13 | 5 6

Compare from right to left.

Shift 13.

11 12 13 13 6

Shift 12.

11 12 12 13 6

Shift 11.

11 11 12 13 6

Insert 5.

5 11 12 13 | 6

Pass 4

Take 6.

5 11 12 13 | 6

Shift 13.

5 11 12 13 13

Shift 12.

5 11 12 12 13

Shift 11.

5 11 11 12 13

Insert 6.

5 6 11 12 13

Array is now sorted.

Insertion Sort Algorithm

Start

For each element from the second position

    Store current element as key

    Compare key with previous elements

    Shift larger elements one position right

    Insert key into its correct position

Stop

Flow of Insertion Sort

Start
   │
Pick Next Element (Key)
   │
Compare with Sorted Part
   │
Shift Larger Elements Right
   │
Insert Key
   │
Repeat
   │
Sorted

C Program

#include <stdio.h>

int main()
{
    int arr[] = {12, 11, 13, 5, 6};
    int n = 5;

    for (int i = 1; i < n; i++)
    {
        int key = arr[i];
        int j = i - 1;

        while (j >= 0 && arr[j] > key)
        {
            arr[j + 1] = arr[j];
            j--;
        }

        arr[j + 1] = key;
    }

    printf("Sorted Array:\n");

    for (int i = 0; i < n; i++)
        printf("%d ", arr[i]);

    return 0;
}

Output

Sorted Array:
5 6 11 12 13

Code Explanation

Outer Loop

for(int i = 1; i < n; i++)
  • Starts from the second element (i = 1).
  • The first element is already considered sorted.

Store the Key

int key = arr[i];

The current element is stored in the variable key.

Previous Element

int j = i - 1;

j points to the last element of the sorted part.

Shift Larger Elements

while(j >= 0 && arr[j] > key)
{
    arr[j + 1] = arr[j];
    j--;
}
  • Compare the key with elements in the sorted part.
  • Shift larger elements one position to the right.

Insert the Key

arr[j + 1] = key;

Place the key in its correct position.

Time Complexity

Case Complexity
Best Case (already sorted)O(n)
Average CaseO(n²)
Worst Case (reverse order)O(n²)

When the array is already sorted, no shifting is needed, making Insertion Sort very efficient.

Space Complexity

O(1)

Insertion Sort uses only a few extra variables (key and j), so it requires constant extra memory.

Advantages

  • Simple and easy to implement.
  • Efficient for small datasets.
  • Very efficient for nearly sorted arrays.
  • Stable sorting algorithm.
  • In-place sorting (no extra array required).
  • Performs fewer comparisons for nearly sorted data.

Disadvantages

  • Inefficient for large datasets.
  • Worst-case time complexity is O(n²).
  • Requires many shifts when the array is in reverse order.

Applications

  • Sorting small datasets.
  • Sorting nearly sorted data efficiently.
  • Online sorting (processing data as it arrives).
  • Used as a subroutine in advanced algorithms like TimSort (used in Python) and IntroSort.

Key Points to Remember

  • The first element is considered sorted.
  • Each new element is inserted into its correct position in the sorted part.
  • Larger elements are shifted to the right.
  • Stable and in-place sorting algorithm.
  • Best Case: O(n).
  • Average/Worst Case: O(n²).
