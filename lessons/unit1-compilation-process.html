Compilation Process

When you write a C program, the computer cannot understand it directly because it only understands Machine Language (0s and 1s).

So, the C program must go through several stages before it can be executed.

This complete journey is called the Compilation Process.

What is the Compilation Process?

Compilation Process is the process of converting a C source program into an executable program that the computer can run.

There are 6 main stages:

  1. Preprocessing
  2. Compilation
  3. Assembly
  4. Linking
  5. Loading
  6. Execution

Stage 1: Source Code

The program written by the programmer is called the Source Code.

Example:

#include <stdio.h>

int main()
{
    printf("Hello World");

    return 0;
}

Usually saved as

hello.c

Extension:

.c

Stage 2: Preprocessing

The Preprocessor processes all preprocessor directives before compilation.

Examples of directives:

#include <stdio.h>
#define PI 3.14

What does the preprocessor do?

  • Includes header files
  • Expands macros
  • Removes comments
  • Processes conditional compilation directives (#ifdef, #ifndef, etc.)

Example

Original code

#include <stdio.h>

int main()
{
    printf("Hello");
}

After preprocessing (conceptually)

// Thousands of lines from stdio.h are inserted here

int main()
{
    printf("Hello");
}

Stage 3: Compilation

Now the Compiler checks the program for errors and converts it into Assembly Language.

Compiler checks for:

  • Syntax errors
  • Type errors
  • Declaration errors

Example:

printf("Hello")

Missing semicolon.

Compiler Output

Error: expected ';'

If there are no errors, it generates:

Assembly Code (.s)

Stage 4: Assembly

The Assembler converts the assembly code into Object Code.

Assembly Code
      │
      ▼
Assembler
      │
      ▼
Object Code

Object file extension:

Windows

.obj

Linux

.o

Object code is machine code, but it is not yet executable because it may still depend on external libraries.

Stage 5: Linking

Most programs use library functions like:

printf()
scanf()
sqrt()
strlen()

These functions are not stored in your source file.

The Linker connects your object code with the required library files.

Example

printf("Hello");

The linker finds the implementation of printf() inside the C Standard Library and attaches it to your program.

Output:

Executable File

Windows:

program.exe

Linux:

a.out

(or another executable name if specified)

Stage 6: Loading

When you run the executable, the Loader loads it into the computer's main memory (RAM).

Executable
      │
      ▼
Loader
      │
      ▼
RAM

After loading, the CPU starts execution from the main() function.

Stage 7: Execution

Now the CPU executes the instructions.

Example

printf("Hello World");

Output

Hello World

Complete Example

Compilation Errors vs Runtime Errors

Compilation Error

Occurs before execution.

Example

printf("Hello")

Compiler message

Missing semicolon

Program does not compile.

Runtime Error

Occurs during execution.

Example

int a = 10;
int b = 0;

printf("%d", a / b);

The program compiles successfully but fails at runtime because division by zero is invalid.

Key Points to Remember

  • The Compilation Process converts a C program into an executable program.
  • Source Code is the program written by the programmer (.c).
  • The Preprocessor handles directives like #include and #define.
  • The Compiler checks for syntax errors and generates assembly code.
  • The Assembler converts assembly code into object code (.o / .obj).
  • The Linker combines object code with required libraries to create an executable file.
  • The Loader loads the executable into RAM.
  • Execution always starts from the main() function.

Interview Questions

Q1. What is the compilation process?

Answer: It is the process of converting C source code into an executable program.

Q2. What is the difference between source code and object code?

Answer: Source code is human-readable C code (.c), while object code is machine code (.o/.obj) generated by the assembler and is not directly executable.

Q3. What is the role of the linker?

Answer: The linker combines object code with required library files to produce an executable program.

Q4. What is the role of the loader?

Answer: The loader loads the executable program into RAM and prepares it for execution.

Q5. Which stage checks for syntax errors?

Answer: The Compiler checks the program for syntax and semantic errors before generating assembly code.
