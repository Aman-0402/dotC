Looping Statements

Introduction

Many programming tasks require performing the same operation repeatedly.

Examples:

  • Print numbers from 1 to 100.
  • Display a multiplication table.
  • Calculate the sum of numbers.
  • Process records in a file.
  • Display a menu until the user chooses to exit.

Instead of writing the same code multiple times, we use loops.

What is a Loop?

A loop is a control structure that repeatedly executes a block of code as long as a specified condition remains true.

Without Loop

printf("Hello\n");
printf("Hello\n");
printf("Hello\n");
printf("Hello\n");
printf("Hello\n");

With Loop

for(int i = 1; i <= 5; i++)
{
    printf("Hello\n");
}

Both produce the same output, but the loop is much shorter and easier to maintain.

1. for Loop

The for loop is used when the number of iterations is known in advance.

It combines initialization, condition, and update into one statement.

Syntax

{
    // statements
}

Example 1

Print numbers from 1 to 5.

#include <stdio.h>

int main()
{
    int i;

    for(i = 1; i <= 5; i++)
    {
        printf("%d\n", i);
    }

    return 0;

Example 2

Print even numbers.

#include <stdio.h>

int main()
{

    {
        printf("%d ", i);
    }

    return 0;

2 4 6 8 10

Example 3

Print numbers in reverse order.

#include <stdio.h>

int main()
{
    int i;

    for(i = 5; i >= 1; i--)
    {
        printf("%d ", i);
    }

    return 0;
}

Output

5 4 3 2 1

Example 4

Find the sum of first 10 natural numbers.

#include <stdio.h>

int main()
{
    int i, sum = 0;

    for(i = 1; i <= 10; i++)
    {
        sum = sum + i;
    }

    printf("Sum = %d", sum);

    return 0;
}

Output

Sum = 55

Infinite for Loop

A loop without a terminating condition runs forever.

for(;;)
{
    printf("Infinite Loop");
}

2. while Loop

The while loop executes as long as the condition is true.

The condition is checked before entering the loop.

If the condition is false initially, the loop will not execute even once.

Syntax

while(condition)
{
    // statements
}

Flow

Condition
   |
True?
   |
Statements
   |
Update
   |
Condition
   |
False
   |
Exit

Example 1

#include <stdio.h>

int main()
{
    int i = 1;

    while(i <= 5)
    {
        printf("%d ", i);
        i++;
    }

    return 0;
}

Output

1 2 3 4 5

Example 2

Print odd numbers.

#include <stdio.h>

int main()
{
    int i = 1;

    while(i <= 10)
    {
        printf("%d ", i);
        i += 2;
    }

    return 0;
}

Output

1 3 5 7 9

Example 3

Factorial of a number.

#include <stdio.h>

int main()
{
    int n = 5;
    int fact = 1;

    while(n > 0)
    {
        fact *= n;
        n--;
    }

    printf("%d", fact);

    return 0;
}

Output

120

3. do...while Loop

The do...while loop executes the loop body first and checks the condition afterward.

Therefore, the loop executes at least once, even if the condition is false.

Syntax

do
{
    // statements
}
while(condition);

Notice: The semicolon (;) after while(condition) is mandatory.

Flow

Statements
     |
Condition
     |
True?
     |
Statements
     |
False
     |
Exit

Example 1

#include <stdio.h>

int main()
{
    int i = 1;

    do
    {
        printf("%d ", i);
        i++;
    }
    while(i <= 5);

    return 0;
}

Output

1 2 3 4 5

Example 2

Condition is false initially.

#include <stdio.h>

int main()
{
    int i = 10;

    do
    {
        printf("%d", i);
    }
    while(i < 5);

    return 0;
}

Output

10

The loop executes once because the condition is checked after the loop body.

Example 3

Menu-driven program.

#include <stdio.h>

int main()
{
    int choice;

    do
    {
        printf("\n1. Add");
        printf("\n2. Delete");
        printf("\n3. Exit");

        printf("\nEnter Choice: ");
        scanf("%d", &choice);

    } while(choice != 3);

    return 0;
}

The menu continues until the user selects 3.

Nested Loops

A Nested Loop is a loop inside another loop.

The outer loop executes first, and for each iteration of the outer loop, the inner loop executes completely.

Syntax

for(initialization; condition; update)
{
    for(initialization; condition; update)
    {
        // statements
    }
}

Flow

Outer Loop

   |

Inner Loop

   |

Statements

Example 1

Print a 3 × 3 grid.

#include <stdio.h>

int main()
{
    int i, j;

    for(i = 1; i <= 3; i++)
    {
        for(j = 1; j <= 3; j++)
        {
            printf("* ");
        }

        printf("\n");
    }

    return 0;
}

Output

* * *
* * *
* * *

Common Mistakes

Forgetting to update the loop variable

int i = 1;

while(i <= 5)
{
    printf("%d", i);
}

This creates an infinite loop because i never changes.

Using = instead of ==

❌ Incorrect

if(i = 5)

✔ Correct

if(i == 5)

Missing semicolon in do...while

❌ Incorrect

while(i <= 5)

✔ Correct

while(i <= 5);

Summary

  • A loop repeats a block of code until a condition becomes false.
  • for is best when the number of iterations is known.
  • while is ideal when the number of iterations is unknown and the condition must be checked before execution.
  • do...while guarantees at least one execution because the condition is checked after the loop body.
  • Nested loops are used for working with patterns, multiplication tables, matrices, and multidimensional data.
