Functions

What is a Function?

A function is a block of code that performs a specific task. Instead of writing the same code multiple times, we can place it inside a function and call it whenever needed.

Functions make programs:

  • Modular
  • Reusable
  • Easy to understand
  • Easy to debug
  • Easy to maintain

Advantages of Functions

  • Reduces code duplication
  • Improves readability
  • Makes debugging easier
  • Simplifies program maintenance
  • Encourages code reusability

Types of Functions

Functions in C are mainly divided into two types.

1. Library Functions

These are predefined functions provided by the C Standard Library.

Examples:

Function Header File Purpose
printf()<stdio.h>Display output
scanf()<stdio.h>Read input
strlen()<string.h>Find string length
sqrt()<math.h>Square root
pow()<math.h>Power calculation

Example

#include <stdio.h>

int main()
{
    printf("Hello World");

    return 0;
}

Here, printf() is a library function.

2. User-Defined Functions

These are functions created by the programmer to perform a specific task.

Example

#include <stdio.h>

void display()
{
    printf("Welcome to C Programming");
}

int main()
{
    display();

    return 0;
}

Output

Welcome to C Programming

Components of a Function

A function has three important parts.

  1. Function Declaration (Prototype)
  2. Function Definition
  3. Function Call

Function Declaration (Prototype)

A function declaration tells the compiler:

  • Function name
  • Return type
  • Number of parameters
  • Type of parameters

Syntax

return_type function_name(parameter_list);

Example

int add(int, int);

Function Definition

The definition contains the actual code that executes when the function is called.

Syntax

return_type function_name(parameters)
{
    // statements
}

Example

int add(int a, int b)
{
    return a + b;
}

Function Call

A function call transfers program control to the function.

Syntax

function_name(arguments);

Example

sum = add(10,20);

Complete Function Example

#include <stdio.h>

int add(int, int);

int main()
{
    int result;

    result = add(10,20);

    printf("Sum = %d", result);

    return 0;
}

int add(int a, int b)
{
    return a+b;
}

Output

Sum = 30

Return Type

The return type specifies what value the function sends back to the caller.

Example

int square(int n)
{
    return n*n;
}

Returns an integer.

Example

float average(float a,float b)
{
    return (a+b)/2;
}

Returns a floating-point value.

Example

void message()
{
    printf("Hello");
}

Returns nothing because the return type is void.

Parameters and Arguments

Parameters

Variables declared in the function definition.

int add(int a,int b)

Here,

a and b are parameters.

Arguments

Actual values passed during function call.

add(10,20);

Here,

10 and 20 are arguments.

Call by Value

In Call by Value, a copy of the actual argument is passed to the function.

Changes made inside the function do not affect the original variable.

Example

#include <stdio.h>

void change(int x)
{
    x = 100;
}

int main()
{
    int a = 10;

    change(a);

    printf("%d",a);

    return 0;
}

Output

10

The value of a remains unchanged because only a copy was modified.

Call by Reference

In Call by Reference, the address of the variable is passed to the function using pointers.

Changes made inside the function affect the original variable.

Example

#include <stdio.h>

void change(int *x)
{
    *x = 100;
}

int main()
{
    int a = 10;

    change(&a);

    printf("%d",a);

    return 0;
}

Output

100

The original variable is modified because the function receives its memory address.

Difference Between Call by Value and Call by Reference

Feature Call by Value Call by Reference
What is Passed?Copy of valueAddress of variable
Original Value Changes?NoYes
Uses Pointers?NoYes
Memory UsageMore (copy created)Less (same memory used)
Suitable ForRead-only operationsUpdating variables

Complete Example

#include <stdio.h>

int square(int n)
{
    return n*n;
}

void message()
{
    printf("Learning Functions in C\n");
}

int main()
{
    int num = 6;

    message();

    printf("Square = %d\n", square(num));

    return 0;
}

Output

Learning Functions in C
Square = 36

Important Notes

  • A function is a reusable block of code that performs a specific task.
  • Every function has a return type, function name, and parameter list.
  • A function generally involves three steps: declaration, definition, and call.
  • Library functions are predefined, while user-defined functions are created by the programmer.
  • Functions can have arguments, return values, both, or neither.
  • In Call by Value, changes made inside the function do not affect the original variable.
  • In Call by Reference, the original variable can be modified because its address is passed.
