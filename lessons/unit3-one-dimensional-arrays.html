Arrays (One-Dimensional Arrays)

Introduction

Until now, we have stored only one value in one variable.

Example:

int age = 20;

If we need to store the marks of 100 students, creating 100 separate variables is impractical.

int marks1;
int marks2;
int marks3;
...
int marks100;

This approach is:

  • Time-consuming
  • Difficult to manage
  • Difficult to process using loops

To solve this problem, C provides Arrays.

What is an Array?

An Array is a collection of elements of the same data type, stored in contiguous (continuous) memory locations, and accessed using a single variable name with an index.

Example:

Marks of 5 Students

Marks
 ┌────┬────┬────┬────┬────┐
 │ 85 │ 72 │ 90 │ 65 │ 88 │
 └────┴────┴────┴────┴────┘
   0    1    2    3    4

Here,

  • Array Name = marks
  • Total Elements = 5
  • Index starts from 0

Why Use Arrays?

Without Array

int m1 = 80;
int m2 = 75;
int m3 = 90;
int m4 = 88;
int m5 = 95;

With Array

int marks[5];

Advantages:

  • Less code
  • Easy to process with loops
  • Easy searching and sorting
  • Better memory organization

Characteristics of Arrays

  • Stores same type of data.
  • Elements are stored in contiguous memory.
  • Uses a single variable name.
  • Elements are accessed using an index.
  • Size is fixed after declaration.

Array Operations

Arrays support several common operations.

Operation Description
TraversingVisit every element
InsertionAdd an element (manual shifting required)
DeletionRemove an element (manual shifting required)
SearchingFind an element
UpdatingModify an element
SortingArrange elements
MergingCombine two arrays

Traversing an Array

Traversing means visiting every element once.

#include <stdio.h>

int main()
{
    int arr[5] = {2,4,6,8,10};
    int i;

    for(i = 0; i < 5; i++)
    {
        printf("%d ", arr[i]);
    }

    return 0;
}

Output

2 4 6 8 10

Searching an Element

#include <stdio.h>

int main()
{

Common Array Programs

Program 1

Print all elements.

#include <stdio.h>

int main()
{
    int arr[5] = {5,10,15,20,25};
    int i;

    for(i = 0; i < 5; i++)
    {
        printf("%d ", arr[i]);
    }

    return 0;
}

Output

5 10 15 20 25

Program 2

Find Sum of Elements.

#include <stdio.h>

int main()
{
    int arr[5] = {10,20,30,40,50};
    int sum = 0, i;

    for(i = 0; i < 5; i++)
    {
        sum += arr[i];
    }

    printf("Sum = %d", sum);

    return 0;
}

Output

Sum = 150

Program 3

Find Average.

#include <stdio.h>

int main()
{
    int arr[5] = {10,20,30,40,50};
    int i, sum = 0;
    float avg;

    for(i = 0; i < 5; i++)
    {
        sum += arr[i];
    }

    avg = (float)sum / 5;

    printf("Average = %.2f", avg);

    return 0;
}

Output

Average = 30.00

Program 4

Find Largest Element.

#include <stdio.h>

int main()
{
    int arr[5] = {20,45,15,80,35};
    int i, max;

    max = arr[0];

    for(i = 1; i < 5; i++)
    {
        if(arr[i] > max)
        {
            max = arr[i];
        }
    }

    printf("Largest = %d", max);

    return 0;
}

Output

Largest = 80

Program 5

Find Smallest Element.

#include <stdio.h>

int main()
{
    int arr[5] = {20,45,15,80,35};
    int i, min;

    min = arr[0];

    for(i = 1; i < 5; i++)
    {
        if(arr[i] < min)
        {
            min = arr[i];
        }
    }

    printf("Smallest = %d", min);

    return 0;
}

Output

Smallest = 15

Program 6

Reverse an Array.

#include <stdio.h>

int main()
{
    int arr[5] = {10,20,30,40,50};
    int i;

    for(i = 4; i >= 0; i--)
    {
        printf("%d ", arr[i]);
    }

    return 0;
}

Output

50 40 30 20 10

Common Mistakes

Accessing an Invalid Index

❌ Incorrect

int arr[5];

printf("%d", arr[5]);

Valid indices are 0 to 4. Accessing arr[5] is out of bounds and results in undefined behavior.

Using a Negative Index

❌ Incorrect

arr[-1];

Negative indices are not valid in C.

Exceeding Array Size

❌ Incorrect

int arr[3] = {1,2,3,4};

Too many initializers for the declared array size.

Advantages of Arrays

  • Store multiple values using one variable.
  • Easy to process with loops.
  • Faster access using indices.
  • Efficient memory usage due to contiguous storage.
  • Useful for sorting, searching, and other algorithms.

Limitations of Arrays

  • Fixed size after declaration.
  • Can store only one data type.
  • Insertion and deletion require shifting elements.
  • Accessing an invalid index causes undefined behavior.

Summary

  • An array stores multiple values of the same data type in contiguous memory locations.
  • A one-dimensional array represents data in a single sequence and is declared using data_type array_name[size];.
  • Array elements are accessed using zero-based indexing.
  • Common operations include traversing, searching, updating, insertion, deletion, sorting, and merging.
  • Loops are commonly used to process arrays efficiently.
