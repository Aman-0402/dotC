Pseudocode

After writing an algorithm, the next step is often to write Pseudocode.

Pseudocode acts as a bridge between an algorithm and a program. It is easier to convert into actual code than a plain English algorithm.

What is Pseudocode?

Definition:

Pseudocode is an informal way of writing a program's logic using simple English mixed with programming-like keywords, without following the syntax of any programming language.

It is not a programming language, so it cannot be compiled or executed.

Why Do We Use Pseudocode?

  • Makes program logic easy to understand.
  • Helps plan before writing code.
  • Easy to convert into C, Java, Python, etc.
  • Makes debugging easier.
  • Improves communication among programmers.

Features of Pseudocode

  • Written in simple English.
  • No strict syntax rules.
  • Easy to read and modify.
  • Language-independent.
  • Focuses only on logic.

Common Keywords Used in Pseudocode

Keyword Meaning
START Beginning of the algorithm
STOP / END End of the algorithm
INPUT Accept data from the user
OUTPUT / PRINT Display data
SET Assign a value
IF Decision making
ELSE Alternative condition
WHILE Repeat while a condition is true
FOR Repeat a fixed number of times

Step 3

Example 1: Add Two Numbers

Problem

Find the sum of two numbers.

Pseudocode

START

INPUT A
INPUT B

SET SUM = A + B

PRINT SUM

STOP

Equivalent C Program

#include <stdio.h>

int main()
{
    int A, B, SUM;

    scanf("%d %d", &A, &B);

    SUM = A + B;

    printf("%d", SUM);

    return 0;
}

Notice that the pseudocode is much simpler because it ignores C syntax like #include, main(), semicolons, and braces.

Example 2: Area of a Rectangle

Formula

Area = Length × Width

Pseudocode

START

INPUT Length
INPUT Width

SET Area = Length * Width

PRINT Area

STOP

Example 3: Average of Three Numbers

Formula

Average = (A + B + C) / 3

Pseudocode

START

INPUT A
INPUT B
INPUT C

SET Average = (A + B + C) / 3

PRINT Average

STOP

Example 4: Swap Two Numbers

Before

A = 10
B = 20

Pseudocode

START

INPUT A
INPUT B

SET Temp = A
SET A = B
SET B = Temp

PRINT A
PRINT B

STOP

Output

A = 20
B = 10

Example 5: Find Simple Interest

Formula

SI = (P × R × T) / 100

Pseudocode

START

INPUT P
INPUT R
INPUT T

SET SI = (P * R * T) / 100

PRINT SI

STOP

Best Practices

  • Always start with START.
  • End with STOP or END.
  • Use meaningful variable names.
  • Keep statements simple and clear.
  • Indent blocks for readability (especially for IF and loops).

Key Points to Remember

  • Pseudocode is a structured description of program logic.
  • It is not a programming language.
  • It cannot be compiled or executed.
  • It uses keywords such as START, INPUT, SET, PRINT, and STOP.
  • It is easier to convert into actual C code than a plain English algorithm.
  • Every programmer may write pseudocode slightly differently, as there is no fixed standard syntax.
