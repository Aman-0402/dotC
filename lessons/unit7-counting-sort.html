Counting Sort

Counting Sort is a non-comparison-based sorting algorithm. Instead of comparing elements like Bubble Sort or Quick Sort, it counts how many times each value appears and then reconstructs the sorted array.

It is very efficient when the range of input values is small.

What is Counting Sort?

Counting Sort works in three main steps:

  1. Count the frequency of each element.
  2. Calculate the cumulative (prefix) count.
  3. Place each element in its correct position.

Unlike comparison-based sorting algorithms, Counting Sort does not compare two elements.

When Should We Use Counting Sort?

Counting Sort is suitable when:

  • Elements are integers.
  • The range of values (0 to k) is small.
  • There are many duplicate values.

Example:

2 5 3 0 2 3 0 3

Range:

0 to 5

Since the range is small, Counting Sort works efficiently.

Real-Life Analogy

Imagine a classroom where students receive grades from 0 to 10.

Instead of arranging all answer sheets one by one:

  • Count how many students got each grade.
  • Write all 0s, then all 1s, then all 2s, and so on.

The result is automatically sorted.

C Program

#include <stdio.h>

void countingSort(int arr[], int n)
{
    int max = arr[0];

    // Find maximum element
    for(int i = 1; i < n; i++)
    {
        if(arr[i] > max)
            max = arr[i];
    }

    int count[max + 1];
    int output[n];

    // Initialize count array
    for(int i = 0; i <= max; i++)
        count[i] = 0;

    // Count frequency
    for(int i = 0; i < n; i++)
        count[arr[i]]++;

    // Cumulative count
    for(int i = 1; i <= max; i++)
        count[i] += count[i - 1];

    // Build output array (right to left for stability)
    for(int i = n - 1; i >= 0; i--)
    {
        output[count[arr[i]] - 1] = arr[i];
        count[arr[i]]--;
    }

    // Copy output back
    for(int i = 0; i < n; i++)
        arr[i] = output[i];
}

int main()
{
    int arr[] = {4, 2, 2, 8, 3, 3, 1};
    int n = sizeof(arr) / sizeof(arr[0]);

    countingSort(arr, n);

    printf("Sorted Array:\n");

    for(int i = 0; i < n; i++)
        printf("%d ", arr[i]);

    return 0;
}

Code Explanation

Find Maximum Element

int max = arr[0];

Find the largest value to determine the size of the count array.

Count Frequency

count[arr[i]]++;

Increase the frequency of each value.

Cumulative Count

count[i] += count[i - 1];

Convert frequencies into positions.

Build Output Array

output[count[arr[i]] - 1] = arr[i];
count[arr[i]]--;

Place each element into its correct position.

Processing from right to left preserves the order of equal elements, making Counting Sort stable.

Copy Back

arr[i] = output[i];

Replace the original array with the sorted array.

Time Complexity

CaseComplexity
Best CaseO(n + k)
Average CaseO(n + k)
Worst CaseO(n + k)

Where:

  • n = Number of elements
  • k = Range of input values (maximum value + 1)

Space Complexity

O(n + k)

Extra space is required for both the output array and the count array.

Advantages

  • Very fast when the range of values is small.
  • Stable sorting algorithm.
  • Does not perform element comparisons.
  • Linear time complexity under suitable conditions.

Disadvantages

  • Works only with integer values.
  • Inefficient when the range of values (k) is much larger than the number of elements (n).
  • Requires extra memory.

Applications

  • Sorting student grades.
  • Sorting ages.
  • Counting votes.
  • Histogram generation.
  • Used as a subroutine in Radix Sort.

Key Points to Remember

  • Counting Sort is non-comparison-based.
  • It counts the frequency of each value instead of comparing elements.
  • Best suited for small integer ranges.
  • Stable sorting algorithm.
  • Time Complexity: O(n + k).
  • Space Complexity: O(n + k).
