Indirect Recursion

What is Indirect Recursion?

Indirect Recursion (also called Mutual Recursion) occurs when two or more functions call each other recursively instead of a function calling itself directly.

Definition: A function A() calls B(), and B() calls A() (directly or through other functions). This is called Indirect Recursion.

Unlike Direct Recursion, the recursive call happens through another function.

Example 1: Print Numbers

#include <stdio.h>

void funB(int);

void funA(int n)
{
    if(n <= 0)
        return;

    printf("%d ", n);

    funB(n - 1);
}

void funB(int n)
{
    if(n <= 0)
        return;

    printf("%d ", n);

    funA(n - 1);
}

int main()
{
    funA(5);

    return 0;
}

Example 2: Even and Odd Numbers

This example checks whether a number is even or odd using two mutually recursive functions.

#include <stdio.h>

int isOdd(int);

int isEven(int n)
{
    if(n == 0)
        return 1;

    return isOdd(n - 1);
}

int isOdd(int n)
{
    if(n == 0)
        return 0;

    return isEven(n - 1);
}

int main()
{
    if(isEven(8))
        printf("Even");
    else
        printf("Odd");

    return 0;
}

Output

Even

Why is the Base Case Important?

Consider this code:

void funA()
{
    funB();
}

void funB()
{
    funA();
}

↓

↓

↓

...

This never ends.

A base case is essential to stop the recursive calls.

Advantages

  • Models problems that naturally involve two or more interacting processes.
  • Makes some algorithms easier to express.
  • Useful in state-based recursive problems.

Disadvantages

  • More difficult to understand and debug than direct recursion.
  • Uses additional stack memory.
  • Easy to create infinite recursion if base cases are incorrect.
  • Often harder to trace program flow.

Applications

  • Even/Odd checking.
  • State machine implementations.
  • Grammar parsing in compilers.
  • Recursive descent parsers.
  • Certain graph and tree algorithms.

Key Points to Remember

  • Indirect Recursion involves two or more functions calling each other.
  • It is also known as Mutual Recursion.
  • Every chain of recursive calls must eventually reach a base case.
  • Without a base case, the program enters infinite recursion and eventually causes a stack overflow.
  • Indirect recursion is useful for modeling problems where different states or behaviors naturally alternate.
