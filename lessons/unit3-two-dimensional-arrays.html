Two-Dimensional Arrays (2D Arrays)

Introduction

A One-Dimensional Array (1D Array) stores data in a single row.

Example:

10 20 30 40 50

But many real-world applications require data to be stored in rows and columns, such as:

  • Student marks
  • Multiplication tables
  • Matrices
  • Seating arrangements
  • Chess board
  • Spreadsheet data

For such data, C provides Two-Dimensional Arrays (2D Arrays).

What is a Two-Dimensional Array?

A Two-Dimensional Array is an array of arrays. It stores data in the form of rows and columns, similar to a table or matrix.

Example

Marks of Students

       Subject1  Subject2  Subject3

Student1    85       90       88
Student2    70       75       80
Student3    92       95       91

Representation of a 2D Array

Rows

0 → 10 20 30

1 → 40 50 60

2 → 70 80 90

      0  1  2
     Columns

Declaration of a Two-Dimensional Array

Syntax

data_type array_name[rows][columns];

Example

int marks[3][4];

float salary[5][2];

char board[8][8];

Explanation

int marks[3][4];

Means

  • 3 Rows
  • 4 Columns

Total Elements

3 × 4 = 12 Elements

Memory Representation

int arr[2][3];
         Columns

          0    1    2

Row 0    10   20   30

Row 1    40   50   60

Memory is actually stored in contiguous locations.

10 → 20 → 30 → 40 → 50 → 60

Initialization of 2D Arrays

Method 1

Initialize row-wise.

int arr[2][3] =
{
    {10,20,30},
    {40,50,60}
};

Memory

10 20 30
40 50 60

Method 2

Single List Initialization

int arr[2][3] =
{
    10,20,30,
    40,50,60
};

Compiler automatically fills row by row.

Method 3

Partial Initialization

int arr[2][3] =
{
    {10,20},
    {40}
};

Memory

10 20 0

40  0 0

Remaining elements become 0.

Method 4

Initialize all elements to zero.

int arr[3][3] = {0};

Output

0 0 0

0 0 0

0 0 0

Accessing Elements

Syntax

array[row][column]

Example

marks[0][2]

marks[2][1]

arr[1][0]

Example

#include <stdio.h>

int main()
{
    int arr[2][3] =
    {
        {10,20,30},
        {40,50,60}
    };

    printf("%d\n", arr[0][0]);
    printf("%d\n", arr[1][2]);

    return 0;
}

Output

10
60

Input in 2D Array

Nested loops are used.

#include <stdio.h>

int main()
{
    int arr[2][3];
    int i, j;

    printf("Enter Elements:\n");

    for(i = 0; i < 2; i++)
    {
        for(j = 0; j < 3; j++)
        {
            scanf("%d", &arr[i][j]);
        }
    }

    return 0;
}

Traversing a 2D Array

Traversing means visiting every element.

#include <stdio.h>

int main()
{
    int arr[3][3] =
    {
        {1,2,3},
        {4,5,6},
        {7,8,9}
    };

    int i, j;

    for(i = 0; i < 3; i++)
    {
        for(j = 0; j < 3; j++)
        {
            printf("%d ", arr[i][j]);
        }

        printf("\n");
    }

    return 0;
}

Output

1 2 3
4 5 6
7 8 9

Common 2D Array Programs

Program 1

Print Matrix

#include <stdio.h>

int main()
{
    int arr[2][2] =
    {
        {5,10},
        {15,20}
    };

    int i, j;

    for(i = 0; i < 2; i++)
    {
        for(j = 0; j < 2; j++)
        {
            printf("%d ", arr[i][j]);
        }

        printf("\n");
    }

    return 0;
}

Output

5 10
15 20

Program 2

Find Sum of All Elements

#include <stdio.h>

int main()
{
    int arr[2][2] =
    {
        {10,20},
        {30,40}
    };

    int sum = 0;
    int i, j;

    for(i = 0; i < 2; i++)
    {
        for(j = 0; j < 2; j++)
        {
            sum += arr[i][j];
        }
    }

    printf("Sum = %d", sum);

    return 0;
}

Output

Sum = 100

Program 3

Find Largest Element

#include <stdio.h>

int main()
{
    int arr[2][3] =
    {
        {20,15,30},
        {45,12,25}
    };

    int max = arr[0][0];
    int i, j;

    for(i = 0; i < 2; i++)
    {
        for(j = 0; j < 3; j++)
        {
            if(arr[i][j] > max)
            {
                max = arr[i][j];
            }
        }
    }

    printf("Largest = %d", max);

    return 0;
}

Output

Largest = 45

Program 4

Find Smallest Element

int main()

Program 5

Addition of Two Matrices

#include <stdio.h>

int main()
{
    int A[2][2] = {{1,2},{3,4}};
    int B[2][2] = {{5,6},{7,8}};
    int C[2][2];

    int i, j;

    for(i = 0; i < 2; i++)
    {
        for(j = 0; j < 2; j++)
        {
            C[i][j] = A[i][j] + B[i][j];
        }
    }

    printf("Result Matrix:\n");

    for(i = 0; i < 2; i++)
    {
        for(j = 0; j < 2; j++)
        {
            printf("%d ", C[i][j]);
        }

        printf("\n");
    }

    return 0;
}

Output

Result Matrix:
6 8
10 12

Program 6

Transpose of a Matrix

#include <stdio.h>

int main()
{
    int arr[2][3] =
    {
        {1,2,3},
        {4,5,6}
    };

    int i, j;

    printf("Transpose Matrix:\n");

    for(i = 0; i < 3; i++)
    {
        for(j = 0; j < 2; j++)
        {
            printf("%d ", arr[j][i]);
        }

        printf("\n");
    }

    return 0;
}

Output

Transpose Matrix:
1 4
2 5
3 6

Common Mistakes

Using Invalid Row Index

❌ Incorrect

arr[3][1];

If the array has only 3 rows, valid row indices are 0 to 2.

Using Invalid Column Index

❌ Incorrect

arr[1][5];

If the array has 4 columns, valid column indices are 0 to 3.

Incorrect Loop Limits

❌ Incorrect

for(i = 0; i <= 2; i++)

For a 2 × 2 array, the correct loop is:

for(i = 0; i < 2; i++)

Summary

  • A Two-Dimensional Array stores data in rows and columns.
  • It is declared using data_type array_name[rows][columns];.
  • Elements are accessed using two indices: array[row][column].
  • Nested loops are commonly used for input, output, and processing of 2D arrays.
  • Common operations include traversing, matrix addition, transpose, and finding the largest, smallest, or sum of elements.
