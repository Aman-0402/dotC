File Operations

File operations are the functions provided by C to create, open, read, write, modify, rename, and delete files.

All file handling functions are declared in the <stdio.h> header file.

1. fopen()

Definition

The fopen() function is used to open an existing file or create a new file.

Syntax

FILE *fp;

fp = fopen("filename", "mode");

Example

FILE *fp;

fp = fopen("student.txt", "r");

If successful

fp → Valid Address

If unsuccessful

fp = NULL

Example with Error Checking

#include <stdio.h>

int main()
{
    FILE *fp;

    fp = fopen("student.txt", "r");

    if(fp == NULL)
    {
        printf("Cannot Open File");
        return 1;
    }

    printf("File Opened Successfully");

    fclose(fp);

    return 0;
}

2. fclose()

Definition

The fclose() function closes an opened file.

Syntax

fclose(fp);

Example

FILE *fp;

fp = fopen("student.txt","r");

fclose(fp);

Why Close Files?

  • Saves data
  • Releases memory
  • Prevents corruption
  • Avoids resource leaks

3. fprintf()

Definition

Writes formatted data into a text file.

Works similarly to printf().

Syntax

fprintf(file_pointer, "format", values);

Example

#include <stdio.h>

int main()
{
    FILE *fp;

    fp = fopen("data.txt","w");

    fprintf(fp,"%d\n",100);
    fprintf(fp,"%s\n","Aman");
    fprintf(fp,"%.2f\n",95.5);

    fclose(fp);

    return 0;
}

File Content

100
Aman
95.50

4. fscanf()

Definition

Reads formatted data from a text file.

Works similarly to scanf().

Syntax

fscanf(file_pointer,"format",&variables);

Example

#include <stdio.h>

int main()
{
    FILE *fp;

    int roll;
    char name[20];

    fp = fopen("data.txt","r");

    fscanf(fp,"%d",&roll);
    fscanf(fp,"%s",name);

    printf("%d\n",roll);
    printf("%s",name);

    fclose(fp);

    return 0;
}

Output

100
Aman

5. fgetc()

Definition

Reads one character from a file.

Syntax

character = fgetc(file_pointer);

Example

#include <stdio.h>

int main()
{
    FILE *fp;

    char ch;

    fp = fopen("data.txt","r");

    while((ch = fgetc(fp)) != EOF)
    {
        printf("%c", ch);
    }

    fclose(fp);

    return 0;
}

6. fputc()

Definition

Writes one character into a file.

Syntax

fputc(character, file_pointer);

Example

#include <stdio.h>

int main()
{
    FILE *fp;

    fp = fopen("letters.txt","w");

    fputc('A', fp);
    fputc('B', fp);
    fputc('C', fp);

    fclose(fp);

    return 0;
}

File Content

ABC

7. fgets()

Definition

Reads an entire line (or a specified number of characters) from a file.

Syntax

fgets(array, size, file_pointer);

Example

#include <stdio.h>

int main()
{
    FILE *fp;

    char str[100];

    fp = fopen("data.txt","r");

    fgets(str,100,fp);

    printf("%s",str);

    fclose(fp);

    return 0;
}

8. fputs()

Definition

Writes an entire string into a file.

Syntax

fputs(string, file_pointer);

Example

#include <stdio.h>

int main()
{
    FILE *fp;

    fp = fopen("message.txt","w");

    fputs("Welcome to C Programming", fp);

    fclose(fp);

    return 0;
}

File Content

Welcome to C Programming

9. fread()

Definition

Reads binary data from a binary file.

Syntax

fread(address, size, count, file_pointer);

Parameters

  • address → Variable address
  • size → Size of one record
  • count → Number of records
  • file_pointer → Binary file

Example

struct Student s;

FILE *fp;

fp = fopen("student.dat","rb");

fread(&s, sizeof(s), 1, fp);

fclose(fp);

10. fwrite()

Definition

Writes binary data into a binary file.

Syntax

fwrite(address, size, count, file_pointer);

Example

struct Student s =
{
    101,
    "Aman",
    95.5
};

FILE *fp;

fp = fopen("student.dat","wb");

fwrite(&s, sizeof(s), 1, fp);

fclose(fp);

11. remove()

Definition

Deletes a file permanently.

Syntax

remove("filename");

Example

#include <stdio.h>

int main()
{
    remove("student.txt");

    printf("File Deleted");

    return 0;
}

12. rename()

Definition

Changes the name of a file.

Syntax

rename("oldname","newname");

Example

#include <stdio.h>

int main()
{
    rename("student.txt","record.txt");

    printf("File Renamed");

    return 0;
}

{

Common Mistakes

❌ Forgetting to check if fopen() returns NULL.

❌ Forgetting to call fclose().

❌ Using "r" mode for a file that doesn't exist.

❌ Reading binary files using text functions (fprintf(), fscanf()).

❌ Opening binary files without b mode ("rb", "wb").

❌ Reading beyond the end of a file without checking EOF.

Key Takeaways

  • fopen() opens or creates a file.
  • fclose() closes the file and saves changes.
  • fprintf() and fscanf() work with formatted text data.
  • fgetc() and fputc() handle one character at a time.
  • fgets() and fputs() work with complete strings or lines.
  • fread() and fwrite() are used for efficient binary file operations.
  • remove() deletes a file permanently, while rename() changes its name.
  • Always verify successful file opening and close every file after use to ensure safe and reliable file handling.
