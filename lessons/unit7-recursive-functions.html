Recursive Functions

A Recursive Function is a function that calls itself directly or indirectly to solve a problem.

The key idea is:

Solve a small part of the problem, then let the function solve the remaining smaller problem.

Anatomy of a Recursive Function

Every recursive function has three essential components:

returnType function(parameters)
{
    // Base Case
    if(condition)
        return value;

    // Recursive Case
    return function(smaller_problem);
}

Components

  1. Function Declaration
  2. Base Case (Stopping condition)
  3. Recursive Call (Function calls itself)

Example 1: Print Numbers from 1 to 5

#include <stdio.h>

void print(int n)
{
    if(n > 5)
        return;

    printf("%d ", n);

    print(n + 1);
}

int main()
{
    print(1);

    return 0;
}

1 2 3 4 5

Example 2: Print Numbers in Reverse

#include <stdio.h>

void reverse(int n)
{
    if(n == 0)
        return;

    printf("%d ", n);

    reverse(n - 1);
}

int main()
{
    reverse(5);

    return 0;
}

Output

5 4 3 2 1

Example 3: Sum of First N Numbers

Formula:

sum(n) = n + sum(n - 1)

Base Case:

sum(0) = 0

Program

#include <stdio.h>

int sum(int n)
{
    if(n == 0)
        return 0;

    return n + sum(n - 1);
}

int main()
{
    printf("%d", sum(5));

    return 0;

Example 4: Power of a Number

Formula:

power(a, b)

=

a × power(a, b − 1)

Program

#include <stdio.h>

int power(int base, int exp)
{
    if(exp == 0)
        return 1;

    return base * power(base, exp - 1);
}

int main()
{
    printf("%d", power(2, 5));

    return 0;
}

Output

32

Example 5: Fibonacci Series

Formula:

F(n)

=

F(n-1) + F(n-2)

Base Cases:

F(0)=0

F(1)=1

Program

#include <stdio.h>

int fibonacci(int n)
{
    if(n == 0)
        return 0;

    if(n == 1)
        return 1;

    return fibonacci(n-1) + fibonacci(n-2);
}

int main()
{
    for(int i=0;i<8;i++)
        printf("%d ", fibonacci(i));

    return 0;
}

Output

0 1 1 2 3 5 8 13

Fibonacci Call Tree

For:

fibonacci(4)
                 fib(4)
                /      \
            fib(3)    fib(2)
           /     \     /    \
       fib(2) fib(1) fib(1) fib(0)
       /   \
   fib(1) fib(0)

Notice that:

fib(2)

fib(1)

fib(0)

are computed multiple times.

This is why the recursive Fibonacci solution is inefficient.

Rules for Writing Recursive Functions

✅ Always define a Base Case.

if(n == 0)
    return;

✅ Reduce the problem size.

fun(n-1);

or

fun(n/2);

❌ Wrong

fun(n);

The problem size never changes, causing infinite recursion.

Common Errors

Missing Base Case

void fun()
{
    fun();
}

Result:

Infinite Recursion

↓

Stack Overflow

Problem Not Reduced

fun(n);

The same function keeps calling itself forever.

Wrong Base Condition

if(n == 100)
    return;

If n never becomes 100, the recursion never stops.

  • Graph Traversal

Advantages

  • Short and clean code.
  • Easy to understand for recursive problems.
  • Natural fit for divide-and-conquer algorithms.
  • Ideal for hierarchical data structures like trees.

Disadvantages

  • Extra memory is needed for the call stack.
  • Can be slower than loops due to function call overhead.
  • Poorly designed recursion can lead to stack overflow.
  • Some recursive solutions (e.g., naive Fibonacci) perform repeated computations.

Iteration vs Recursion

Feature Iteration Recursion
UsesLoopsFunction calls
MemoryO(1)O(n) (call stack)
SpeedUsually fasterUsually slower
CodeMore verboseOften shorter and cleaner
Best ForRepetitive tasksDivide-and-conquer, trees, graphs

Key Points to Remember

  • A recursive function solves a problem by calling itself.
  • Every recursive function must have a base case.
  • Each recursive call should move closer to the base case.
  • The call stack stores active recursive calls.
  • Recursive functions are powerful but should be used carefully to avoid excessive memory use and infinite recursion.
