Interpreters

In the previous topics, we learned that C uses a Compiler to convert the entire program into machine code.

But not all programming languages work this way. Some languages use an Interpreter instead.

Understanding the difference between a Compiler and an Interpreter is a very common interview and exam topic.

What is an Interpreter?

Definition

An Interpreter is a software program that translates and executes a program one statement (or one line) at a time, instead of translating the whole program at once.

Unlike a compiler, an interpreter does not create a separate executable file.

What Happens if an Error Occurs?

Example:

print("Hello")

x = 10

print(y)

print("End")

Execution:

Line 1 → Executed ✅

Line 2 → Executed ✅

Line 3 → Error ❌

Program Stops

Output:

Hello

NameError: name 'y' is not defined

Notice:

  • The first two lines executed successfully.
  • Execution stopped at the error.
  • The last line was never executed.

How Does a Compiler Work?

Suppose we have a C program.

#include <stdio.h>

int main()
{
    printf("Hello");

    printf("Welcome")

    printf("C");

    return 0;
}

There is a missing semicolon after:

printf("Welcome")

The compiler checks the entire program first.

Result:

Compilation Error

Program Will Not Execute

Even though the first printf() is correct, nothing is executed until all compilation errors are fixed.

Advantages of Compiler

  • Faster execution after compilation.
  • Creates an executable file.
  • Optimizes the program.
  • Errors are detected before execution.

Disadvantages of Compiler

  • Compilation takes time.
  • Every change requires recompilation.
  • Larger executable files.

Advantages of Interpreter

  • Easy to test small programs.
  • No separate compilation step.
  • Good for scripting.
  • Easier for beginners.

Disadvantages of Interpreter

  • Slower execution.
  • No executable file.
  • Stops at the first runtime error.
  • Must interpret the program every time it runs.

Languages Using Compilers

Examples:

  • C
  • C++
  • Go
  • Rust

Languages Using Interpreters

Examples:

  • Python
  • JavaScript (in browsers)
  • Ruby
  • PHP

Note: Modern implementations are often more complex. For example, Java uses both compilation (to bytecode) and interpretation/JIT compilation, and Python also compiles to bytecode internally before execution. For beginners, it's fine to remember that C is primarily compiled, while Python and JavaScript are commonly described as interpreted.

Interview Questions

Q1. What is an Interpreter?

Answer: An Interpreter is software that translates and executes a program one statement at a time.

Q2. What is the main difference between a Compiler and an Interpreter?

Answer: A compiler translates the entire program before execution, while an interpreter translates and executes one statement at a time.

Q3. Does an Interpreter create an executable file?

Answer: No, an interpreter executes the program directly without creating a separate executable file.

Q4. Which is faster after translation: Compiler or Interpreter?

Answer: A compiled program is generally faster because it runs as machine code.

Q5. Name two interpreted languages.

Answer: Python and JavaScript.

Key Points to Remember

  • An Interpreter translates and executes code one statement at a time.
  • A Compiler translates the entire program before execution.
  • Compilers create executable files; interpreters generally do not.
  • C uses a Compiler.
  • Python and JavaScript are commonly taught as Interpreted Languages.
  • Compiled programs usually execute faster than interpreted programs.
